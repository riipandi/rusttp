# UI Components Library

React components on [Base UI](https://base-ui.com) parts, styled with [StyleX](https://stylexjs.com). Every color, size, shadow, and motion value is a token, so one change reaches every component and both themes.

The library ships as source. Import from `uilibs/<path under src>` (`uilibs/base/button`, `uilibs/extra/card`, `uilibs/theme`) and let your bundler compile its StyleX with the rest of your app.

## Install

These are the library's `dependencies`. The first line is what every app needs; each later line is needed only if you use the components named in its comment.

```sh
# Every app
pnpm add @base-ui/react @stylexjs/stylex @stylexjs/atoms @keyline-icons/react react react-dom

# ThemeProvider (its script runs before first paint)
pnpm add @tanstack/react-router

# Calendar
pnpm add react-day-picker

# Input Phone
pnpm add react-phone-number-input country-flag-icons

# Data Grid
pnpm add @tanstack/react-table @tanstack/react-virtual

# Charts
pnpm add @tanstack/charts

# Kanban, Sortable, and the data grid's row dragging
pnpm add @dnd-kit/core @dnd-kit/modifiers @dnd-kit/sortable @dnd-kit/utilities

# Resizable
pnpm add react-resizable-panels
```

## Set up

Put `UIProvider` and `ThemeProvider` once at the root, and render `ThemeSwitcher` wherever the user should change theme. [Theming](?path=/docs/theming--docs) has the props, the dark theme, one-off scopes, and right-to-left text.

```tsx
import { UIProvider } from 'uilibs/base/provider'
import { ThemeProvider, ThemeSwitcher } from 'uilibs/theme'

export function Root({ children }: { children: React.ReactNode }) {
  return (
    <UIProvider>
      <ThemeProvider attribute='data-theme' defaultTheme='system'>
        <ThemeSwitcher />
        {children}
      </ThemeProvider>
    </UIProvider>
  )
}
```

## Design tokens

The tokens follow [Reshaped UI](https://www.reshaped.so/docs/tokens): a color is a role (`primary`, `neutral`, `positive`, `warning`, `critical`) plus a part (`background`, `foreground`, `border`) plus an optional modifier (`Faded`, `Highlighted`). A text color on a solid background comes from the matching `onBackground*` token, so the pair stays readable in any theme. Surfaces that sit above the page use the elevation tokens, because a shadow alone is faint in dark mode. [Theming](?path=/docs/theming--docs) lists every token and says which a theme can replace.
