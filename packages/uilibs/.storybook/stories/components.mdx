# Components

The catalog of `packages/uilibs/src`. Check it before you write a component, and extend an existing one when it already does the job. Each name opens that component's page: import, anatomy, examples, props, data attributes, and caveats.

## Conventions

- **Imports.** `uilibs/<path under src>`: `uilibs/base/button`, `uilibs/extra/card`, `uilibs/styles/tokens.stylex`, `uilibs/theme`. Inside the package use a relative path; there is no `#/` alias (lint rejects it).
- **Layout.** A component is a folder: `<name>.component.tsx`, `<name>.stylex.ts`, `<name>.stories.tsx`, `<name>.mdx`, `index.ts`. A new, renamed, or removed component updates this page in the same change.
- **Styling.** StyleX only, with tokens from `uilibs/styles/`. A component takes `style` and never `className`. See [Styling](?path=/docs/styling--docs) and [Theming](?path=/docs/theming--docs).
- **Color and fill.** `color` is the role: `primary`, `neutral`, `positive`, `warning`, `critical`. `variant` is the fill: `solid`, `faded`, `outline`, `ghost`. Text-entry controls use `variant` for the box: `outline`, `faded`, `ghost`, `headless`.
- **Size.** Form controls take `size`: `small` 32px, `medium` 36px (default), `large` 40px, and `xsmall` 28px on Button, Toggle, and Tabs. A row of mixed controls shares one height.
- **Text.** Built-in strings are one `labels` object per component, with English defaults. There are no `text`, `label`, or `title` props. Wrappers take `ref` as a prop.
- **Playground.** Each component's `Playground` story is where its props can be tried: the Controls panel shows only there.
- **Behavior.** Base components wrap [Base UI](https://base-ui.com) and keep its props, events, and ARIA behavior. Props not listed on a page pass through.

## Choosing between look-alikes

- **Popover, Dialog, Drawer, or Sheet.** Popover is interactive content anchored to its trigger. Dialog is a modal popup over the page, and the page behind it is inert. Sheet is a Dialog that slides in from an edge, for navigation or settings. Drawer is a swipe panel with snap points, for touch.
- **Dialog or Alert Dialog.** Dialog is content the user may dismiss. Alert Dialog needs an answer, for a destructive or high-risk action.
- **Select, Combobox, Autocomplete, or Command.** Select picks one value from a short list. Combobox searches a list, and `ComboboxChips` takes several values. Autocomplete suggests free text that may match nothing. Command is a palette of actions.
- **Tooltip, Preview Card, or Popover.** Tooltip names a control on hover or focus and holds no interactive content. Preview Card previews a link on hover or focus. Popover holds interactive content and opens from a trigger.
- **Dropdown Menu, Context Menu, or Menubar.** Dropdown Menu opens from a button. Context Menu opens at the pointer on right click or long press. Menubar is a desktop-style bar of menus. The three share their items.
- **Toggle, Switch, or Checkbox.** Switch is an on and off setting that takes effect at once. Checkbox is a choice that is submitted with a form, alone or in a group. Toggle is a button that stays pressed, such as bold in a toolbar.
- **Accordion or Collapsible.** Accordion is a stack of headings that each open a panel. Collapsible is one panel with its own trigger.
- **Toggle Group, Tabs, or Radio.** Toggle Group is a row of pressed buttons that act on content, such as a text style. Tabs switch which panel of content shows. Radio is one choice from a few options, submitted with a form.
- **Number Field, Slider, or Input.** Number Field is a typed number with steppers. Slider picks a value or a range by dragging. Input is free text.
- **Table or Data Grid.** Table is a styled HTML table for a few static rows. Data Grid is for sorting, selection, paging, pinning, and editing.
- **Item or Table.** Item is a one-column row. A record with several columns is a Table.
- **Link or Button with `render`.** A link inside a sentence, a footer, or a form is a Link. A link that looks like a button is a Button with `render={<a />}`; both take a router link through `render`.
- **Progress, Meter, or Step Dots.** Progress is how far one task has got. Meter is a value in a known range. Step Dots is the position in a sequence of steps or slides.
- **Image or Avatar.** Image is a content picture with a ratio and a fallback box. Avatar is a person, with initials as its fallback.
- **Badge `dismiss` or Badge Anchor.** The dismiss button of a Badge removes the badge. Badge Anchor pins a badge to the corner of another element, such as an avatar or an icon button.
- **Theme Scope or the page theme.** The page theme comes from `ThemeProvider` and `ThemeSwitcher`. Theme Scope makes one subtree dark, light, or the opposite of the page, and its popups follow it.
- **Stack or raw flex.** Layout between elements (a row of actions, a form column, a page section) is a Stack. A flex rule that styles one control's own parts stays in that component's stylesheet.
- **Container, Stack, or Hidden.** Container is a centered column with a maximum width. Stack spaces its children. Hidden shows or hides markup per breakpoint, and `useResponsiveValue` picks a value that is not markup.
- **Hidden or `useResponsiveValue`.** Hidden uses CSS media queries and its children still mount. `useResponsiveValue` returns the value for the current viewport so a component can skip rendering.

## Data Grid

[Data Grid](?path=/docs/data-grid-basics--data-grid) is for large or interactive data; a few static rows are a Table. It is a virtualized TanStack Table grid: column pinning and reordering, inline editing, drag-and-drop rows, infinite loading, footers, and a pager. A table needs a name (`aria-label` or `aria-labelledby`), a row's controls are named through `getRowLabel`, and with `onRowClick` the rows are keyboard targets; each resizable column has a keyboard separator. Import from `uilibs/data-grid`.

## Charts

Primitives on TanStack Charts: `ChartContainer` (takes `config` and an optional `description`), `Chart` (takes a `defineChart()` definition, `ariaLabel`, and `height`), and `ChartLegend`. Import from `uilibs/charts`. [Charts](?path=/docs/visualizations-charts--docs) covers the accessibility rules and the show-as-table recipe; `charts/stories/` holds one recipe per chart type.

- A series key in `config` matches a mark `id`. A mark color is any CSS color, including a theme token.
- A series that carries meaning needs 3:1 against the page, or a second cue such as a label or legend entry. The `foreground*` tokens pass in both themes. A `background*` fill as a series color does not, so label it.
- Give each chart in a document an explicit `idPrefix`.

## Icons, hooks, and assets

- **Icons.** General icons come from `@keyline-icons/react`; wrap them in `Icon` to size and color them. `uilibs/icons` has the brand marks (see the [Icon page](?path=/docs/extra-components-icon--docs)): `FacebookIcon`, `GitHubIcon`, `GoogleIcon`, `InstagramIcon`, `LinkedInIcon`, `TelegramIcon`, `WhatsAppIcon`, `XIcon`, and `ViteIcon`. They are not built on `Icon`: each takes `size` in px, and each except `ViteIcon` is a named image (`role='img'` with an `aria-label`), so pass `aria-hidden` when the mark sits beside visible text that already says the name. `ViteIcon` has no name; give it an `aria-label` or `aria-hidden`.
- **Hooks.** `uilibs/hooks/use-media-query` exports `useMediaQuery` and `useIsMobile`. `uilibs/hooks/use-responsive-value` exports `useResponsiveValue` and the `Responsive<T>` type: one value, or `{ small, medium, large, xlarge }`.
- **Styles.** `uilibs/styles/*`: `colors.stylex`, `tokens.stylex`, `control.stylex` (`controlSizes`, `controlBase`, `controlPress`), `popup.stylex` (`popupFx`), `utils.stylex` (`ring`, `focusRing`, `visuallyHidden`, `unitLength`), and `themes`.
- **Assets.** `uilibs/assets/*.css`: `reset.css`, `fontface.css`, `globals.css`.
