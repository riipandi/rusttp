# Data Grid

A table for large, interactive data: sorting, filtering, paging, pinning, resizing, row and cell selection, spreadsheet editing, and drag reordering.

## Import

```jsx
import {
  DataGrid,
  DataGridCellSelection,
  DataGridColumnFilter,
  DataGridColumnHeader,
  DataGridContainer,
  dataGridFeatures,
  DataGridPagination,
  DataGridProvider,
  DataGridScrollArea,
  DataGridSelectionBar,
  DataGridTable,
  DataGridTableBody,
  DataGridTableHead,
  DataGridTableRowExpand,
  DataGridTableRowPin,
  DataGridTableRowSelect,
  DataGridTableRowSelectAll
} from 'uilibs/data-grid'
```

Built on [TanStack Table](https://tanstack.com/table), [TanStack Virtual](https://tanstack.com/virtual), and [dnd-kit](https://docs.dndkit.com). The grid never owns your data: every write goes back through a callback.

## Anatomy

- **DataGrid:** the root. It renders no element; it publishes layout, messages, and callbacks to the parts below it. `DataGridProvider` is the same without the defaults.
- **DataGridCellSelection:** optional, headless spreadsheet controller (keyboard, clipboard, fill handle). It needs `tableLayout.cellSelection`.
- **DataGridContainer:** the frame around the grid.
- **DataGridScrollArea:** a scroll area with a grid-aware scrollbar around the table.
- **DataGridTable:** header, body, optional footer, and the add-row button, assembled from `DataGridTableHead` and `DataGridTableBody`. Swap it for `DataGridTableVirtual`, `DataGridTableDnd` (draggable columns), or `DataGridTableDndRows` (draggable rows).
- **DataGridSelectionBar:** optional bar with the selected row count and your bulk actions. It is hidden while no row is selected.
- **DataGridPagination:** page-size select, record range, and page buttons.
- **DataGridColumnHeader:** a header cell with title, sort, and a menu for pinning, moving, and hiding. It goes in a column definition's `header` and takes a `DataGridColumnFilter` in its `filter` prop.
- **DataGridTableRowSelect, DataGridTableRowSelectAll, DataGridTableRowExpand, DataGridTableRowPin, DataGridTableDndRowHandle:** row controls that go in a column definition's `cell` (or `header`, for select-all).
- **DataGridTableFootRow, DataGridTableFootRowCell:** footer rows, passed as `footerContent` to a table.

```jsx
<DataGrid table={table} recordCount={…}>
  <DataGridCellSelection table={table} />
  <DataGridContainer>
    <DataGridScrollArea table={table}>
      <DataGridTable table={table} />
    </DataGridScrollArea>
  </DataGridContainer>
  <DataGridSelectionBar table={table} />
  <DataGridPagination table={table} />
</DataGrid>
```

Create `table` with `useTable` and `dataGridFeatures`, and give every part that takes `table` the same instance as `DataGrid`.

## API reference

`DataGridContainer`, `DataGridScrollArea`, `DataGridPagination`, `DataGridSelectionBar`, `DataGridColumnHeader`, `DataGridTableDndRowHandle`, `DataGridTableFootRowCell`, `DataGridTableBodyRowSkeleton`, and `DataGridTableRowExpand` also take `style`: StyleX styles that replace `className` and `style`. `DataGrid` accepts `style` but does not apply it. See [Styling](?path=/docs/styling--docs).

### DataGrid, DataGridProvider

`DataGridProvider` takes the same props with a required `table` and without the defaults.

| Prop                    | Description                                                                                                                                                                                                                           |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `table`                 | table instance from `useTable` <br /> The grid's table. Required; `DataGrid` throws without it.                                                                                                                                       |
| `recordCount`           | `number` <br /> Total records, used for paging and counts. Required.                                                                                                                                                                  |
| `isLoading`             | `boolean` <br /> Shows the loading state. Default `false`.                                                                                                                                                                            |
| `loadingMode`           | `skeleton`, `spinner` <br /> How the loading state looks. Default `skeleton`.                                                                                                                                                         |
| `loadingMessage`        | `ReactNode` <br /> Overrides the loading label. Default from `i18n`.                                                                                                                                                                  |
| `fetchingMoreMessage`   | `ReactNode` <br /> Shown while more rows load in infinite mode. Default from `i18n`.                                                                                                                                                  |
| `allRowsLoadedMessage`  | `ReactNode` <br /> Shown after the last infinite page. Default from `i18n`.                                                                                                                                                           |
| `emptyMessage`          | `ReactNode` <br /> Shown when there are no rows. Default from `i18n`.                                                                                                                                                                 |
| `i18n`                  | `{ labels }` <br /> Overrides built-in strings; a specific prop such as `emptyMessage` still wins. Default English.                                                                                                                   |
| `onRowClick`            | `(row) => void` <br /> Makes rows clickable.                                                                                                                                                                                          |
| `onRowCreate`           | `() => void` <br /> Adds an "Add row" button as the last body row.                                                                                                                                                                    |
| `rowCreateLabel`        | `ReactNode` <br /> Label of that button. Default from `i18n`.                                                                                                                                                                         |
| `appendRow`             | `ReactNode` <br /> A `tr` rendered after the data rows, such as a draft row.                                                                                                                                                          |
| `getRowStatus`          | `(row) => 'new' \| 'dirty' \| 'deleted' \| undefined` <br /> Tints or strikes a row.                                                                                                                                                  |
| `getCellStatus`         | `(row, columnId) => 'dirty' \| 'invalid' \| undefined` <br /> Marks a cell corner.                                                                                                                                                    |
| `onCellsChange`         | `(details) => void` <br /> Receives each paste, cut, clear, fill, or edit batch. Without it writes do nothing.                                                                                                                        |
| `onCellEditRequest`     | `(request) => void` <br /> Asks you to open an editor for the focused cell.                                                                                                                                                           |
| `onCellSelectionChange` | `(snapshot) => void` <br /> Fires on every selection change with the resolved focus and ranges.                                                                                                                                       |
| `onCellsCopy`           | `(details) => void` <br /> Fires after the clipboard is written.                                                                                                                                                                      |
| `tableLayout`           | object, see below <br /> Layout and feature switches.                                                                                                                                                                                 |
| `tableStyles`           | object of StyleX styles <br /> Per-part styles: `base`, `header`, `headerRow`, `headerSticky`, `body`, `bodyRow`, `footer`, `edgeCell`, `rowNew`, `rowDirty`, `rowDeleted`, `rowPinned`, `rowCreate`, `cellFillHandle`. Default `{}`. |
| `children`              | `ReactNode` <br /> The grid parts.                                                                                                                                                                                                    |

### Column meta

Set on `columnDef.meta` (`DataGridColumnMeta`).

| Key               | Description                                                                                                                          |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `headerTitle`     | `string` <br /> Header and visibility label; falls back to a string `header`, then the id.                                           |
| `headerStyle`     | StyleX styles <br /> Extra styles for the header cell.                                                                               |
| `cellStyle`       | StyleX styles <br /> Extra styles for the body cell.                                                                                 |
| `skeleton`        | `ReactNode` <br /> Cell content while loading.                                                                                       |
| `expandedContent` | `(row) => ReactNode` <br /> Detail panel shown when the row expands.                                                                 |
| `autoSize`        | `boolean` <br /> Absorbs free width under `columnsResizable` and reflows with the container. Default `false`.                        |
| `fillWidth`       | `boolean` <br /> Absorbs the free-space strip; one column per grid. Default `false`.                                                 |
| `cellEdit`        | `{ editable, parse, format, clearValue, control }` <br /> Marks the column writable for paste, fill, clear, and the built-in editor. |

`cellEdit` keys: `editable` (`boolean` or `(row) => boolean`, default `true`), `parse` (`(raw, row) => unknown`, return `undefined` to reject), `format` (`(value, row) => string`), `clearValue` (default `null`), and `control` (`text` or `textarea`).

### Layout parts

| Prop                               | Description                                                                            |
| ---------------------------------- | -------------------------------------------------------------------------------------- |
| `DataGridContainer` `border`       | `boolean` <br /> Draws an edge around the grid, with rounded corners. Default `false`. |
| `DataGridScrollArea` `table`       | table <br /> The grid's table instance. Required.                                      |
| `DataGridScrollArea` `children`    | `ReactNode` <br /> The table. Required.                                                |

### Tables

`DataGridTable`, `DataGridTableVirtual`, `DataGridTableDnd`, and `DataGridTableDndRows` each take `table` (required, the grid's table instance) and `footerContent` (`ReactNode`, rows or cells for the footer). `DataGridTableHeader` renders only the header, for a body that scrolls in a separate viewport, and takes `table`.

| Prop                  | Description                                                                                                                                        |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `renderHeader`        | `boolean` <br /> On `DataGridTable` and `DataGridTableVirtual`: set `false` to render the body alone. Default `true`.                              |
| `handleDragEnd`       | `(event: DragEndEvent) => void` <br /> On `DataGridTableDnd` and `DataGridTableDndRows`: reorder `columnOrder` or your data here. Required.        |
| `dataIds`             | `UniqueIdentifier[]` <br /> On `DataGridTableDndRows`: row ids in display order. Required.                                                         |
| `collisionDetection`  | dnd-kit collision function <br /> On `DataGridTableDndRows`: how the drop target is found. Default `closestCenter`.                                |
| `modifiers`           | dnd-kit modifiers <br /> On `DataGridTableDndRows`: replaces the axis restriction; the container clamp always applies. Default vertical axis only. |
| `sortingStrategy`     | dnd-kit sorting strategy <br /> On `DataGridTableDndRows`: return `null` to leave rows put while dragging. Default holds rows in place.            |
| `renderRowDecoration` | `({ row, isDragging, isOver }) => ReactNode` <br /> On `DataGridTableDndRows`: per-row slot for drop indicators and depth guides.                  |
| `dropIndicator`       | `boolean` <br /> On `DataGridTableDndRows`: line on the seam the row would land on. Default `true`.                                                |
| `onDragStart`         | `(event) => void` <br /> On `DataGridTableDndRows`: dnd-kit drag start.                                                                            |
| `onDragMove`          | `(event) => void` <br /> On `DataGridTableDndRows`: dnd-kit drag move.                                                                             |
| `onDragOver`          | `(event) => void` <br /> On `DataGridTableDndRows`: dnd-kit drag over.                                                                             |
| `onDragCancel`        | `(event) => void` <br /> On `DataGridTableDndRows`: dnd-kit drag cancel.                                                                           |

### Table building blocks

`DataGridTable` and `DataGridTableVirtual` assemble these; use them for a custom table. Props, all required unless marked:

- `DataGridTableBase`: `table`, `children` (the `thead`, `tbody`, and `tfoot`).
- `DataGridTableViewport`: `table`, `children`, `viewportRef` (optional, receives the viewport element), and `style` (optional `CSSProperties`, inline CSS and not StyleX).
- `DataGridTableHead`, `DataGridTableBody`, `DataGridTableFoot`: `children` only. `DataGridTableRowSpacer` and `DataGridTableLoader` take no props.
- `DataGridTableAddRow`, `DataGridTableEmpty`, `DataGridTableFillHeadCell`, `DataGridTableFillBodyCell`: `table` only.
- `DataGridTableHeadRow`: `children`, `rowId` (rendered as `data-header-row-id`).
- `DataGridTableHeadRowCell`: `header`, `table`, `children`; optional `dndRef` and `dndStyle` from `DataGridTableDnd`.
- `DataGridTableHeadRowCellResize`: `header`, `table`.
- `DataGridTableFootRow`: `table`, `children`. `DataGridTableFootRowCell`: optional `children` and `colSpan`.
- `DataGridTableBodyRowSkeleton`: `children`; optional `wantsBorder` (draws the bottom border) and `stripe` (alternating tint under `stripped`).
- `DataGridTableBodyRowSkeletonCell`: `column`, `table`, `children`.
- `DataGridTableBodyRow`: `row`, `table`, `children`; optional `pinnedBoundary` (`top` or `bottom`), `rowRef`, `dndRef` and `dndStyle` from `DataGridTableDndRows`, `dataIndex` (rendered as `data-index`), `stripe`, `wantsBorder`.
- `DataGridTableBodyRowCell`: `cell`, `table`, `children`; optional `dndRef`, `dndStyle`, `columnIndex` (rendered as `data-column-index`), `isFirstRow` and `isLastRow` (clamp the selection outline), `nextPinned`, `prevPinned`, `nextIsFillCell`, `rowSelected` and `rowStatus` (`new`, `dirty`, `deleted`) to tint pinned cells.
- `DataGridTableBodyRowExpandded` (spelled so in the export): `row` only.
- `DataGridTableRenderedRow`: a body row with its cells, pinning, and expansion. `row`, `table`; optional `pinnedBoundary`, `rowRef`, `rowIndex`, `stripe` (default derived), `wantsBorder`, `isFirstRow`, `isLastRow`, `centerWindow` (`{ start, end }`, renders only that slice of center cells).

| Data attribute             | Description                                                                                                                     |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `data-state`               | Set by this library on a body row: `selected` while the row is selected.                                                        |
| `data-row-status`          | Set by this library on a body row: `new`, `dirty`, or `deleted`, from `getRowStatus`.                                           |
| `data-row-pinned-boundary` | Set by this library on a body row: `top` or `bottom` on the edge of a pinned group.                                             |
| `data-cell-status`         | Set by this library on a body cell: `dirty` or `invalid`, from `getCellStatus`.                                                 |
| `data-pinned`              | Set by this library on head and body cells: `start` or `end` while the column is pinned.                                        |
| `data-cell-selected`       | Set by this library on a body cell: present while the cell is in the selection.                                                 |
| `data-cell-focused`        | Set by this library on a body cell: present on the focused cell.                                                                |
| `data-cell-edge-top`       | Set by this library on a body cell: present on the selection's top edge. `-right`, `-bottom`, and `-left` mark the other edges. |

### Hooks and helpers

- `useDataGrid`: reads the grid context (`props`, `recordCount`, `isLoading`, `i18n`) inside a `DataGrid`.
- `dataGridFeatures`: the TanStack feature bundle the grid renders against. `mergeDataGridI18n` merges `i18n` overrides over the English defaults, one level deep.
- Column and cell: `getColumnHeaderLabel`, `toDataGridDomId`, `getDataGridCellSelectionCellAttrs`, `getPinningStyles`, `getDataGridTreeIndentStyle`, `getDataGridScrollAreaViewport`.
- Rows and headers: `getDataGridTableRowSections`, `getDataGridTableResolvedRows`, `getDataGridTableMergedHeaderGroups`, `hasDataGridTableRightPinnedColumns`.
- Clipboard and edits: `parseDataGridClipboardText`, `serializeDataGridClipboardText`, `tileDataGridClipboardBlock`, `buildDataGridPasteDetails`, `buildDataGridClearDetails`, `invertDataGridCellsChange` (swaps a batch's values for undo and redo), `getDataGridActiveRegionGrid`, `getDataGridVisibleSelectedCellCount`.

## Caveats

- Without `onCellsChange`, copy still works but paste, cut, clear, fill, and edit write nothing.
- `DataGridCellSelection` needs `tableLayout.cellSelection`; with it on the table renders as `role="grid"`, and a page change clears the selection.
- `DataGridColumnHeader` does not forward the `div` attributes its type extends.
- `DataGridTableBodyRowExpandded` is exported with that spelling.
- `DataGridTableViewport` takes `style` as inline `CSSProperties`, not StyleX.
