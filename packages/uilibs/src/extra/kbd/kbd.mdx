# Kbd

A keyboard key cap. `KbdGroup` joins several keys into one shortcut.

## Import

```jsx
import { Kbd, KbdGroup } from 'uilibs/extra/kbd'
```

Plain `kbd` elements, no Base UI parts. Props not listed here pass through.

## Anatomy

- **KbdGroup:** optional for a single key. Lays several keys out in a row. It renders a `kbd`.
- **Kbd:** one key cap, a `kbd`.

```jsx
<KbdGroup>
  <Kbd>…</Kbd>
</KbdGroup>
```

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs). No part adds props or data attributes.

## Caveats

- `Kbd` only draws the key; it registers no shortcut. The listener is separate, such as `@tanstack/react-hotkeys`.
- `Kbd` sets `pointer-events: none` and `user-select: none`, so a key cap cannot be selected or clicked.
