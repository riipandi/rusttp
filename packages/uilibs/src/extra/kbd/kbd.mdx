# Kbd

A keyboard key cap. `KbdGroup` joins several keys into one shortcut.

## Import

```jsx
import { Kbd, KbdGroup } from 'uilibs/extra/kbd'
```

`Kbd` is built on Base UI [useRender](https://base-ui.com/react/utils/use-render), so `render` swaps its `kbd` for another element. `KbdGroup` is a plain `kbd`. Props not listed here pass through.

## Anatomy

- **KbdGroup:** optional for a single key. Lays several keys out in a row. It renders a `kbd`.
- **Kbd:** one key cap, a `kbd`.

```jsx
<KbdGroup>
  <Kbd>…</Kbd>
</KbdGroup>
```

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs). No part adds data attributes.

### Kbd

| Prop     | Description                                                                          |
| -------- | ------------------------------------------------------------------------------------ |
| `render` | `ReactElement`, function <br /> Swaps the `kbd` for another element, such as a link. |

## Caveats

- `Kbd` is a native `kbd`; a screen reader reads its text, so write `Control` or a spoken name where a symbol such as `⌘` would be read badly.
- `Kbd` only draws the key; it registers no shortcut. The listener is separate, such as `@tanstack/react-hotkeys`.
- `Kbd` sets `pointer-events: none` and `user-select: none`, so a key cap cannot be selected or clicked.
