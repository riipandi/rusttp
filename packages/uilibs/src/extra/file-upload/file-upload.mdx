# File Upload

A file input with a drop area. Inside a `Field` it takes the label, error, and invalid state.

Built on Base UI [Field](https://base-ui.com/react/components/field) `Control` for the input and [useRender](https://base-ui.com/react/utils/use-render) for the root `div`, so `render` swaps the element. Props not listed here pass through.

## Anatomy

```jsx
import { FileUpload, FileUploadTrigger } from 'uilibs/extra/file-upload'

;<FileUpload name='…'>
  <FileUploadTrigger>…</FileUploadTrigger>
</FileUpload>
```

`FileUpload` renders the file input and a label around its children, so the whole area opens the picker. `FileUploadTrigger` is optional: a `span` that keeps a nested element in the text flow, and it does not open the picker itself. It takes the `span` props.

## Props

### FileUpload

| Prop              | Values                                          | Default   | Note                                                                           |
| ----------------- | ----------------------------------------------- | --------- | ------------------------------------------------------------------------------ |
| `name`            | `string`                                        | required  | Name of the file input.                                                        |
| `onChange`        | `({ name, value, event }) => void`              | none      | Called with the chosen or dropped files as `value`, a `File[]`.                |
| `disabled`        | `boolean`                                       | `false`   | Disables the input and the drop area.                                          |
| `variant`         | `outline`, `headless`                           | `outline` | `headless` has no box, for a custom trigger such as a `Button`.                |
| `inline`          | `boolean`                                       | `false`   | A more compact layout.                                                         |
| `height`          | `string`, `number`                              | none      | A CSS height, or a number of px.                                               |
| `children`        | node, or a function receiving `{ highlighted }` | none      | `highlighted` is `true` while files are dragged over the area.                 |
| `inputAttributes` | `input` props                                   | none      | Passed to the file input, such as `accept` and `multiple`; a drop honors both. |
| `style`           | StyleX styles                                   | none      | Replaces `className` and `style`.                                              |
