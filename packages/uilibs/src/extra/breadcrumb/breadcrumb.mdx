# Breadcrumb

A trail of links that shows where the page sits in the site.

Plain `nav`, `ol`, `li`, `a`, and `span` elements. Props not listed here pass through.

## Anatomy

```jsx
import {
  Breadcrumb,
  BreadcrumbEllipsis,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator
} from 'uilibs/extra/breadcrumb'

;<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href='…' />
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbEllipsis />
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage />
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

`BreadcrumbSeparator` is an `li` between items, not inside one, and shows a chevron unless it has children. `BreadcrumbEllipsis` is optional; `BreadcrumbPage` marks the current location with `aria-current="page"`.

## Props

Every part also takes `style`: StyleX styles that replace `className` and `style`. On `Breadcrumb` it lands on the `nav`.

### Breadcrumb

| Prop     | Values               | Default      | Note                                             |
| -------- | -------------------- | ------------ | ------------------------------------------------ |
| `color`  | `neutral`, `primary` | `neutral`    | The role of the links in every `BreadcrumbLink`. |
| `labels` | `{ breadcrumb }`     | `Breadcrumb` | Name of the `nav` landmark.                      |

### BreadcrumbEllipsis

| Prop     | Values     | Default | Note                                           |
| -------- | ---------- | ------- | ---------------------------------------------- |
| `labels` | `{ more }` | `More`  | Text for assistive technology on the ellipsis. |
