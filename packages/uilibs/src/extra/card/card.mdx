# Card

A surface that groups related content, with a header, content, and footer.

A plain `div`. Props not listed here pass through.

## Anatomy

```jsx
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle
} from 'uilibs/extra/card'

;<Card>
  <CardHeader>
    <CardTitle />
    <CardDescription />
    <CardAction />
  </CardHeader>
  <CardContent />
  <CardFooter />
</Card>
```

`CardAction` sits in `CardHeader` and is pinned to its top-right corner. `CardTitle` renders an `h3` and `CardDescription` a `p`.

## Props

Every part also takes `style`: StyleX styles that replace `className` and `style`.

### Card

| Prop       | Values     | Default | Note                                                                                   |
| ---------- | ---------- | ------- | -------------------------------------------------------------------------------------- |
| `size`     | `sm`, `md` | `md`    | Padding and gaps.                                                                      |
| `selected` | `boolean`  | `false` | A primary edge and `data-selected`. Name the choice for assistive technology yourself. |
| `raised`   | `boolean`  | `false` | Lifts the card with the raised shadow.                                                 |
