# Card

A surface that groups related content, with a header, a content area, and a footer.

## Import

```jsx
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle
} from 'uilibs/extra/card'
```

`Card` is built on Base UI [useRender](https://base-ui.com/react/utils/use-render), so `render` swaps its `div` for another element. The other parts are plain `div`, `h3`, and `p` elements. Props not listed here pass through.

## Anatomy

- **Card:** the root surface. It sets the size, the raised shadow, and the selected edge.
- **CardHeader:** a two-column grid that holds the title, the description, and the action.
- **CardTitle:** the heading, an `h3`.
- **CardDescription:** supporting text under the title, a `p`.
- **CardAction:** optional slot for a header control, pinned to the top-right corner of the header.
- **CardContent:** the main area. `flush` removes its inline padding for a table or an image that runs to the card's edge.
- **CardFooter:** the bottom row, for actions or metadata.

```jsx
<Card>
  <CardHeader>
    <CardTitle />
    <CardDescription />
    <CardAction />
  </CardHeader>
  <CardContent />
  <CardFooter />
</Card>
```

### Stretched link

A card that is one link: put a `Link` in the title and stretch its `::after` over the card, so a press anywhere follows it. The card is `position: relative` and shows the focus ring itself, because the link's own ring would hug only the text. Any other control in the card sits above the cover (`position: relative` and a `zIndex`) so it keeps its own press.

<Canvas of={Stories.StretchedLink} />

```jsx
const styles = stylex.create({
  card: {
    position: 'relative',
    outline: { default: 'none', ':has(a:focus-visible)': `${stroke.ring2} solid ${colors.foregroundPrimary}` }
  },
  stretch: { outline: 'none', '::after': { content: '""', inset: 0, position: 'absolute' } },
  above: { position: 'relative', zIndex: zIndex.raised }
})

<Card style={styles.card}>
  <CardHeader>
    <CardTitle>
      <Link href='/diagon-alley' color='inherit' variant='plain' style={styles.stretch}>Diagon Alley</Link>
    </CardTitle>
  </CardHeader>
  <CardFooter>
    <Button style={styles.above}>Save for later</Button>
  </CardFooter>
</Card>
```

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs).

### Card

| Prop       | Description                                                                                             |
| ---------- | ------------------------------------------------------------------------------------------------------- |
| `size`     | `small`, `medium` <br /> Padding and gaps. Default `medium`.                                            |
| `selected` | `boolean` <br /> Marks the card as chosen: a doubled primary edge and `data-selected`. Default `false`. |
| `raised`   | `boolean` <br /> Lifts the card with the raised shadow. Default `false`.                                |
| `render`   | `ReactElement`, function <br /> Swaps the `div` for another element, such as an `article`.              |

| Data attribute  | Description                                     |
| --------------- | ----------------------------------------------- |
| `data-selected` | Set by this library while `selected` is `true`. |

`CardContent` also takes `flush`, a `boolean` that removes its inline padding so a table or an image runs to the card's border. Default `false`.

## Caveats

- `selected` is visual only. Name the choice for assistive technology yourself, with a `role` and `aria-selected` or a control inside the card.
- `CardTitle` always renders an `h3`; the level cannot be changed through a prop.
- A data grid in a card uses `CardContent flush` with `dataGridCardEdge`: see [Data Grid](?path=/docs/data-grid-basics--docs).
- `CardAction` belongs inside `CardHeader`, which gives it the right-hand grid column.
- A stretched link makes the whole card one target. Do not nest a second link in it, and keep one link per card: two covers would fight over the same area.
