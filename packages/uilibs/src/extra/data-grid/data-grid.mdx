# Data Grid

A table for large, interactive data: sorting, filtering, paging, pinning, resizing, row and cell selection, spreadsheet editing, and drag reordering.

Built on TanStack Table and TanStack Virtual. You create the table with `useTable` and `dataGridFeatures`, pass it to every part as `table`, and the grid reads layout and messages from `DataGrid`. The grid never owns your data; every write goes back through a callback.

Parts that take a `table` prop need the same table instance you gave `DataGrid`. A `style` prop takes StyleX styles, replaces `className`, and is the only styling prop a part accepts.

## DataGrid

The root. It renders no element of its own; it publishes layout, messages, and callbacks to every part below it. `DataGridProvider` takes the same props plus a required `table`, without the defaults.

### Column meta

Set on `columnDef.meta` (`DataGridColumnMeta`).

| Key               | Values                                             | Default | Note                                                                        |
| ----------------- | -------------------------------------------------- | ------- | --------------------------------------------------------------------------- |
| `headerTitle`     | `string`                                           | none    | Header and visibility label; falls back to a string `header`, then the id.  |
| `headerStyle`     | StyleX styles                                      | none    | Extra styles for the header cell.                                           |
| `cellStyle`       | StyleX styles                                      | none    | Extra styles for the body cell.                                             |
| `skeleton`        | `ReactNode`                                        | none    | Cell content while loading.                                                 |
| `expandedContent` | `(row) => ReactNode`                               | none    | Detail panel shown when the row expands.                                    |
| `autoSize`        | `boolean`                                          | `false` | Absorbs free width under `columnsResizable` and reflows with the container. |
| `fillWidth`       | `boolean`                                          | `false` | Absorbs the free-space strip; one column per grid.                          |

## Hooks and helpers

- `useDataGrid`: reads the grid context (`props`, `recordCount`, `isLoading`, `i18n`) inside a `DataGrid`.
- `dataGridFeatures`: the TanStack feature bundle the grid renders against.
- `mergeDataGridI18n`: merges `i18n` overrides over the English defaults, one level deep.
- `getColumnHeaderLabel`: the label of a column from meta, a string header, or its id.
- `getDataGridCellSelectionCellAttrs`: the `td` attributes for a selectable cell.
- `toDataGridDomId`: turns a row or column id into a DOM-safe id.
- `getPinningStyles`: the sticky inline style for a pinned column.
- `getDataGridTreeIndentStyle`: the CSS variable that indents a tree row.
- `getDataGridScrollAreaViewport`: the scroll viewport that belongs to this grid.
- `getDataGridTableRowSections`, `getDataGridTableResolvedRows`: split rows into pinned and center sections.
- `getDataGridTableMergedHeaderGroups`: header groups with grouped placeholders merged.
- `hasDataGridTableRightPinnedColumns`: whether any column is pinned to the end.
- `parseDataGridClipboardText`, `serializeDataGridClipboardText`: tab-separated text to a grid of strings and back.
- `tileDataGridClipboardBlock`: repeats a clipboard block to fill a region.
- `buildDataGridPasteDetails`, `buildDataGridClearDetails`: turn the selection into an `onCellsChange` batch.
- `invertDataGridCellsChange`: swaps a batch's values to implement undo and redo.
- `getDataGridActiveRegionGrid`, `getDataGridVisibleSelectedCellCount`: the active selection as formatted strings, and its visible cell count.
