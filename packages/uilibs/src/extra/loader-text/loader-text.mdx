# LoaderText

A line of text with a shimmer while work is in progress. When the work completes, it can cross-fade to a second line.

Renders this library's `Text`. It takes only the props below; others do not pass through.

## Anatomy

```jsx
import { LoaderText } from 'uilibs/extra/loader-text'

;<LoaderText>Text</LoaderText>
```

With `icon`, the glyph sits before the text. Without `completedText`, `completed` only stops the shimmer. With it, both texts stay mounted and cross-fade.

## Props

### LoaderText

| Prop            | Values                                                                                                                                            | Default  | Note                                                              |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | ----------------------------------------------------------------- |
| `children`      | node                                                                                                                                              | none     | The text while loading.                                           |
| `variant`       | `headline-1`, `headline-2`, `headline-3`, `featured-1` to `featured-6`, `body-1`, `body-2`, `caption-1`, `caption-2`, or one value per breakpoint | `body-2` | Type style, as in `Text`.                                         |
| `weight`        | `light`, `regular`, `medium`, `semibold`, `bold`, `extrabold`, `black`, or one value per breakpoint                                               | none     | Font weight, as in `Text`.                                        |
| `color`         | `neutral`, `neutral-faded`, `positive`, `warning`, `critical`, `primary`, `disabled`                                                              | none     | Text color, as in `Text`.                                         |
| `icon`          | glyph component                                                                                                                                   | none     | A glyph before the text, sized to the text.                       |
| `completedText` | node                                                                                                                                              | none     | Text that cross-fades with `children` once `completed` is `true`. |
| `completed`     | `boolean`                                                                                                                                         | `false`  | Stops the shimmer.                                                |
| `style`         | StyleX styles                                                                                                                                     | none     | Replaces `className` and `style`.                                 |
