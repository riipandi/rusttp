# Input Password

A password input with a button that shows or hides the value.

Built on `InputGroup`: its other props pass to the inner `InputGroupInput`, except `type`, which the toggle controls. `autoComplete` defaults to `new-password`.

## InputPassword

| Prop              | Values                                  | Default                          | Note                                                          |
| ----------------- | --------------------------------------- | -------------------------------- | ------------------------------------------------------------- |
| `size`            | `sm`, `md`, `lg`                        | `md`                             | Control height and type, set on the group.                    |
| `variant`         | `outline`, `faded`, `ghost`, `headless` | `outline`                        | The box, set on the group.                                    |
| `visible`         | `boolean`                               | none                             | Makes the visibility controlled.                              |
| `defaultVisible`  | `boolean`                               | `false`                          | Initial visibility when uncontrolled.                         |
| `onVisibleChange` | `(visible: boolean) => void`            | none                             | Called when the toggle is pressed.                            |
| `showIcon`        | node                                    | an eye icon                      | Shown while the value is hidden.                              |
| `hideIcon`        | node                                    | a slashed eye icon               | Shown while the value is visible.                             |
| `labels`          | `{ show, hide }`                        | `Show password`, `Hide password` | Names of the toggle in each state.                            |
| `toggleVariant`   | `solid`, `faded`, `outline`, `ghost`    | `ghost`                          | The toggle button's fill.                                     |
| `toggleSize`      | `xs`, `icon-xs`, `icon-sm`              | `icon-xs`                        | The toggle button's size.                                     |
| `style`           | StyleX styles                           | none                             | Styles the group; replaces the `className` and `style` props. |
