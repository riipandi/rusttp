# Input Password

A password input with a button that shows or hides the value.

## Import

```jsx
import { InputPassword } from 'uilibs/extra/input-password'
```

Built on the library's `InputGroup`. Props not listed here pass to the inner `InputGroupInput`, except `type`, which the toggle controls.

## Anatomy

- **InputPassword:** a single component. It renders the group, the input, and the toggle button in an end addon, so there are no parts to assemble.

```jsx
<InputPassword />
```

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs). On `InputPassword` it styles the group, not the input.

### InputPassword

| Prop              | Description                                                                                                      |
| ----------------- | ---------------------------------------------------------------------------------------------------------------- |
| `size`            | `sm`, `md`, `lg` <br /> Control height and type, set on the group. Default `md`.                                 |
| `variant`         | `outline`, `faded`, `ghost`, `headless` <br /> The box, set on the group. Default `outline`.                     |
| `visible`         | `boolean` <br /> Makes the visibility controlled.                                                                |
| `defaultVisible`  | `boolean` <br /> Initial visibility when uncontrolled. Default `false`.                                          |
| `onVisibleChange` | `(visible: boolean) => void` <br /> Called when the toggle is pressed.                                           |
| `showIcon`        | `ReactNode` <br /> Shown on the toggle while the value is hidden. Default an eye icon.                           |
| `hideIcon`        | `ReactNode` <br /> Shown on the toggle while the value is visible. Default a slashed eye icon.                   |
| `labels`          | `{ show, hide }` <br /> The toggle's accessible name in each state. Default `Show password` and `Hide password`. |
| `toggleVariant`   | `solid`, `faded`, `outline`, `ghost` <br /> The toggle button's fill. Default `ghost`.                           |
| `toggleSize`      | `xs`, `icon-xs`, `icon-sm` <br /> The toggle button's size. Default `icon-xs`.                                   |

| Data attribute / ARIA | Description                                                                   |
| --------------------- | ----------------------------------------------------------------------------- |
| `aria-pressed`        | On the toggle button: `true` while the value is visible. Set by this library. |
| `data-disabled`       | On the input: present when it is disabled.                                    |
| `data-invalid`        | On the input: present when it is invalid, inside a `Field`.                   |
| `data-focused`        | On the input: present while it is focused.                                    |

## Caveats

- Name the input with a `Field` label or an `aria-label`; `labels` names only the toggle.
- With `visible` set, pressing the toggle only calls `onVisibleChange`; update `visible` yourself.
- `autoComplete` defaults to `new-password`. Pass `autoComplete='current-password'` on a sign-in form.
- `type` is not accepted.
