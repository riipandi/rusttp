# Text

Typography for body copy, captions, and headings.

Built on Base UI [useRender](https://base-ui.com/react/utils/use-render). Props not listed here pass through.

## Anatomy

```jsx
import { Text } from 'uilibs/extra/text'

;<Text>Text</Text>
```

`Text` renders a `div`. The `featured-1` to `featured-6` variants render `h1` to `h6`, and with a responsive `variant` the tag follows the largest breakpoint's value. Set `render` to use another element.

## Props

### Text

`variant`, `weight`, and `align` take one value for every viewport, or an object with the breakpoint keys `s`, `m`, `l`, and `xl`, mobile first.

| Prop         | Values                                                                                                                           | Default  | Note                                          |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------- | -------- | --------------------------------------------- |
| `variant`    | `headline-1`, `headline-2`, `headline-3`, `featured-1` to `featured-6`, `body-1`, `body-2`, `caption-1`, `caption-2`; responsive | `body-1` | Size and line height.                         |
| `color`      | `neutral`, `neutral-faded`, `positive`, `warning`, `critical`, `primary`, `disabled`                                             | none     | The text color; unset inherits.               |
| `weight`     | `light`, `regular`, `medium`, `semibold`, `bold`, `extrabold`, `black`; responsive                                               | none     | Overrides the weight of the variant.          |
| `align`      | `start`, `center`, `end`; responsive                                                                                             | none     | Text alignment.                               |
| `decoration` | `underline`, `line-through`                                                                                                      | none     | Text decoration.                              |
| `maxLines`   | `number`                                                                                                                         | none     | Clamps the text to this many lines.           |
| `wrap`       | `balance`, `nowrap`                                                                                                              | none     | Balances the lines or keeps them on one line. |
| `monospace`  | `boolean`                                                                                                                        | `false`  | Uses the monospace font.                      |
| `numeric`    | `boolean`                                                                                                                        | `false`  | Uses tabular figures.                         |
| `style`      | StyleX styles                                                                                                                    | none     | Replaces `className` and `style`.             |
