# Sheet

A Dialog that slides in from an edge of the screen; use Drawer for a swipe panel with snap points.

## Import

```jsx
import {
  Sheet,
  SheetClose,
  SheetContent,
  SheetDescription,
  SheetFooter,
  SheetHeader,
  SheetOverlay,
  SheetPortal,
  SheetTitle,
  SheetTrigger
} from 'uilibs/extra/sheet'
```

Built on Base UI [Dialog](https://base-ui.com/react/components/dialog). Props not listed here pass through. `Sheet`, `SheetTrigger`, `SheetClose`, and `SheetPortal` are the Dialog parts unchanged.

## Anatomy

- **Sheet:** the root. It holds the open state.
- **SheetTrigger:** the button that opens the sheet.
- **SheetContent:** the panel that slides in. It renders the portal, the overlay, and a close button itself.
- **SheetHeader:** a container for the title and description.
- **SheetTitle:** the sheet's heading.
- **SheetDescription:** a short description under the title.
- **SheetFooter:** a container for the actions.
- **SheetClose:** a button that closes the sheet.
- **SheetPortal** and **SheetOverlay:** the portal and the backdrop. They are exported only for custom compositions.

```jsx
<Sheet>
  <SheetTrigger />
  <SheetContent>
    <SheetHeader>
      <SheetTitle />
      <SheetDescription />
    </SheetHeader>
    <SheetFooter>
      <SheetClose />
    </SheetFooter>
  </SheetContent>
</Sheet>
```

### Sheet on phones, Dialog on desktop

`useIsMobile()` (the viewport is under 660px) picks the modal, so one trigger opens a Sheet from the bottom edge on a phone and a centered Dialog on a larger screen. Both modals are Base UI Dialogs, so focus, scroll lock, and Escape behave the same in either.

<Canvas of={Stories.ResponsiveModalRecipe} />

```jsx
import { Dialog, DialogContent, DialogDescription, DialogHeader, DialogTitle, DialogTrigger } from 'uilibs/base/dialog'
import { useIsMobile } from 'uilibs/hooks/use-media-query'

function ResponsiveModal() {
  const isMobile = useIsMobile()
  return isMobile ? (
    <Sheet>
      <SheetTrigger render={<Button variant='outline' />}>Open</SheetTrigger>
      <SheetContent side='bottom'>
        <SheetHeader>
          <SheetTitle>The Pensieve</SheetTitle>
          <SheetDescription>Lift a memory from your mind.</SheetDescription>
        </SheetHeader>
      </SheetContent>
    </Sheet>
  ) : (
    <Dialog>
      <DialogTrigger render={<Button variant='outline' />}>Open</DialogTrigger>
      <DialogContent>
        <DialogHeader>
          <DialogTitle>The Pensieve</DialogTitle>
          <DialogDescription>Lift a memory from your mind.</DialogDescription>
        </DialogHeader>
      </DialogContent>
    </Dialog>
  )
}
```

## Accessibility

The popup is a `dialog` named by `SheetTitle` and described by `SheetDescription`. Always render a `SheetTitle`: without it the sheet has no name. While it is open, the page behind it is inert, Tab stays inside the popup, and Escape closes it. The `Keyboard` story walks this path, and the `Open` story keeps the popup open so the accessibility check reads it.

| Key                     | Action                                                                                  |
| ----------------------- | --------------------------------------------------------------------------------------- |
| `Enter` or `Space`      | On `SheetTrigger`: opens the sheet. On `SheetClose`: closes it.                         |
| `Tab` and `Shift + Tab` | Moves focus between the controls inside the popup. It wraps and never leaves the popup. |
| `Escape`                | Closes the sheet and returns focus to the trigger.                                      |

- Focus moves to the first focusable control in the popup, in document order (a footer button when the header holds none), not to the built-in close button, which renders last.
- The built-in close button is named by `labels.close`. A `SheetClose` you render yourself needs visible text or an `aria-label`.
- Keyboard behavior is Base UI's [Dialog](https://base-ui.com/react/components/dialog), which `Sheet` is built on.

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs). On `SheetContent` it styles the popup.

### SheetTrigger

| Data attribute    | Description                           |
| ----------------- | ------------------------------------- |
| `data-popup-open` | Present while the sheet is open.      |
| `data-disabled`   | Present when the trigger is disabled. |

### SheetOverlay

| Prop             | Description                                                           |
| ---------------- | --------------------------------------------------------------------- |
| `blurredOverlay` | `boolean` <br /> Blurs the page behind the backdrop. Default `false`. |

| Data attribute        | Description                          |
| --------------------- | ------------------------------------ |
| `data-open`           | Present while the sheet is open.     |
| `data-closed`         | Present while the sheet is closed.   |
| `data-starting-style` | Present as the sheet begins to open. |
| `data-ending-style`   | Present as the sheet closes.         |

### SheetContent

| Prop              | Description                                                                                   |
| ----------------- | --------------------------------------------------------------------------------------------- |
| `side`            | `top`, `right`, `bottom`, `left` <br /> The edge the sheet slides in from. Default `right`.   |
| `blurredOverlay`  | `boolean` <br /> Blurs the page behind the backdrop. Default `false`.                         |
| `showCloseButton` | `boolean` <br /> Renders the built-in close button. Default `true`.                           |
| `labels`          | `{ close: string }` <br /> The accessible name of the built-in close button. Default `Close`. |

| Data attribute            | Description                                         |
| ------------------------- | --------------------------------------------------- |
| `data-open`               | Present while the sheet is open.                    |
| `data-closed`             | Present while the sheet is closed.                  |
| `data-starting-style`     | Present as the sheet begins to open.                |
| `data-ending-style`       | Present as the sheet closes.                        |
| `data-nested`             | Present when the sheet is nested in another dialog. |
| `data-nested-dialog-open` | Present when another dialog is open inside it.      |

| CSS variable       | Description                            |
| ------------------ | -------------------------------------- |
| `--nested-dialogs` | How many dialogs are nested inside it. |

### SheetClose

| Data attribute  | Description                          |
| --------------- | ------------------------------------ |
| `data-disabled` | Present when the button is disabled. |

## Caveats

- `SheetContent` already renders `SheetPortal` and `SheetOverlay`; do not wrap it in them.
- With `showCloseButton={false}`, give the sheet a `SheetClose`.
- `blurredOverlay` on `SheetContent` is forwarded to its overlay. Set it on `SheetOverlay` only in a custom composition.
- `useIsMobile()` is `false` until the browser reports the viewport, so a server-rendered page first draws the Dialog branch. Resizing across 660px while a modal is open swaps the modal and closes it: keep the open state outside `ResponsiveModal` if that matters.
