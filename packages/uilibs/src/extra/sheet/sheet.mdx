# Sheet

A Dialog that slides in from an edge of the screen and holds focus until it closes. Use Drawer for a swipe panel with snap points.

Built on Base UI [Dialog](https://base-ui.com/react/components/dialog). Props not listed here pass through. `Sheet`, `SheetTrigger`, `SheetClose`, and `SheetPortal` are the Dialog parts unchanged.

## Anatomy

```jsx
import {
  Sheet,
  SheetClose,
  SheetContent,
  SheetDescription,
  SheetFooter,
  SheetHeader,
  SheetTitle,
  SheetTrigger
} from 'uilibs/extra/sheet'

;<Sheet>
  <SheetTrigger />
  <SheetContent>
    <SheetHeader>
      <SheetTitle />
      <SheetDescription />
    </SheetHeader>
    <SheetFooter>
      <SheetClose />
    </SheetFooter>
  </SheetContent>
</Sheet>
```

`SheetContent` renders the portal, the overlay, and a close button. `SheetPortal` and `SheetOverlay` are exported only for custom compositions.

## Props

Every part also takes `style`: StyleX styles that replace `className` and `style`. On `SheetContent` it styles the popup.

### SheetContent

| Prop              | Values                           | Default | Note                                |
| ----------------- | -------------------------------- | ------- | ----------------------------------- |
| `side`            | `top`, `right`, `bottom`, `left` | `right` | The edge the sheet slides in from.  |
| `blurredOverlay`  | `boolean`                        | `false` | Blurs the page behind the backdrop. |
| `showCloseButton` | `boolean`                        | `true`  | Renders the built-in close button.  |
| `labels`          | `{ close }`                      | `Close` | Name of the built-in close button.  |

### SheetOverlay

| Prop             | Values    | Default | Note                                |
| ---------------- | --------- | ------- | ----------------------------------- |
| `blurredOverlay` | `boolean` | `false` | Blurs the page behind the backdrop. |
