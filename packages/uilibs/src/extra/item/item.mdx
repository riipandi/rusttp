# Item

A row with media, content, and actions; `ItemGroup` stacks several as a list. For multi-column records, use Table.

## Import

```jsx
import {
  Item,
  ItemActions,
  ItemContent,
  ItemDescription,
  ItemFooter,
  ItemGroup,
  ItemHeader,
  ItemMedia,
  ItemSeparator,
  ItemTitle
} from 'uilibs/extra/item'
```

Built on Base UI [useRender](https://base-ui.com/react/utils/use-render): `Item` renders a `div` and `render` swaps the element. The other parts render a `div`, except `ItemDescription` (`p`) and `ItemSeparator`, which is the library's `Separator`. Props not listed here pass through.

## Anatomy

- **ItemGroup:** optional. A `role="list"` column that stacks items.
- **Item:** one row. Inside a group it sits in a `div` with `role="listitem"`.
- **ItemHeader:** a full-width row at the top of the item.
- **ItemMedia:** an icon, an avatar, or an image at the start of the row.
- **ItemContent:** the text column.
- **ItemTitle:** the row's name.
- **ItemDescription:** a supporting line under the title, a `p`.
- **ItemActions:** buttons or other controls at the end of the row.
- **ItemFooter:** a full-width row at the bottom of the item.
- **ItemSeparator:** a line between items in a group.

```jsx
<ItemGroup>
  <Item>
    <ItemHeader />
    <ItemMedia />
    <ItemContent>
      <ItemTitle />
      <ItemDescription />
    </ItemContent>
    <ItemActions />
    <ItemFooter />
  </Item>
  <ItemSeparator />
</ItemGroup>
```

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs).

### Item

| Prop      | Description                                                                                                                       |
| --------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `variant` | `ghost`, `outline`, `faded` <br /> `ghost` is the bare row, `outline` adds an edge, `faded` a soft neutral fill. Default `ghost`. |
| `size`    | `xsmall`, `small`, `medium` <br /> Padding and gap: `xsmall` is the tightest, `medium` the most open. Default `medium`.           |

### ItemMedia

| Prop      | Description                                                                                           |
| --------- | ----------------------------------------------------------------------------------------------------- |
| `variant` | `default`, `icon`, `image` <br /> `icon` colors a glyph; `image` rounds a picture. Default `default`. |

## Caveats

- Outside an `ItemGroup`, an `Item` has no `listitem` role and no wrapper.
- Inside an `ItemGroup`, `Item` renders a `div` wrapper with the `listitem` role around the item, so `render` can swap in a link without losing its role.
- Inside a group, `ItemSeparator` drops its separator role so the list stays valid.
- `ItemHeader` and `ItemFooter` each take a full row, so place them first and last in the `Item`.
