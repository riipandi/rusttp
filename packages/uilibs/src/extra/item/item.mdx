# Item

A row for a list of things, with media, content, and actions. `ItemGroup` holds several.

`Item` renders a `div` through Base UI [useRender](https://base-ui.com/react/utils/use-render), so `render` swaps the element. The other parts render a `div`, except `ItemDescription`, which renders a `p`. Their other props pass through.

`ItemGroup`, `ItemContent`, `ItemTitle`, `ItemDescription`, `ItemActions`, `ItemHeader`, and `ItemFooter` take only `style` (StyleX styles that replace `className` and `style`).

`ItemSeparator` is `Separator` unchanged; inside an `ItemGroup` it drops its separator role so the list stays valid.

## Item

| Prop      | Values                      | Default | Note                                                                          |
| --------- | --------------------------- | ------- | ----------------------------------------------------------------------------- |
| `variant` | `ghost`, `outline`, `faded` | `ghost` | `ghost` is the bare row, `outline` adds an edge, `faded` a soft neutral fill. |
| `size`    | `xs`, `sm`, `md`            | `md`    | Padding and gap.                                                              |
| `style`   | StyleX styles               | none    | Replaces the `className` and `style` props.                                   |

## ItemMedia

| Prop      | Values                     | Default   | Note                                             |
| --------- | -------------------------- | --------- | ------------------------------------------------ |
| `variant` | `default`, `icon`, `image` | `default` | `icon` colors a glyph; `image` rounds a picture. |
| `style`   | StyleX styles              | none      | Replaces the `className` and `style` props.      |
