# Kanban

A board of columns whose items drag between columns and whose columns drag to reorder; for a single reorderable list use Sortable.

## Import

```jsx
import {
  Kanban,
  KanbanBoard,
  KanbanColumn,
  KanbanColumnContent,
  KanbanColumnHandle,
  KanbanItem,
  KanbanOverlay
} from 'uilibs/extra/kanban'
```

Built on [dnd-kit](https://docs.dndkit.com). Every part except `KanbanOverlay` renders a `div` through Base UI [useRender](https://base-ui.com/react/utils/use-render), so `render` swaps the element. Props not listed here pass through.

## Anatomy

- **Kanban:** the root. It holds the value and the drag state; you own the data and the board reports each change through `onValueChange`.
- **KanbanBoard:** the row of columns.
- **KanbanColumn:** one column. It can only be dragged by its handle.
- **KanbanColumnHandle:** the grab handle of a column. Optional, but without it the column cannot be dragged. It names itself from `labels.columnHandle`.
- **KanbanColumnContent:** the list of items in a column.
- **KanbanItem:** one item. The whole element is the drag surface.
- **KanbanOverlay:** optional ghost that follows the pointer. It portals into `document.body`.

```jsx
<Kanban value={…} onValueChange={…} getItemValue={…}>
  <KanbanBoard>
    <KanbanColumn value={…}>
      <KanbanColumnHandle />
      <KanbanColumnContent value={…}>
        <KanbanItem value={…} />
      </KanbanColumnContent>
    </KanbanColumn>
  </KanbanBoard>
  <KanbanOverlay />
</Kanban>
```

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. On `KanbanOverlay` it styles the ghost. See [Styling](?path=/docs/styling--docs).

### Kanban

| Prop              | Description                                                                                                                                                                                     |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `value`           | `Record<string, T[]>` <br /> The items of each column, keyed by column id. The key order is the column order. Required.                                                                         |
| `onValueChange`   | `(value) => void` <br /> Called with the new value as items and columns move. Required.                                                                                                         |
| `getItemValue`    | `(item) => string` <br /> The id of an item. Ids must be unique across every column. Required.                                                                                                  |
| `onMove`          | `(event: KanbanMoveEvent) => void` <br /> Takes over item moves: the board stops reordering items itself and reports the drop here.                                                             |
| `onValueCommit`   | `(value, meta: KanbanCommitMeta) => void` <br /> Called once after a drag that moved something, with the previous value. Not called for item moves while `onMove` is set.                       |
| `restoreOnCancel` | `boolean` <br /> Restores the value from the start of the drag when it is cancelled. Default `false`.                                                                                           |
| `onDragStart`     | `(event: DragStartEvent) => void` <br /> A dnd-kit event.                                                                                                                                       |
| `onDragEnd`       | `(event: DragEndEvent) => void` <br /> A dnd-kit event.                                                                                                                                         |
| `onDragCancel`    | `(event: DragCancelEvent) => void` <br /> A dnd-kit event.                                                                                                                                      |
| `accessibility`   | dnd-kit `accessibility` prop <br /> Overrides the announcements and instructions built from `labels`.                                                                                           |
| `modifiers`       | dnd-kit `Modifiers` <br /> Restricts or transforms the drag movement.                                                                                                                           |
| `labels`          | `Partial<{ columnHandle, instructions, pickedUp, movedOver, dropped, cancelled }>` <br /> The handle name and the screen reader texts. Defaults to English; `columnHandle` is `Reorder column`. |

| Data attribute  | Description                                                                        |
| --------------- | ---------------------------------------------------------------------------------- |
| `data-slot`     | Set by this library: `kanban`.                                                     |
| `data-dragging` | Set by this library: `true` while any item or column is dragged, absent otherwise. |

### KanbanColumn

| Prop       | Description                                                         |
| ---------- | ------------------------------------------------------------------- |
| `value`    | `string` <br /> The column id: a key of the root `value`. Required. |
| `disabled` | `boolean` <br /> Stops the column from being dragged.               |

| Data attribute  | Description                                                             |
| --------------- | ----------------------------------------------------------------------- |
| `data-slot`     | Set by this library: `kanban-column`.                                   |
| `data-value`    | Set by this library: the column id.                                     |
| `data-dragging` | Set by this library: `true` while this column is dragged, else `false`. |
| `data-disabled` | Set by this library: `true` when the column is disabled.                |

### KanbanColumnHandle

| Prop     | Description                                             |
| -------- | ------------------------------------------------------- |
| `cursor` | `boolean` <br /> Shows the grab cursor. Default `true`. |

| Data attribute  | Description                                                            |
| --------------- | ---------------------------------------------------------------------- |
| `data-slot`     | Set by this library: `kanban-column-handle`.                           |
| `data-dragging` | Set by this library: `true` while its column is dragged, else `false`. |
| `data-disabled` | Set by this library: `true` when its column is disabled.               |

### KanbanColumnContent

| Prop    | Description                                                                                  |
| ------- | -------------------------------------------------------------------------------------------- |
| `value` | `string` <br /> The column id. It throws when the root `value` has no such column. Required. |

| Data attribute | Description                                   |
| -------------- | --------------------------------------------- |
| `data-slot`    | Set by this library: `kanban-column-content`. |

### KanbanItem

| Prop       | Description                                                          |
| ---------- | -------------------------------------------------------------------- |
| `value`    | `string` <br /> The item id, as `getItemValue` returns it. Required. |
| `disabled` | `boolean` <br /> Stops the item from being dragged.                  |

| Data attribute  | Description                                                                                          |
| --------------- | ---------------------------------------------------------------------------------------------------- |
| `data-slot`     | Set by this library: `kanban-item`.                                                                  |
| `data-value`    | Set by this library: the item id.                                                                    |
| `data-dragging` | Set by this library: `true` while this item is dragged and on its copy in the overlay, else `false`. |
| `data-disabled` | Set by this library: `true` when the item is disabled.                                               |

### KanbanOverlay

| Prop       | Description                                                                                                                                  |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `children` | node, or `({ value, variant }) => node` <br /> What the ghost shows. The function receives the dragged id and `variant`, `column` or `item`. |
| `render`   | component type <br /> Passed to dnd-kit's `DragOverlay` with the other props.                                                                |

## Caveats

- Item ids must be unique across every column, or dragging misbehaves.
- `KanbanColumn` takes no drag listeners itself; a column without a `KanbanColumnHandle` cannot be dragged.
- `KanbanColumnContent` throws when its `value` is not a key of the root `value`.
- `KanbanOverlay` renders nothing on the server and during hydration.
- A column is announced by its `aria-label`, else its id; an item by its `aria-label` or text, never its id.
