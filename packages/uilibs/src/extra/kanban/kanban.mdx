# Kanban

A board of columns whose items and columns can be dragged to reorder. You own the data: the board reports each change through `onValueChange`.

Built on [dnd-kit](https://docs.dndkit.com). Parts render a `div` through Base UI [useRender](https://base-ui.com/react/utils/use-render), so `render` swaps the element. Their other props pass through.

## Anatomy

```jsx
import {
  Kanban,
  KanbanBoard,
  KanbanColumn,
  KanbanColumnContent,
  KanbanColumnHandle,
  KanbanItem,
  KanbanOverlay
} from 'uilibs/extra/kanban'

;<Kanban value={…} onValueChange={…} getItemValue={…}>
  <KanbanBoard>
    <KanbanColumn value={…}>
      <KanbanColumnHandle />
      <KanbanColumnContent value={…}>
        <KanbanItem value={…} />
      </KanbanColumnContent>
    </KanbanColumn>
  </KanbanBoard>
  <KanbanOverlay />
</Kanban>
```

`value` on a column and its content is a key of the root `value`; on an item it is the id `getItemValue` returns. A column can only be dragged by its `KanbanColumnHandle`, and the whole `KanbanItem` is its own drag surface. `KanbanOverlay` is optional and portals the ghost into `document.body`.

## Props

Every part also takes `style`: StyleX styles that replace `className` and `style`. On `KanbanOverlay` it styles the ghost.

### Kanban

| Prop              | Values                                                                    | Default                        | Note                                                                                                                       |
| ----------------- | ------------------------------------------------------------------------- | ------------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| `value`           | `Record<string, T[]>`                                                     | required                       | The items of each column, keyed by column id. The key order is the column order.                                           |
| `onValueChange`   | `(value) => void`                                                         | required                       | Called with the new value as items and columns move.                                                                       |
| `getItemValue`    | `(item) => string`                                                        | required                       | The id of an item. Ids must be unique across every column.                                                                 |
| `children`        | node                                                                      | required                       | The board and the overlay.                                                                                                 |
| `onMove`          | `(event: KanbanMoveEvent) => void`                                        | none                           | Takes over item moves: the board no longer reorders items itself and reports the drop here.                                |
| `onValueCommit`   | `(value, meta: KanbanCommitMeta) => void`                                 | none                           | Called once after a drag that changed the order, with the previous value.                                                  |
| `restoreOnCancel` | `boolean`                                                                 | `false`                        | Restores the value from the start of the drag when it is cancelled.                                                        |
| `onDragStart`     | `(event: DragStartEvent) => void`                                         | none                           | A dnd-kit event.                                                                                                           |
| `onDragEnd`       | `(event: DragEndEvent) => void`                                           | none                           | A dnd-kit event.                                                                                                           |
| `onDragCancel`    | `(event: DragCancelEvent) => void`                                        | none                           | A dnd-kit event.                                                                                                           |
| `accessibility`   | dnd-kit `accessibility` prop                                              | none                           | Overrides the announcements and instructions built from `labels`.                                                          |
| `modifiers`       | dnd-kit `Modifiers`                                                       | none                           | Restricts or transforms the drag movement.                                                                                 |
| `labels`          | `{ columnHandle, instructions, pickedUp, movedOver, dropped, cancelled }` | English text, `Reorder column` | Name of the column handle and the screen reader announcements. An item is named by its `aria-label` or text, never its id. |

### KanbanColumn

| Prop       | Values    | Default  | Note                                      |
| ---------- | --------- | -------- | ----------------------------------------- |
| `value`    | `string`  | required | The column id: a key of the root `value`. |
| `disabled` | `boolean` | `false`  | Stops the column from being dragged.      |

### KanbanColumnHandle

| Prop     | Values    | Default | Note                   |
| -------- | --------- | ------- | ---------------------- |
| `cursor` | `boolean` | `true`  | Shows the grab cursor. |

### KanbanColumnContent

| Prop    | Values   | Default  | Note                                                               |
| ------- | -------- | -------- | ------------------------------------------------------------------ |
| `value` | `string` | required | The column id. It throws when the root `value` has no such column. |

### KanbanItem

| Prop       | Values    | Default  | Note                                       |
| ---------- | --------- | -------- | ------------------------------------------ |
| `value`    | `string`  | required | The item id, as `getItemValue` returns it. |
| `disabled` | `boolean` | `false`  | Stops the item from being dragged.         |

### KanbanOverlay

| Prop       | Values                                                                        | Default | Note                                                        |
| ---------- | ----------------------------------------------------------------------------- | ------- | ----------------------------------------------------------- |
| `children` | node, or `({ value, variant }) => node` where `variant` is `column` or `item` | none    | What the ghost shows. The function receives the dragged id. |
| `render`   | component type                                                                | none    | Passed to dnd-kit's `DragOverlay` with the other props.     |
