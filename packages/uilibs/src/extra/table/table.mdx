# Table

A data table in a scrollable, focusable region. For single-column rows, use Item instead.

Built on the native table elements (`table`, `thead`, `tbody`, `tfoot`, `tr`, `th`, `td`, `caption`). Props not listed here pass through.

## Anatomy

```jsx
import {
  Table,
  TableBody,
  TableCaption,
  TableCell,
  TableFooter,
  TableHead,
  TableHeader,
  TableRow
} from 'uilibs/extra/table'

;<Table>
  <TableCaption />
  <TableHeader>
    <TableRow>
      <TableHead />
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell />
    </TableRow>
  </TableBody>
  <TableFooter>
    <TableRow>
      <TableCell />
    </TableRow>
  </TableFooter>
</Table>
```

`Table` renders the `div` with `role="region"` that scrolls sideways and takes focus; the `table` sits inside it. Header, footer, and caption are optional. Keep the native nesting: rows go in a header, body, or footer, and cells in rows.

## Props

Every part also takes `style`: StyleX styles that replace `className` and `style`. On `Table` it styles the `table`; the region's `style` is not exposed.

### Table

| Prop           | Values       | Default | Note                                                                                           |
| -------------- | ------------ | ------- | ---------------------------------------------------------------------------------------------- |
| `border`       | `boolean`    | `false` | Draws an edge around the table, with rounded corners.                                          |
| `columnBorder` | `boolean`    | `false` | Draws an edge between the columns.                                                             |
| `labels`       | `{ region }` | `Table` | Name of the scroll region. Set it, or add a `TableCaption`, so the table says which one it is. |

### TableRow

| Prop          | Values    | Default | Note                                                                                    |
| ------------- | --------- | ------- | --------------------------------------------------------------------------------------- |
| `highlighted` | `boolean` | `false` | Tints the row. Visual only: pair it with `aria-selected` where the table is selectable. |

### TableHead and TableCell

Both take the same added props. They replace the native `align` and `width` attributes.

| Prop            | Values                                                       | Default            | Note                                 |
| --------------- | ------------------------------------------------------------ | ------------------ | ------------------------------------ |
| `align`         | `start`, `center`, `end`                                     | the cell's default | Horizontal alignment of the content. |
| `verticalAlign` | `start`, `center`, `end`                                     | the cell's default | Vertical alignment of the content.   |
| `width`         | a count of `unit` steps (`0` to `20`) or a CSS length string | none               | Column width.                        |
| `minWidth`      | a count of `unit` steps (`0` to `20`)                        | none               | Minimum column width.                |
