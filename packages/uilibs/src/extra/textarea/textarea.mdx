# Textarea

A multiline text control; inside a `Field` it takes the label, description, error, and invalid state.

## Import

```jsx
import { Field, FieldDescription, FieldError, FieldLabel } from 'uilibs/base/field'
import { Textarea } from 'uilibs/extra/textarea'
```

Built on Base UI [Field](https://base-ui.com/react/components/field) `Field.Control`, rendered as a `textarea`. Props not listed here pass through.

## Anatomy

- **Textarea:** the `textarea`. It is the `Field` control, so it works alone or inside a `Field`.
- **Field**, **FieldLabel**, **FieldDescription**, **FieldError:** the optional `Field` parts around it, from `uilibs/base/field`.

```jsx
<Field>
  <FieldLabel />
  <Textarea />
  <FieldDescription />
  <FieldError />
</Field>
```

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs).

### Textarea

| Prop         | Description                                                                                                      |
| ------------ | ---------------------------------------------------------------------------------------------------------------- |
| `size`       | `sm`, `md`, `lg` <br /> The minimum height (56, 64, or 72px) and the type. Default `md`.                         |
| `variant`    | `outline`, `faded`, `ghost`, `headless` <br /> The box. Default `outline`.                                       |
| `autoResize` | `boolean` <br /> Grows with its content instead of a fixed height, and drops the resize handle. Default `false`. |

| Data attribute  | Description                              |
| --------------- | ---------------------------------------- |
| `data-disabled` | Present when the field is disabled.      |
| `data-invalid`  | Present when the field is invalid.       |
| `data-valid`    | Present when the field is valid.         |
| `data-touched`  | Present once the field has been touched. |
| `data-dirty`    | Present once the value has changed.      |
| `data-filled`   | Present while the field has a value.     |
| `data-focused`  | Present while the textarea has focus.    |

## Caveats

- Outside a `Field`, name the textarea with `aria-label`.
- `Textarea` has no `invalid` prop. Set `invalid` on the `Field`, or let its validation set it.
- `autoResize` writes an inline `height` from the content, so a height in `style` does not apply.
- `autoResize` measures on mount and on typing only. A `value` set from outside does not re-measure.
- `faded`, `ghost`, and `headless` have no visible edge at rest, so give the textarea a visible label.
