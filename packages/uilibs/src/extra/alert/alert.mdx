# Alert

An inline notice with an optional glyph, title, description, and action.

## Import

```jsx
import { Alert, AlertAction, AlertDescription, AlertTitle } from 'uilibs/extra/alert'
```

Plain `div` and heading elements, not built on Base UI. Props not listed here pass through.

## Anatomy

- **Alert:** the root. It is a polite live region (`role='status'`) and draws the optional glyph.
- **AlertTitle:** the heading, an `h5` unless `level` says otherwise.
- **AlertDescription:** the body text.
- **AlertAction:** optional slot for a dismiss or undo control, pinned to the top-right corner. It must be a direct child of `Alert`.

```jsx
<Alert>
  <AlertTitle />
  <AlertDescription />
  <AlertAction />
</Alert>
```

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs).

### Alert

| Prop     | Description                                                                                                                                                                                           |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `color`  | `neutral`, `primary`, `positive`, `warning`, `critical` <br /> The role of the notice. Default `neutral`.                                                                                             |
| `icon`   | glyph component <br /> A glyph before the text, in the role's color. The alert sizes it to 20 and hides it from assistive technology.                                                                 |
| `inline` | `boolean` <br /> Puts `AlertAction` on the row with the text; it wraps under the text when space is short. Default `false`.                                                                           |
| `bleed`  | `0`, `0.5`, `1`, `1.5`, `2` to `10`, `12`, `14`, `16`, `18`, `20` <br /> Runs the notice out past its parent's padding by this many `unit` steps, with square corners. `0` only drops the side edges. |

### AlertTitle

| Prop    | Description                                                                       |
| ------- | --------------------------------------------------------------------------------- |
| `level` | `1`, `2`, `3`, `4`, `5`, `6` <br /> The heading level, `h1` to `h6`. Default `5`. |

## Caveats

- The default `role='status'` is announced politely when the alert changes. Pass `role='alert'` for an error the user must act on at once, or `role={undefined}` for a notice that is static on load.
- `AlertAction` must be a direct child of `Alert`: `inline` moves only the actions it finds among the direct children.
- `AlertTitle` is a real heading, so set `level` to fit the page's outline.
