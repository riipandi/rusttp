# Alert

A notice with an optional glyph, title, description, and action.

A plain `div`. Props not listed here pass through.

## Anatomy

```jsx
import { Alert, AlertAction, AlertDescription, AlertTitle } from 'uilibs/extra/alert'

;<Alert>
  <AlertTitle />
  <AlertDescription />
  <AlertAction />
</Alert>
```

`AlertAction` must be a direct child of `Alert`. The root is a polite live region (`role="status"`): pass `role="alert"` for an error the user must act on at once, or `role={undefined}` for a notice that should not be announced.

## Props

Every part also takes `style`: StyleX styles that replace `className` and `style`.

### Alert

| Prop     | Values                                                            | Default   | Note                                                                                                                     |
| -------- | ----------------------------------------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------ |
| `color`  | `neutral`, `primary`, `positive`, `warning`, `critical`           | `neutral` | The role.                                                                                                                |
| `icon`   | glyph component                                                   | none      | A glyph before the text, in the role's color.                                                                            |
| `inline` | `boolean`                                                         | `false`   | Puts `AlertAction` on the row with the text; it wraps under the text when space is short.                                |
| `bleed`  | `0`, `0.5`, `1`, `1.5`, `2` to `10`, `12`, `14`, `16`, `18`, `20` | none      | Runs the notice past its parent's padding by this many `unit` steps, with square corners; `0` only drops the side edges. |

### AlertTitle

Renders a heading element.

| Prop    | Values                       | Default | Note                                                       |
| ------- | ---------------------------- | ------- | ---------------------------------------------------------- |
| `level` | `1`, `2`, `3`, `4`, `5`, `6` | `5`     | The heading level, `h1` to `h6`; match the page's outline. |
