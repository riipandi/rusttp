# Empty

A placeholder for a view with nothing to show, built from media, a title, a description, and actions.

Each part renders a `div`; its other props pass through.

`Empty`, `EmptyHeader`, `EmptyTitle`, `EmptyDescription`, and `EmptyContent` take only `style` (StyleX styles that replace `className` and `style`).

## EmptyMedia

| Prop      | Values            | Default   | Note                                             |
| --------- | ----------------- | --------- | ------------------------------------------------ |
| `variant` | `default`, `icon` | `default` | `icon` sets the glyph on a rounded neutral tile. |
| `style`   | StyleX styles     | none      | Replaces the `className` and `style` props.      |
