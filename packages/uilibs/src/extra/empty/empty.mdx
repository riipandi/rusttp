# Empty

A placeholder for a view with nothing to show: media, a title, a description, and actions.

## Import

```jsx
import {
  Empty,
  EmptyContent,
  EmptyDescription,
  EmptyHeader,
  EmptyMedia,
  EmptyTitle
} from 'uilibs/extra/empty'
```

Plain `div` elements, no Base UI parts. Props not listed here pass through.

## Anatomy

- **Empty:** the root, with a dashed edge.
- **EmptyHeader:** groups the media, title, and description.
- **EmptyMedia:** an icon, an avatar, or any other graphic.
- **EmptyTitle:** what is missing.
- **EmptyDescription:** a sentence of help under the title.
- **EmptyContent:** the actions, such as a `Button`.

```jsx
<Empty>
  <EmptyHeader>
    <EmptyMedia />
    <EmptyTitle />
    <EmptyDescription />
  </EmptyHeader>
  <EmptyContent />
</Empty>
```

Every part except `Empty` is optional.

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs).

### EmptyMedia

| Prop      | Description                                                                                    |
| --------- | ---------------------------------------------------------------------------------------------- |
| `variant` | `default`, `icon` <br /> `icon` puts the content on a rounded neutral tile. Default `default`. |

## Caveats

- `EmptyTitle` and `EmptyDescription` render a `div`, not a heading or a paragraph, so the title does not appear in the page outline.
