# Step Dots

A row of dots that shows where the user is in a few steps or slides. Pick it for a position in a sequence of known length, such as the slides of a [Carousel](?path=/docs/extra-components-carousel--docs) or an onboarding flow; for the completion of one task, use [Progress](?path=/docs/base-components-progress--docs).

## Import

```jsx
import { StepDots } from 'uilibs/extra/step-dots'
```

Built on Base UI [useRender](https://base-ui.com/react/utils/use-render): it renders a `div`, and `render` swaps the element. The active dot takes the fill of `Progress`, so a role looks alike in both. Props not listed here pass through.

## Anatomy

- **StepDots:** one `progressbar` whose value is the one-based position. It has no children.
- **Dot:** one per step. The active dot is stretched to a pill.

```jsx
<StepDots total={5} activeIndex={2} />
```

### Sizes

`small` dots are 6px and `medium` dots are 8px; the active dot is a pill of 16px or 24px.

## API reference

The indicator also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs).

### StepDots

| Prop          | Description                                                                                                                              |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `total`       | `number` <br /> How many dots there are. More than seven slide in a window.                                                              |
| `activeIndex` | `number` <br /> The index, from `0`, of the active dot; it is clamped to the row. Default `0`.                                           |
| `color`       | `neutral`, `primary`, `positive`, `warning`, `critical`, `media` <br /> The role of the active dot; `media` is white. Default `primary`. |
| `size`        | `small`, `medium` <br /> Dot size. Default `medium`.                                                                                     |
| `labels`      | `Partial<StepDotsLabels>` <br /> `name` (default "Progress") and `value(current, total)` (default "2 of 5"), the spoken value.           |
| `render`      | `ReactElement`, function <br /> Swaps the `div` for another element, such as a `span`.                                                   |

Data attributes: each dot carries `data-active` while it is the active one.

## Caveats

- It is output only: it is not a tablist and takes no focus or clicks. Put the control that moves the position beside it.
- The bar is named "Progress" unless you pass `aria-label` or `aria-labelledby`; name it by what it counts when a page has more than one.
- A color alone is not meaning: the active dot is also wider, so the position reads without telling the roles apart.
- The dots that are not active use `borderControl`, not the track color of `Progress`, so they stay visible against the page (3:1).
- Motion (the slide of a long row and the stretch of the pill) is off under `prefers-reduced-motion`.
