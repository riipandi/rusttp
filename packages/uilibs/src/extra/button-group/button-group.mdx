# Button Group

Fuses Buttons, Inputs, and similar controls into one segmented control.

A plain `div` with `role="group"`; `ButtonGroupSeparator` is the library's `Separator`. Props not listed here pass through.

## Anatomy

```jsx
import { ButtonGroup, ButtonGroupSeparator, ButtonGroupText } from 'uilibs/extra/button-group'
import { Button } from 'uilibs/base/button'

;<ButtonGroup>
  <ButtonGroupText />
  <ButtonGroupSeparator />
  <Button />
</ButtonGroup>
```

Every child must accept `style`, because the group passes position styles through it; a wrapper that does not, such as a menu root, is styled by hand. `ButtonGroupText` and `ButtonGroupSeparator` are optional, and filled Buttons get a divider without a separator.

## Props

Every part also takes `style`: StyleX styles that replace `className` and `style`.

### ButtonGroup

| Prop          | Values                   | Default      | Note                                     |
| ------------- | ------------------------ | ------------ | ---------------------------------------- |
| `orientation` | `horizontal`, `vertical` | `horizontal` | The direction the children are laid out. |

### ButtonGroupSeparator

Takes the `Separator` props, `color` and `inset` among them.

| Prop          | Values                   | Default    | Note                       |
| ------------- | ------------------------ | ---------- | -------------------------- |
| `orientation` | `horizontal`, `vertical` | `vertical` | The direction of the line. |
