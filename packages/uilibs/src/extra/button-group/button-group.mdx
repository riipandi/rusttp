# Button Group

Fuses Buttons, Inputs, and similar controls into one segmented control.

## Import

```jsx
import { ButtonGroup, ButtonGroupSeparator, ButtonGroupText } from 'uilibs/extra/button-group'
import { Button } from 'uilibs/base/button'
```

A plain `div` with `role='group'`, not built on Base UI; `ButtonGroupSeparator` is the library's `Separator`. Props not listed here pass through.

## Anatomy

- **ButtonGroup:** the root. It clones each element child to pass position styles through `style`.
- **ButtonGroupText:** optional static label, such as a prefix.
- **ButtonGroupSeparator:** optional divider between children. Filled Buttons get a divider without it.
- **Button:** any child control that accepts `style`, such as Button or Input.

```jsx
<ButtonGroup>
  <ButtonGroupText />
  <ButtonGroupSeparator />
  <Button />
</ButtonGroup>
```

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs).

### ButtonGroup

| Prop          | Description                                                                                    |
| ------------- | ---------------------------------------------------------------------------------------------- |
| `orientation` | `horizontal`, `vertical` <br /> The direction the children are laid out. Default `horizontal`. |

### ButtonGroupSeparator

It takes the `Separator` props, `color` and `inset` among them.

| Prop          | Description                                                                    |
| ------------- | ------------------------------------------------------------------------------ |
| `orientation` | `horizontal`, `vertical` <br /> The direction of the line. Default `vertical`. |

## Caveats

- Every child must accept `style`, because the group passes position styles through it. A wrapper that does not, such as a menu root, is styled by hand, as the Split story does for its trigger.
- A bordered child (outline Button, Input) shares its neighbour's edge; a filled Button (`solid` or `faded`) gets a divider instead.
- Fragments are opened up and text children are kept, but a Fragment's children currently get duplicate React keys and log a dev error (audit-00002 F-04, open).
- Give the group an `aria-label` when its purpose is not clear from the buttons.
