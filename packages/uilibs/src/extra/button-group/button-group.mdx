# Button Group

Fuses Buttons, Inputs, and similar controls into one segmented control. Every child must accept `style`; a wrapper that does not has to be styled by hand.

Renders a `div` with `role="group"`; its other props pass through.

`ButtonGroupText` renders a `div` and takes only `style` (StyleX styles that replace `className` and `style`).

## ButtonGroup

| Prop          | Values                   | Default      | Note                                        |
| ------------- | ------------------------ | ------------ | ------------------------------------------- |
| `orientation` | `horizontal`, `vertical` | `horizontal` | The direction the children are laid out.    |
| `style`       | StyleX styles            | none         | Replaces the `className` and `style` props. |

## ButtonGroupSeparator

A divider between children of a group. It is the library's `Separator` with another default `orientation`; its other props, `color` and `inset` among them, pass through.

| Prop          | Values                   | Default    | Note                                        |
| ------------- | ------------------------ | ---------- | ------------------------------------------- |
| `orientation` | `horizontal`, `vertical` | `vertical` | The direction of the line.                  |
| `style`       | StyleX styles            | none       | Replaces the `className` and `style` props. |
