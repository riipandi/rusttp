# Spinner

A busy indicator: a named `status` on its own, hidden from assistive technology inside a Button.

## Import

```jsx
import { Spinner } from 'uilibs/extra/spinner'
```

Draws Keyline `LoaderCircle`, an `svg`. Props not listed here pass through.

## Anatomy

- **Spinner:** the rotating glyph.

```jsx
<Spinner />
```

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs).

### Spinner

| Prop     | Description                                                                                                                                      |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `size`   | `sm`, `md`, `lg` <br /> The glyph size: 12px, 16px, or 20px. Default `md`.                                                                       |
| `color`  | `inherit`, `primary`, `positive`, `warning`, `critical` <br /> The role color; `inherit` draws in the surrounding text color. Default `inherit`. |
| `labels` | `{ loading: string }` <br /> The accessible name of a standalone spinner. Default `Loading`.                                                     |

## Caveats

- For a busy button, set `loading` on `Button` instead of placing a `Spinner` in it.
- Inside a Button the spinner gets `aria-hidden`, so `labels.loading` is not read there.
- Under `prefers-reduced-motion: reduce` the rotation slows from 1s to 3s; it does not stop.
