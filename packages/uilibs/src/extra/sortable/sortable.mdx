# Sortable

A list or grid whose items the user reorders by drag and drop, with the pointer, touch, or the keyboard.

Built on [dnd-kit](https://docs.dndkit.com). `Sortable`, `SortableItem`, and `SortableItemHandle` render a `div` through Base UI [useRender](https://base-ui.com/react/utils/use-render), so `render` swaps the element. Their other props pass through.

## Anatomy

```jsx
import { Sortable, SortableItem, SortableItemHandle } from 'uilibs/extra/sortable'

;<Sortable value={…} onValueChange={…} getItemValue={…}>
  <SortableItem value={…}>
    <SortableItemHandle />
  </SortableItem>
</Sortable>
```

`SortableItem` elements must be direct children of `Sortable`: the drag clone is found among them. Each `value` is an id `getItemValue` returns. Without a `SortableItemHandle` the whole item starts the drag; with one, the handle does and the item is only the row. `SortableOverlay` is optional and goes inside `Sortable` for a custom ghost. `SortableItemContext` is exported for custom handles.

## Props

Every part except `SortableOverlay` also takes `style`: StyleX styles that replace `className` and `style`.

### Sortable

The root owns the order: it calls `onValueChange` with the reordered array after a drop.

| Prop            | Values                                                                                                  | Default                                          | Note                                                                                  |
| --------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------- |
| `value`         | `T[]`                                                                                                   | required                                         | The items in their current order.                                                     |
| `onValueChange` | `(value: T[]) => void`                                                                                  | required                                         | Called with the reordered items after a drop.                                         |
| `getItemValue`  | `(item: T) => string`                                                                                   | required                                         | The id of an item. Ids must be unique.                                                |
| `children`      | `ReactNode`                                                                                             | required                                         | The `SortableItem` children, each with a `value` matching an id.                      |
| `strategy`      | `vertical`, `horizontal`, `grid`                                                                        | `vertical`                                       | How items move aside while one is dragged.                                            |
| `onMove`        | `(event: { event, activeIndex, overIndex }) => void`                                                    | none                                             | Takes over the reorder: when set, `onValueChange` and `onValueCommit` are not called. |
| `onValueCommit` | `(value: T[], meta: { event, activeIndex, overIndex, previousValue }) => void`                          | none                                             | Called after `onValueChange` with the move's details.                                 |
| `onDragStart`   | dnd-kit `DragStartEvent` handler                                                                        | none                                             | Called when a drag starts.                                                            |
| `onDragEnd`     | dnd-kit `DragEndEvent` handler                                                                          | none                                             | Called when a drag ends, before the reorder.                                          |
| `onDragCancel`  | dnd-kit `DragCancelEvent` handler                                                                       | none                                             | Called when a drag is cancelled.                                                      |
| `accessibility` | dnd-kit `DndContext` `accessibility` prop                                                               | none                                             | Overrides the screen reader texts that `labels` sets.                                 |
| `modifiers`     | dnd-kit `Modifiers`                                                                                     | none                                             | Restricts or transforms the drag movement.                                            |
| `labels`        | `{ instructions, pickedUp(name), movedOver(name, over), dropped(name, over), cancelled(name), handle }` | English sentences; `handle` is `Drag to reorder` | Screen reader texts and the name of the drag handle.                                  |

### SortableItem

| Prop       | Values    | Default  | Note                                    |
| ---------- | --------- | -------- | --------------------------------------- |
| `value`    | `string`  | required | The item's id, matching `getItemValue`. |
| `disabled` | `boolean` | none     | Keeps the item from being dragged.      |

### SortableItemHandle

| Prop     | Values    | Default | Note                                                 |
| -------- | --------- | ------- | ---------------------------------------------------- |
| `cursor` | `boolean` | `true`  | Shows the grabbing cursor while the item is dragged. |

### SortableOverlay

Renders custom ghost content for the dragged item in a portal. It takes the dnd-kit `DragOverlay` props except `style`; its other props pass through.

| Prop       | Values                                            | Default | Note                                                                   |
| ---------- | ------------------------------------------------- | ------- | ---------------------------------------------------------------------- |
| `children` | `ReactNode` or `(params: { value }) => ReactNode` | none    | The overlay content; the function receives the id of the dragged item. |
