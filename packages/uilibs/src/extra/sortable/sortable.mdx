# Sortable

A single list or grid whose items the user reorders by drag and drop, with the pointer, touch, or the keyboard; for columns of items that move between lists use Kanban.

## Import

```jsx
import {
  Sortable,
  SortableItem,
  SortableItemContext,
  SortableItemHandle,
  SortableOverlay
} from 'uilibs/extra/sortable'
```

Built on [dnd-kit](https://docs.dndkit.com). `Sortable`, `SortableItem`, and `SortableItemHandle` render a `div` through Base UI [useRender](https://base-ui.com/react/utils/use-render), so `render` swaps the element. Props not listed here pass through.

## Anatomy

- **Sortable:** the root. It owns the order and calls `onValueChange` with the reordered array after a drop. It renders a drag ghost of the dragged item itself.
- **SortableItem:** one row or tile. Its `value` is an id that `getItemValue` returns. It must be a direct child of `Sortable`.
- **SortableItemHandle:** optional grip inside an item. With one, only the handle starts the drag; without one the whole item does.
- **SortableOverlay:** optional custom ghost for the dragged item. It portals into `document.body`.
- **SortableItemContext:** React context with the item's drag state, exported for custom handles.

```jsx
<Sortable value={…} onValueChange={…} getItemValue={…}>
  <SortableItem value={…}>
    <SortableItemHandle />
  </SortableItem>
</Sortable>
```

## Accessibility

Without a `SortableItemHandle` the item is the drag control, a Tab stop that takes the keys below; with one, the handle is named `Reorder <name>` after its item (the Handle names example). Drags are announced by the item's name in the language `labels` give. The `Keyboard` and `KeyboardAnnouncements` stories drive a list.

| Key                    | Action                                                           |
| ---------------------- | ---------------------------------------------------------------- |
| `Tab`                  | Reaches the first item.                                          |
| `Space`                | Lifts the focused item, and drops it where it is.                |
| `ArrowUp`, `ArrowDown` | While lifted: move the item through the list. Focus stays on it. |
| `Escape`               | While lifted: cancels the drag and leaves the order unchanged.   |

- dnd-kit's own keyboard model and announcements are documented in its [accessibility guide](https://docs.dndkit.com/guides/accessibility).

## API reference

Every part except `SortableOverlay` also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs).

### Sortable

| Prop            | Description                                                                                                                                                                                                                                                       |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `value`         | `T[]` <br /> The items in their current order. Required.                                                                                                                                                                                                          |
| `onValueChange` | `(value: T[]) => void` <br /> Called with the reordered items after a drop. Required.                                                                                                                                                                             |
| `getItemValue`  | `(item: T) => string` <br /> The id of an item. Ids must be unique. Required.                                                                                                                                                                                     |
| `strategy`      | `vertical`, `horizontal`, `grid` <br /> How items move aside while one is dragged. Default `vertical`.                                                                                                                                                            |
| `onMove`        | `(event: { event, activeIndex, overIndex }) => void` <br /> Takes over the reorder: when set, `onValueChange` and `onValueCommit` are not called.                                                                                                                 |
| `onValueCommit` | `(value: T[], meta: { event, activeIndex, overIndex, previousValue }) => void` <br /> Called after `onValueChange` with the move's details.                                                                                                                       |
| `onDragStart`   | dnd-kit `DragStartEvent` handler <br /> Called when a drag starts.                                                                                                                                                                                                |
| `onDragEnd`     | dnd-kit `DragEndEvent` handler <br /> Called when a drag ends, before the reorder.                                                                                                                                                                                |
| `onDragCancel`  | dnd-kit `DragCancelEvent` handler <br /> Called when a drag is cancelled.                                                                                                                                                                                         |
| `accessibility` | dnd-kit `DndContext` `accessibility` prop <br /> Overrides the screen reader texts that `labels` sets.                                                                                                                                                            |
| `modifiers`     | dnd-kit `Modifiers` <br /> Restricts or transforms the drag movement.                                                                                                                                                                                             |
| `labels`        | `Partial<{ instructions, pickedUp(name), movedOver(name, over), dropped(name, over), cancelled(name), handle(name) }>` <br /> Screen reader texts and the handle's name. Defaults to English; `handle` is `Reorder <name>`, with the item's `aria-label` or text. |

| Data attribute  | Description                                                             |
| --------------- | ----------------------------------------------------------------------- |
| `data-slot`     | Set by this library: `sortable`.                                        |
| `data-dragging` | Set by this library: `true` while an item is dragged, absent otherwise. |

### SortableItem

| Prop       | Description                                                       |
| ---------- | ----------------------------------------------------------------- |
| `value`    | `string` <br /> The item's id, matching `getItemValue`. Required. |
| `disabled` | `boolean` <br /> Keeps the item from being dragged.               |

| Data attribute  | Description                                                                                         |
| --------------- | --------------------------------------------------------------------------------------------------- |
| `data-slot`     | Set by this library: `sortable-item`.                                                               |
| `data-value`    | Set by this library: the item's id.                                                                 |
| `data-dragging` | Set by this library: `true` while the item is dragged and on its copy in the overlay, else `false`. |
| `data-disabled` | Set by this library: `true` when the item is disabled.                                              |

### SortableItemHandle

| Prop     | Description                                                                           |
| -------- | ------------------------------------------------------------------------------------- |
| `cursor` | `boolean` <br /> Shows the grabbing cursor while the item is dragged. Default `true`. |

| Data attribute  | Description                                                          |
| --------------- | -------------------------------------------------------------------- |
| `data-slot`     | Set by this library: `sortable-item-handle`.                         |
| `data-dragging` | Set by this library: `true` while its item is dragged, else `false`. |
| `data-disabled` | Set by this library: `true` when its item is disabled.               |

### SortableOverlay

Takes the dnd-kit `DragOverlay` props except `style` and `className`; they pass through.

| Prop       | Description                                                                                                                     |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `children` | `ReactNode` or `(params: { value }) => ReactNode` <br /> The overlay content. The function receives the id of the dragged item. |

## Caveats

- `SortableItem` must be a direct child of `Sortable`: the drag ghost is cloned from the root's children.
- Item ids must be unique, or drag and drop misbehaves.
- Without a `SortableItemHandle` the whole item is the drag control, so it cannot hold a button, switch, or link of its own. Add a handle to free the item.
- An item is announced by its `aria-label` or text, never its id.
- `SortableOverlay` renders nothing on the server and during hydration.
