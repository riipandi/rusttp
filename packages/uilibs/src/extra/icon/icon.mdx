# Icon

Sizes and colors an SVG asset. It inherits the parent's text color unless `color` is set.

## Import

```jsx
import { Icon } from 'uilibs/extra/icon'
```

Built on Base UI [useRender](https://base-ui.com/react/utils/use-render): it renders a `span`, and `render` swaps the element. Props not listed here pass through.

## Anatomy

- **Icon:** the root `span` that wraps the SVG. It is `aria-hidden` unless `render` is set.

```jsx
<Icon svg={…} />
```

## Brand icons

`uilibs/icons` ships eight brand marks as ready SVG components: `FacebookIcon`, `GitHubIcon`, `GoogleIcon`, `InstagramIcon`, `LinkedInIcon`, `TelegramIcon`, `WhatsAppIcon`, and `XIcon`. They are not built on `Icon`: each takes `size` (a number of px, default `24`) and any SVG prop, fills with `currentColor`, and is an image named for the brand (`role='img'`, `aria-label='GitHub'`).

```jsx
import { GitHubIcon, GoogleIcon } from 'uilibs/icons'
```

<Canvas of={BrandStories.Gallery} />

Beside a visible label the icon is decoration, so pass `aria-hidden='true'` and let the text name the control. On its own, such as in an icon-only button or a footer link, keep the brand name.

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs). On `Icon` it styles the root `span`.

### Icon

| Prop        | Description                                                                                                                                                    |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `svg`       | SVG component, SVG element, or `null` <br /> The asset to draw, such as an icon from `@keyline-icons/react`. Required.                                         |
| `size`      | `number` or `string` <br /> A number is px; a string is any CSS size. Default `1em`.                                                                           |
| `color`     | `neutral`, `neutral-faded`, `primary`, `positive`, `warning`, `critical`, `disabled` <br /> A foreground token. Inherits the parent's text color when omitted. |
| `autoWidth` | `boolean` <br /> Uses the width of the SVG instead of a square box. Default `false`.                                                                           |

## Caveats

- The default `span` is `aria-hidden`, so an icon that carries meaning needs a text label beside it.
- With `render`, `aria-hidden` is not set and the rendered element owns its accessibility semantics, such as an `aria-label` on a link.
- `size` takes one value, not a responsive object. A number is px, not a multiple of a spacing token.
- The component overrides the `display`, `height`, and `width` set on the SVG itself.
