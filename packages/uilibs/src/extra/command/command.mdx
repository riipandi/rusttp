# Command

A command palette: a search field over a filtered list of actions, rendered in place with no popup. To pick a form value, use Select, Combobox, or Autocomplete.

Built on Base UI [Autocomplete](https://base-ui.com/react/components/autocomplete). `Command` sets `inline` and `open` itself, so it does not take them. Props not listed here pass through.

## Anatomy

```jsx
import {
  Command,
  CommandDialog,
  CommandEmpty,
  CommandGroup,
  CommandInput,
  CommandItem,
  CommandList,
  CommandShortcut
} from 'uilibs/extra/command'

<Command items={…}>
  <CommandInput />
  <CommandEmpty />
  <CommandList>
    {(group) => (
      <CommandGroup heading={…}>
        <CommandItem value={…}>
          <CommandShortcut />
        </CommandItem>
      </CommandGroup>
    )}
  </CommandList>
</Command>

<CommandDialog open={…} onOpenChange={…}>
  <Command items={…}>…</Command>
</CommandDialog>
```

`items` goes on `Command`, and `CommandList` takes a render function over the filtered items. A search matches `itemToStringValue`, so include any keywords there. For groups, pass group objects that each hold their own `items`, and put a `CommandSeparator` between the groups in the render function. `CommandDialog` has no trigger: control it with `open` and `onOpenChange`. It renders the dialog and a hidden title and description itself, with no close button.

## Props

Every part also takes `style`: StyleX styles that replace `className` and `style`. On `CommandInput` it styles the wrapper around the field, on `CommandList` the list inside the scroll area, and on `CommandDialog` the dialog content. `CommandShortcut` renders a `span`.

### CommandDialog

| Prop           | Values                          | Default                                           | Note                                                                               |
| -------------- | ------------------------------- | ------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `labels`       | `{ title, description }`        | `Command Palette`, `Search for a command to run…` | Name and description of the dialog, read but not shown.                            |
| `initialFocus` | `boolean`, a ref, or a function | the first focusable element                       | Where focus goes on open. Pass the container for a panel with no field to type in. |
| `finalFocus`   | `boolean`, a ref, or a function | the element that opened the dialog                | Where focus goes on close. `false` leaves it where it is.                          |

### CommandGroup

| Prop      | Values      | Default | Note               |
| --------- | ----------- | ------- | ------------------ |
| `heading` | `ReactNode` | none    | The group's label. |
