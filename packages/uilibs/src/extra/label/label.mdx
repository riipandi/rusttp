# Label

The caption of a form control used outside a `Field`; inside a `Field`, use `FieldLabel`.

## Import

```jsx
import { Label } from 'uilibs/extra/label'
```

A plain `label` element. Props not listed here pass through.

## Anatomy

- **Label:** the caption. It can wrap the control or point at it with `htmlFor`.

```jsx
<Label htmlFor='owl-name'>Owl name</Label>
```

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs).

## Caveats

- Without a wrapped control or an `htmlFor` that matches the control's `id`, the label names nothing.
- The text is `user-select: none`, so a visitor cannot select it.
