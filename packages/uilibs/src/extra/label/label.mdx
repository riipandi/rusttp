# Label

The caption of a form control, for use outside a `Field`. Inside a `Field`, use `FieldLabel`.

A plain `label` element. Props not listed here pass through.

## Anatomy

```jsx
import { Label } from 'uilibs/extra/label'

;<Label>Text</Label>
```

Wrap the control in the label, or set `htmlFor` to the control's `id`, so a click on the text reaches the control.

## Props

`Label` adds only `style`: StyleX styles that replace `className` and `style`.
