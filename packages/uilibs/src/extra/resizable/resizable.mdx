# Resizable

Panels that the user resizes by dragging the handle between them.

Built on [react-resizable-panels](https://github.com/bvaughn/react-resizable-panels). Props not listed here pass through.

## Anatomy

```jsx
import { ResizableHandle, ResizablePanel, ResizablePanelGroup } from 'uilibs/extra/resizable'

;<ResizablePanelGroup>
  <ResizablePanel />
  <ResizableHandle aria-label='…' />
  <ResizablePanel />
</ResizablePanelGroup>
```

A handle sits between two panels. It is a focusable separator, so name it with `aria-label`.

## Props

Every part also takes `style`: StyleX styles that replace `className` and `style`. On `ResizablePanel` it lands on an inner element, so padding never stops the panel from shrinking to zero. Add `overflow` there to scroll within the panel.

### ResizablePanelGroup

| Prop          | Values                   | Default      | Note                                                                     |
| ------------- | ------------------------ | ------------ | ------------------------------------------------------------------------ |
| `orientation` | `horizontal`, `vertical` | `horizontal` | The direction the panels flow. `horizontal` is a row with vertical bars. |

### ResizableHandle

| Prop         | Values                      | Default | Note                                                                      |
| ------------ | --------------------------- | ------- | ------------------------------------------------------------------------- |
| `variant`    | `pill`, `spring`, `capsule` | `pill`  | The look of the grip shown by `withHandle`; `capsule` also boxes the bar. |
| `withHandle` | `boolean`                   | `false` | Shows a grip on the bar.                                                  |
