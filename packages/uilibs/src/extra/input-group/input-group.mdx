# Input Group

An input or textarea with addons, buttons, and text inside one box.

Built on the library's `Input`, `Textarea`, and `Button`. The group is a `div` with `role="group"`. Props not listed here pass through.

## Anatomy

```jsx
import {
  InputGroup,
  InputGroupAddon,
  InputGroupButton,
  InputGroupInput,
  InputGroupText
} from 'uilibs/extra/input-group'

;<InputGroup>
  <InputGroupAddon>
    <InputGroupText />
  </InputGroupAddon>
  <InputGroupInput />
  <InputGroupAddon align='inline-end'>
    <InputGroupButton />
  </InputGroupAddon>
</InputGroup>
```

Use one `InputGroupInput` or `InputGroupTextarea` per group: clicking an addon focuses the first one. `align` places an addon with CSS `order`, so the DOM and focus order stay as written. `InputGroupInput`, `InputGroupTextarea`, and `InputGroupButton` take the props of `Input`, `Textarea`, and `Button`.

## Props

Every part also takes `style`: StyleX styles that replace `className` and `style`.

### InputGroup

| Prop      | Values                                  | Default   | Note                                                                 |
| --------- | --------------------------------------- | --------- | -------------------------------------------------------------------- |
| `size`    | `sm`, `md`, `lg`                        | `md`      | Height and type of the input; the input and textarea inside read it. |
| `variant` | `outline`, `faded`, `ghost`, `headless` | `outline` | The box.                                                             |

### InputGroupAddon

| Prop    | Values                                                   | Default        | Note                                                                                        |
| ------- | -------------------------------------------------------- | -------------- | ------------------------------------------------------------------------------------------- |
| `align` | `inline-start`, `inline-end`, `block-start`, `block-end` | `inline-start` | Which side of the input it sits on. Clicking it, but not a button in it, focuses the input. |

### InputGroupButton

| Prop      | Values                               | Default | Note                                                    |
| --------- | ------------------------------------ | ------- | ------------------------------------------------------- |
| `variant` | `solid`, `faded`, `outline`, `ghost` | `ghost` | The `Button` fill.                                      |
| `size`    | `xs`, `icon-xs`, `icon-sm`           | `xs`    | The `icon-*` sizes are square and need an `aria-label`. |

### InputGroupInput

| Prop   | Values           | Default          | Note                     |
| ------ | ---------------- | ---------------- | ------------------------ |
| `size` | `sm`, `md`, `lg` | the group's size | Control height and type. |

### InputGroupTextarea

| Prop   | Values           | Default          | Note                     |
| ------ | ---------------- | ---------------- | ------------------------ |
| `size` | `sm`, `md`, `lg` | the group's size | Minimum height and type. |
