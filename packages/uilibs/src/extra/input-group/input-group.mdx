# Input Group

An input or textarea with addons, buttons, and text inside one box.

## Import

```jsx
import {
  InputGroup,
  InputGroupAddon,
  InputGroupButton,
  InputGroupInput,
  InputGroupText,
  InputGroupTextarea
} from 'uilibs/extra/input-group'
```

Built on the library's `Input`, `Textarea`, and `Button`. The group is a `div` with `role="group"`. Props not listed here pass through.

## Anatomy

- **InputGroup:** the root. It draws the box and passes its `size` to the input or textarea inside.
- **InputGroupAddon:** a slot beside or above the field, for text, an icon, a button, or a spinner. Clicking it focuses the field.
- **InputGroupText:** a `span` of muted text, such as a prefix or a unit.
- **InputGroupButton:** a small `Button` for use inside an addon.
- **InputGroupInput:** the single-line field. It takes the props of `Input`.
- **InputGroupTextarea:** the multi-line field, used instead of `InputGroupInput`. It takes the props of `Textarea`.

```jsx
<InputGroup>
  <InputGroupAddon>
    <InputGroupText />
  </InputGroupAddon>
  <InputGroupInput />
  <InputGroupAddon align='inline-end'>
    <InputGroupButton />
  </InputGroupAddon>
</InputGroup>
```

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs).

### InputGroup

| Prop      | Description                                                                                   |
| --------- | --------------------------------------------------------------------------------------------- |
| `size`    | `sm`, `md`, `lg` <br /> Height and type; the input and textarea inside read it. Default `md`. |
| `variant` | `outline`, `faded`, `ghost`, `headless` <br /> The box. Default `outline`.                    |

### InputGroupAddon

| Prop    | Description                                                                                                                 |
| ------- | --------------------------------------------------------------------------------------------------------------------------- |
| `align` | `inline-start`, `inline-end`, `block-start`, `block-end` <br /> Which side of the field it sits on. Default `inline-start`. |

| Data attribute | Description                                                                                     |
| -------------- | ----------------------------------------------------------------------------------------------- |
| `data-align`   | The `align` value. Set by this library; the group reads it to switch to a column for `block-*`. |

### InputGroupButton

| Prop      | Description                                                                           |
| --------- | ------------------------------------------------------------------------------------- |
| `variant` | `solid`, `faded`, `outline`, `ghost` <br /> The `Button` fill. Default `ghost`.       |
| `size`    | `xs`, `sm` <br /> 24 px or 32 px tall. With no children it is a square. Default `xs`. |

### InputGroupInput

| Prop   | Description                                                                |
| ------ | -------------------------------------------------------------------------- |
| `size` | `sm`, `md`, `lg` <br /> Control height and type. Default the group's size. |

| Data attribute  | Description                         |
| --------------- | ----------------------------------- |
| `data-disabled` | Present when the input is disabled. |
| `data-invalid`  | Present when the input is invalid.  |
| `data-focused`  | Present while the input is focused. |
| `data-filled`   | Present when the input has a value. |

### InputGroupTextarea

| Prop   | Description                                                                |
| ------ | -------------------------------------------------------------------------- |
| `size` | `sm`, `md`, `lg` <br /> Minimum height and type. Default the group's size. |

## Caveats

- Use one `InputGroupInput` or `InputGroupTextarea` per group: clicking an addon focuses the first one.
- Clicking a button inside an addon does not move focus to the field.
- `align` places an addon with CSS `order`, so the DOM and focus order stay as written.
- A button with no children is a square and needs an `aria-label`; give its glyph as `icon`.
- Name the field with a `Field` label or an `aria-label`; the group itself has no name.
- The group reflects an invalid input with `:has()`, so put the input inside a `Field` to get `data-invalid`.
