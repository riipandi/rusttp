# Skeleton

A placeholder block shown while content loads.

A plain `div`. Props not listed here pass through.

## Anatomy

```jsx
import { Skeleton } from 'uilibs/extra/skeleton'

;<Skeleton />
```

It has no children. Build the shape of the content from several blocks, sized with `width` and `height`.

## Props

### Skeleton

| Prop           | Values                                                         | Default  | Note                                                                    |
| -------------- | -------------------------------------------------------------- | -------- | ----------------------------------------------------------------------- |
| `width`        | a count of `unit` steps (`0` to `20`) or a CSS length string   | none     | One step is 4px, so `12` is 48px. Unset leaves the width to the layout. |
| `height`       | a count of `unit` steps (`0` to `20`) or a CSS length string   | none     | One step is 4px. Unset leaves the height to the layout.                 |
| `borderRadius` | `xsmall`, `small`, `medium`, `large`, `xlarge`, `full`, `none` | `medium` | A corner radius token; `full` suits an avatar.                          |
| `style`        | StyleX styles                                                  | none     | Replaces `className` and `style`.                                       |
