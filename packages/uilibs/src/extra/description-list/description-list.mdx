# DescriptionList

Key-value rows in a definition list, separated by hairlines.

Built on Base UI [useRender](https://base-ui.com/react/utils/use-render): the parts render `dl`, `dt`, and `dd`, and `render` swaps the element. Props not listed here pass through.

## Anatomy

```jsx
import { DescriptionDetails, DescriptionList, DescriptionTerm } from 'uilibs/extra/description-list'

;<DescriptionList>
  <DescriptionTerm />
  <DescriptionDetails />
</DescriptionList>
```

Terms and details are direct children of the list, one pair per row, so the grid and separators line up. `DescriptionTerm` is the muted key and `DescriptionDetails` the emphasized value.

## Props

No part adds props beyond `style`: StyleX styles that replace `className` and `style`.
