# DescriptionList

Key-value rows in a definition list, separated by hairlines.

## Import

```jsx
import { DescriptionDetails, DescriptionList, DescriptionTerm } from 'uilibs/extra/description-list'
```

Built on Base UI [useRender](https://base-ui.com/react/utils/use-render): the parts render `dl`, `dt`, and `dd`, and `render` swaps the element. Props not listed here pass through.

## Anatomy

- **DescriptionList:** the root `dl`. Each term and details pair takes one grid row.
- **DescriptionTerm:** the muted key, a `dt`.
- **DescriptionDetails:** the emphasized value, a `dd`.

```jsx
<DescriptionList>
  <DescriptionTerm />
  <DescriptionDetails />
</DescriptionList>
```

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs). No part adds props or data attributes.

## Caveats

- The list is a native `dl`, so a screen reader announces term and details as a pair; nothing is added to it.
- Terms and details must be direct children of the list, or the grid layout and the separators do not line up.
