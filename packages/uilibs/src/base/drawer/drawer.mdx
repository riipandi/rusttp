# Drawer

A touch-first panel that slides in from an edge and closes by swipe. Use Sheet for a navigation or settings panel.

Built on Base UI [Drawer](https://base-ui.com/react/components/drawer). Props not listed here pass through.

## Anatomy

```jsx
import {
  Drawer,
  DrawerClose,
  DrawerContent,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger
} from 'uilibs/base/drawer'

;<Drawer>
  <DrawerTrigger />
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle />
      <DrawerDescription />
    </DrawerHeader>
    <DrawerFooter>
      <DrawerClose />
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```

`DrawerContent` renders the portal, the overlay (only while `modal`), the viewport, the popup, and the swipe handle (when `showSwipeHandle` is set). `DrawerPortal`, `DrawerOverlay`, and `DrawerSwipeHandle` are exported only for custom compositions.

## Props

Every part except `Drawer`, `DrawerTrigger`, `DrawerClose`, and `DrawerPortal` also takes `style`: StyleX styles that replace `className` and `style`. On `DrawerContent` it styles the popup.

### Drawer

`modal` defaults to `true` and `swipeDirection` to `down`. The parts read both: `DrawerContent` docks to the edge the swipe direction names.

| Prop              | Values    | Default | Note                                                        |
| ----------------- | --------- | ------- | ----------------------------------------------------------- |
| `showSwipeHandle` | `boolean` | `false` | Shows a grab handle on the popup, on the side of the swipe. |
