# Drawer

A touch-first panel that slides in from an edge and closes by swipe. Use Sheet for a navigation or settings panel.

## Import

```jsx
import {
  Drawer,
  DrawerClose,
  DrawerContent,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerOverlay,
  DrawerPortal,
  DrawerSwipeHandle,
  DrawerTitle,
  DrawerTrigger
} from 'uilibs/base/drawer'
```

Built on Base UI [Drawer](https://base-ui.com/react/components/drawer). Props not listed here pass through.

## Anatomy

- **Drawer:** the root. It holds the open state and the swipe direction that the other parts read.
- **DrawerTrigger:** the button that opens the drawer.
- **DrawerContent:** the panel. It renders the portal, the overlay (only while `modal`), the viewport, the popup, and the swipe handle (when `showSwipeHandle` is set) itself.
- **DrawerHeader:** groups the title and description.
- **DrawerTitle:** the drawer's name.
- **DrawerDescription:** supporting text.
- **DrawerFooter:** holds the buttons.
- **DrawerClose:** a button that closes the drawer.
- **DrawerPortal**, **DrawerOverlay**, **DrawerSwipeHandle:** exported only for custom compositions. `DrawerContent` already includes them.

```jsx
<Drawer>
  <DrawerTrigger />
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle />
      <DrawerDescription />
    </DrawerHeader>
    <DrawerFooter>
      <DrawerClose />
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```

## API reference

Every part except `Drawer`, `DrawerTrigger`, `DrawerClose`, and `DrawerPortal` also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs). On `DrawerContent` it styles the popup.

### Drawer

`DrawerContent` docks to the edge the swipe direction names.

| Prop              | Description                                                                                                                   |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `swipeDirection`  | `up`, `right`, `down`, `left` <br /> The direction a swipe dismisses the drawer, and so the edge it docks to. Default `down`. |
| `modal`           | `boolean` <br /> Whether the page behind is locked. The overlay shows only when this is `true`. Default `true`.               |
| `showSwipeHandle` | `boolean` <br /> Shows a grab handle on the popup, on the side of the swipe. Default `false`.                                 |

### DrawerTrigger

| Data attribute    | Description                           |
| ----------------- | ------------------------------------- |
| `data-popup-open` | Present while the drawer is open.     |
| `data-disabled`   | Present when the trigger is disabled. |

### DrawerOverlay

| Data attribute        | Description                           |
| --------------------- | ------------------------------------- |
| `data-open`           | Present while the drawer is open.     |
| `data-closed`         | Present while the drawer is closed.   |
| `data-starting-style` | Present as the drawer begins to open. |
| `data-ending-style`   | Present as the drawer closes.         |

| CSS variable              | Description                                            |
| ------------------------- | ------------------------------------------------------ |
| `--drawer-swipe-progress` | How far the swipe has gone. The overlay fades with it. |

### DrawerContent

| Data attribute            | Description                                                                 |
| ------------------------- | --------------------------------------------------------------------------- |
| `data-open`               | Present while the drawer is open.                                           |
| `data-closed`             | Present while the drawer is closed.                                         |
| `data-starting-style`     | Present as the drawer begins to open.                                       |
| `data-ending-style`       | Present as the drawer closes.                                               |
| `data-swiping`            | Present while the drawer is being swiped. The slide transition is off then. |
| `data-swipe-direction`    | `up`, `down`, `left`, or `right`.                                           |
| `data-nested-drawer-open` | Present when a nested drawer is open.                                       |

| CSS variable                 | Description                                       |
| ---------------------------- | ------------------------------------------------- |
| `--drawer-swipe-movement-x`  | The swipe movement on the X axis.                 |
| `--drawer-swipe-movement-y`  | The swipe movement on the Y axis.                 |
| `--drawer-snap-point-offset` | The snap point offset that translates the drawer. |
| `--nested-drawers`           | How many nested drawers are open.                 |

### DrawerClose

| Data attribute  | Description                          |
| --------------- | ------------------------------------ |
| `data-disabled` | Present when the button is disabled. |

## Caveats

- The overlay renders only while `modal` is exactly `true`. With `false` or `'trap-focus'` the page behind stays visible.
- `DrawerHeader` centers its text only when `swipeDirection` is `up` or `down`. A header in a side drawer is left-aligned.
- `DrawerSwipeHandle` is `aria-hidden`. It is a visual cue, not a control.
