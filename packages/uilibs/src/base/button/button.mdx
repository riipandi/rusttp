# Button

Runs an action; `variant` sets the fill and `color` sets the role, so every fill comes in every color.

## Import

```jsx
import { Button } from 'uilibs/base/button'
```

Built on Base UI [Button](https://base-ui.com/react/components/button); with `render` it is built on [useRender](https://base-ui.com/react/utils/use-render) and renders the element you pass. Props not listed here pass through.

## Anatomy

- **Button:** the button. It renders its own `icon`, children, and `endIcon`, and a spinner while `loading`.

```jsx
<Button icon={…} endIcon={…} />

<Button render={<a href='…' />}>…</Button>
```

### As a link

`render` takes the element, such as `<a href='…' />` or a router link, and gives it the button's look. The element keeps its own role, so it is announced as a link, and the handlers and `ref` of the button reach it. Pass the text as children of the `Button`, not of the element: a button with no children reads as icon-only and turns square.

```jsx
import { Link as RouterLink } from '@tanstack/react-router'

<Button render={<RouterLink to='/login' />}>Sign in</Button>
```

### Aligned with the text around it

A ghost button's padding indents its label from the content edge. A negative `marginInlineStart` of the same size lines the label up with the text above it. The padding is `unit.x2` at `xsmall`, `unit.x3` at `small`, `unit.x4` at `medium`, and `unit.x6` at `large`.

```jsx
const styles = stylex.create({ aligned: { marginInlineStart: `calc(-1 * ${unit.x4})` } })

<Button variant='ghost' style={styles.aligned}>Cancel</Button>
```

## Accessibility

A `Button` is a `button`, named by its text; an icon-only one is named by `aria-label`. The `Keyboard` story walks the table below, and the `States` and `Icons` stories check the names.

| Key                     | Action                                                                                  |
| ----------------------- | --------------------------------------------------------------------------------------- |
| `Tab` and `Shift + Tab` | Moves focus to the button. A disabled button is skipped; a loading one keeps its focus. |
| `Enter` or `Space`      | Presses the button. A loading button ignores both.                                      |

- A button with no children has no text, so it needs an `aria-label`. The glyphs given as `icon` and `endIcon` are hidden from assistive technology.
- While `loading`, the button is `aria-busy` and keeps its name; the spinner adds no second announcement.
- With `render`, the element keeps its own role and keys: a link is announced as a link, as the `As a link` example shows.
- Keyboard behavior is Base UI's; see the Base UI [Button](https://base-ui.com/react/components/button) page for the rest.

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs).

### Button

| Prop          | Description                                                                                                                                                                                                                                                                                  |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `variant`     | `solid`, `faded`, `outline`, `ghost` <br /> The fill. Default `solid`.                                                                                                                                                                                                                       |
| `color`       | `primary`, `neutral`, `critical`, `positive`, `warning`, `media`, `inherit` <br /> The role. `critical` marks a destructive action; `media` is white for a photo or dark surface; `inherit` takes the parent's text color. Default `primary` for `solid`, `neutral` for the other fills.     |
| `size`        | `xsmall`, `small`, `medium`, `large` <br /> The height and type, never the shape. Inside a `ButtonGroup`, the group's size; otherwise `medium`.                                                                                                                                              |
| `rounded`     | `boolean` <br /> Fully rounded ends. Default `false`.                                                                                                                                                                                                                                        |
| `fullWidth`   | `boolean` <br /> Fills the width of its container. Default `false`.                                                                                                                                                                                                                          |
| `raised`      | `boolean` <br /> Lifts the button with the raised shadow. Default `false`.                                                                                                                                                                                                                   |
| `highlighted` | `boolean` <br /> Holds the hover fill at rest. Ignored while disabled or loading. Default `false`.                                                                                                                                                                                           |
| `icon`        | `ComponentType` <br /> A glyph before the label, hidden from assistive technology.                                                                                                                                                                                                           |
| `endIcon`     | `ComponentType` <br /> A glyph after the label, hidden from assistive technology.                                                                                                                                                                                                            |
| `render`      | `ReactElement` <br /> The element to render instead of the `button`, such as `<a href='…' />` or a router link. It keeps its own role. `loading`, `disabled`, and `focusableWhenDisabled` do not apply to it. Mark the link of the open page with `aria-current='page'`; a router link does. |
| `loading`     | `boolean` <br /> Shows a spinner over the label, keeps the width, and ignores presses. Default `false`.                                                                                                                                                                                      |

| Data attribute  | Description                                                          |
| --------------- | -------------------------------------------------------------------- |
| `data-disabled` | Present when the button is disabled, which includes while `loading`. |
| `data-loading`  | Present while `loading`. Set by this library, not Base UI.           |
| `aria-busy`     | `true` while `loading`. Set by this library, not Base UI.            |

## Caveats

- A button with no children is icon-only: a square as wide as it is tall at every `size`. Give the glyph as `icon`, and name the button with `aria-label`.
- A button that holds a custom node, such as an avatar or a page number, is not icon-only. Compose `buttonSquare[size]` through `style` to make it a square.
- While `loading`, the button is disabled but stays focusable, and it keeps its accessible name.
- `render` is for links: the element is not a native button, so it has no `disabled` and no `type`. A control that is not a link stays a `button`.
- `media` is the same in both themes, so show it on a dark backdrop. Its `solid` fill is a light tint under `inherit`, not a cut-out label.
