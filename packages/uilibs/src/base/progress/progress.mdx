# Progress

The status of a task that takes a long time.

Built on Base UI [Progress](https://base-ui.com/react/components/progress). Props not listed here pass through.

## Anatomy

```jsx
import { Progress, ProgressLabel, ProgressValue } from 'uilibs/base/progress'

;<Progress>
  <ProgressLabel />
  <ProgressValue />
</Progress>
```

`Progress` renders the track and the indicator itself, after its children, so `ProgressTrack` and `ProgressIndicator` are not placed by hand. Without a `ProgressLabel`, give the bar an `aria-label`.

## Props

Every part also takes `style`: StyleX styles that replace `className` and `style`.

### Progress

| Prop    | Values                                                  | Default   | Note                                                         |
| ------- | ------------------------------------------------------- | --------- | ------------------------------------------------------------ |
| `color` | `neutral`, `primary`, `positive`, `warning`, `critical` | `primary` | The role of the fill. Pair a non-neutral color with a label. |
| `size`  | `sm`, `md`                                              | `md`      | Bar thickness: `sm` is 2px, `md` is 4px.                     |
