# Scroll Area

A styled scroll container with overlay scrollbars.

Wraps Base UI [Scroll Area](https://base-ui.com/react/components/scroll-area). Its other props pass through.

## ScrollArea

| Prop               | Values                                 | Default    | Note                                                                      |
| ------------------ | -------------------------------------- | ---------- | ------------------------------------------------------------------------- |
| `fade`             | `boolean`                              | `false`    | Masks the edges that can be scrolled towards.                             |
| `orientation`      | `vertical`, `horizontal`, `both`       | `vertical` | Which scrollbars are drawn; `both` adds the corner.                       |
| `scrollbarDisplay` | `visible`, `hover`, `scroll`, `hidden` | `hover`    | When the bar shows: always, on hover or scroll, only on scroll, or never. |
| `style`            | StyleX styles                          | none       | Replaces the `className` and `style` props.                               |

## ScrollBar

| Prop      | Values                                 | Default | Note                                        |
| --------- | -------------------------------------- | ------- | ------------------------------------------- |
| `display` | `visible`, `hover`, `scroll`, `hidden` | `hover` | When the bar shows, as `scrollbarDisplay`.  |
| `style`   | StyleX styles                          | none    | Replaces the `className` and `style` props. |
