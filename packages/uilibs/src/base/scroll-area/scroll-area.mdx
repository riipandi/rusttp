# Scroll Area

A styled scroll container with overlay scrollbars.

Built on Base UI [Scroll Area](https://base-ui.com/react/components/scroll-area). Props not listed here pass through.

## Anatomy

```jsx
import { ScrollArea } from 'uilibs/base/scroll-area'

;<ScrollArea>{content}</ScrollArea>
```

`ScrollArea` renders the viewport, a `ScrollBar` for each axis, and the corner itself, so `ScrollBar` is not placed by hand.

## Props

Both parts also take `style`: StyleX styles that replace `className` and `style`. On `ScrollArea` it lands on the root, not the viewport.

### ScrollArea

| Prop               | Values                                 | Default    | Note                                                                      |
| ------------------ | -------------------------------------- | ---------- | ------------------------------------------------------------------------- |
| `fade`             | `boolean`                              | `false`    | Masks the edges that can be scrolled towards.                             |
| `orientation`      | `vertical`, `horizontal`, `both`       | `vertical` | Which scrollbars are drawn; `both` adds the corner.                       |
| `scrollbarDisplay` | `visible`, `hover`, `scroll`, `hidden` | `hover`    | When the bar shows: always, on hover or scroll, only on scroll, or never. |

### ScrollBar

| Prop      | Values                                 | Default | Note                                       |
| --------- | -------------------------------------- | ------- | ------------------------------------------ |
| `display` | `visible`, `hover`, `scroll`, `hidden` | `hover` | When the bar shows, as `scrollbarDisplay`. |
