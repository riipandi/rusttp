# Scroll Area

A scroll container with overlay scrollbars that match the theme.

## Import

```jsx
import { ScrollArea, ScrollBar } from 'uilibs/base/scroll-area'
```

Built on Base UI [Scroll Area](https://base-ui.com/react/components/scroll-area). Props not listed here pass through.

## Anatomy

- **ScrollArea:** the root. It renders the viewport around your content, a `ScrollBar` for each axis, and the corner itself.
- **ScrollBar:** one scrollbar with its thumb. `ScrollArea` renders it, so you do not place it.

```jsx
<ScrollArea>{content}</ScrollArea>
```

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs). On `ScrollArea` it lands on the root, not the viewport.

### ScrollArea

| Prop               | Description                                                                                                                              |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `fade`             | `boolean` <br /> Masks the edges that can be scrolled towards. Default `false`.                                                          |
| `orientation`      | `vertical`, `horizontal`, `both` <br /> Which scrollbars are drawn, one per axis named. Default `vertical`.                              |
| `scrollbarDisplay` | `visible`, `hover`, `scroll`, `hidden` <br /> When the bar shows: always, on hover or scroll, only on scroll, or never. Default `hover`. |

| Data attribute                                 | Description                                                                |
| ---------------------------------------------- | -------------------------------------------------------------------------- |
| `data-scrolling`                               | Present while the user scrolls.                                            |
| `data-has-overflow-x`, `data-has-overflow-y`   | Present when the content is wider or taller than the viewport.             |
| `data-overflow-x-start`, `data-overflow-x-end` | Present when there is more content before or after on the horizontal axis. |
| `data-overflow-y-start`, `data-overflow-y-end` | Present when there is more content above or below.                         |

| CSS variable                                                | Description             |
| ----------------------------------------------------------- | ----------------------- |
| `--scroll-area-corner-width`, `--scroll-area-corner-height` | The size of the corner. |

### ScrollBar

| Prop      | Description                                                                                               |
| --------- | --------------------------------------------------------------------------------------------------------- |
| `display` | `visible`, `hover`, `scroll`, `hidden` <br /> When the bar shows, as `scrollbarDisplay`. Default `hover`. |

| Data attribute     | Description                                 |
| ------------------ | ------------------------------------------- |
| `data-orientation` | `vertical` or `horizontal`.                 |
| `data-hovering`    | Present while the pointer is over the area. |
| `data-scrolling`   | Present while the user scrolls.             |

| CSS variable                                              | Description            |
| --------------------------------------------------------- | ---------------------- |
| `--scroll-area-thumb-width`, `--scroll-area-thumb-height` | The size of the thumb. |
