# Combobox

A searchable select. `ComboboxChips` holds several chosen values.

Wraps Base UI [Combobox](https://base-ui.com/react/components/combobox). Its other props pass through.

`Combobox`, `ComboboxValue`, and `ComboboxCollection` are the Base UI parts unchanged, and `comboboxCreateItems` is Base UI's `createItems`.

`ComboboxChipsInput`, `ComboboxList`, `ComboboxItem`, `ComboboxGroup`, `ComboboxLabel`, `ComboboxEmpty`, and `ComboboxSeparator` take only `style` (StyleX styles that replace `className` and `style`). `ComboboxChipsInput` is the input inside `ComboboxChips`, with no box of its own.

## ComboboxTrigger

A select-like button. On its own, name it with `aria-label`.

| Prop          | Values                                  | Default   | Note                                                       |
| ------------- | --------------------------------------- | --------- | ---------------------------------------------------------- |
| `size`        | `sm`, `md`, `lg`                        | `md`      | Control height and type.                                   |
| `variant`     | `outline`, `faded`, `ghost`, `headless` | `outline` | The box.                                                   |
| `showChevron` | `boolean`                               | `true`    | Renders the chevron. Set `false` for an icon-only trigger. |
| `style`       | StyleX styles                           | none      | Replaces the `className` and `style` props.                |

## ComboboxInput

An input with a dropdown button and an optional clear button. On its own, name it with `aria-label`.

| Prop          | Values                                  | Default                    | Note                                                                                           |
| ------------- | --------------------------------------- | -------------------------- | ---------------------------------------------------------------------------------------------- |
| `size`        | `sm`, `md`, `lg`                        | `md`                       | Control height and type.                                                                       |
| `variant`     | `outline`, `faded`, `ghost`, `headless` | `outline`                  | The box.                                                                                       |
| `showTrigger` | `boolean`                               | `true`                     | Renders the dropdown button. Set `false` when a `ComboboxTrigger` elsewhere anchors the popup. |
| `showClear`   | `boolean`                               | `false`                    | Renders a clear button before the dropdown button.                                             |
| `labels`      | `{ clear, open }`                       | `Clear value`, `Open list` | Names of the clear and dropdown buttons.                                                       |
| `inputStyle`  | StyleX styles                           | none                       | Styles the inner input element.                                                                |
| `style`       | StyleX styles                           | none                       | Styles the wrapper around the input and buttons; replaces the `className` and `style` props.   |

## ComboboxChips

The box that holds the chips in a multiple-value combobox. It can anchor the popup through its `ref`.

| Prop      | Values                                  | Default   | Note                                        |
| --------- | --------------------------------------- | --------- | ------------------------------------------- |
| `size`    | `sm`, `md`, `lg`                        | `md`      | Minimum height and type.                    |
| `variant` | `outline`, `faded`, `ghost`, `headless` | `outline` | The box.                                    |
| `style`   | StyleX styles                           | none      | Replaces the `className` and `style` props. |

## ComboboxChip

| Prop     | Values             | Default                        | Note                                                                             |
| -------- | ------------------ | ------------------------------ | -------------------------------------------------------------------------------- |
| `labels` | `{ remove(text) }` | `Remove <text>`, else `Remove` | Name of the remove button; `text` is the chip's children when they are a string. |
| `style`  | StyleX styles      | none                           | Replaces the `className` and `style` props.                                      |

## ComboboxContent

Renders the portal and the positioner around the popup.

| Prop                 | Values                                                         | Default           | Note                                        |
| -------------------- | -------------------------------------------------------------- | ----------------- | ------------------------------------------- |
| `side`               | `top`, `right`, `bottom`, `left`, `inline-end`, `inline-start` | `bottom`          | Which side of the anchor the popup sits on. |
| `sideOffset`         | `number` or an offset function                                 | `6`               | Distance from the anchor, in px.            |
| `align`              | `start`, `center`, `end`                                       | `start`           | Alignment along the anchor's edge.          |
| `alignOffset`        | `number` or an offset function                                 | `0`               | Offset along the alignment axis, in px.     |
| `anchor`             | element, ref, virtual element, or a function returning one     | none              | What the popup positions against.           |
| `collisionAvoidance` | Base UI collision settings                                     | Base UI's default | How the popup moves to stay in view.        |
| `style`              | StyleX styles                                                  | none              | Replaces the `className` and `style` props. |
