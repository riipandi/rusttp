# Combobox

A searchable select. Choose it over Select for a list the user searches, and over Autocomplete when the value must be one of the items. `ComboboxChips` takes several values.

Built on Base UI [Combobox](https://base-ui.com/react/components/combobox). Props not listed here pass through.

## Anatomy

```jsx
import {
  Combobox,
  ComboboxChip,
  ComboboxChips,
  ComboboxChipsInput,
  ComboboxCollection,
  ComboboxContent,
  ComboboxEmpty,
  ComboboxGroup,
  ComboboxInput,
  ComboboxItem,
  ComboboxLabel,
  ComboboxList,
  ComboboxSeparator,
  ComboboxValue
} from 'uilibs/base/combobox'

;<Combobox items={…}>
  <ComboboxInput />
  <ComboboxContent>
    <ComboboxEmpty />
    <ComboboxList>
      <ComboboxItem />
      <ComboboxSeparator />
      <ComboboxGroup>
        <ComboboxLabel />
        <ComboboxCollection>
          <ComboboxItem />
        </ComboboxCollection>
      </ComboboxGroup>
    </ComboboxList>
  </ComboboxContent>
</Combobox>

;<Combobox items={…} multiple>
  <ComboboxChips>
    <ComboboxValue>
      <ComboboxChip />
    </ComboboxValue>
    <ComboboxChipsInput />
  </ComboboxChips>
  <ComboboxContent anchor={…} />
</Combobox>
```

`ComboboxInput` renders the dropdown button and the optional clear button. `ComboboxContent` renders the portal and the positioner. `ComboboxItem` renders its check mark, `ComboboxChip` its remove button, and `ComboboxTrigger` its chevron. `ComboboxChipsInput` has no box of its own, and `ComboboxChips` needs a `ref` passed to `anchor` to anchor the popup.

For a select-like button, use `ComboboxTrigger` with `ComboboxValue` inside it, and put `<ComboboxInput showTrigger={false} />` inside `ComboboxContent`. Name a standalone `ComboboxInput` or `ComboboxTrigger` with `aria-label`.

`Combobox`, `ComboboxValue`, and `ComboboxCollection` are Base UI's parts, and `comboboxCreateItems` is Base UI's `createItems`, re-exported unchanged.

## Props

Every part except `Combobox`, `ComboboxValue`, and `ComboboxCollection` also takes `style`: StyleX styles that replace `className` and `style`. On `ComboboxContent` it styles the popup, and on `ComboboxInput` the wrapper around the input and buttons.

### ComboboxTrigger

| Prop          | Values                                  | Default   | Note                                                       |
| ------------- | --------------------------------------- | --------- | ---------------------------------------------------------- |
| `size`        | `sm`, `md`, `lg`                        | `md`      | Control height and type.                                   |
| `variant`     | `outline`, `faded`, `ghost`, `headless` | `outline` | The box.                                                   |
| `showChevron` | `boolean`                               | `true`    | Renders the chevron. Set `false` for an icon-only trigger. |

### ComboboxInput

| Prop          | Values                                  | Default                    | Note                                                                                           |
| ------------- | --------------------------------------- | -------------------------- | ---------------------------------------------------------------------------------------------- |
| `size`        | `sm`, `md`, `lg`                        | `md`                       | Control height and type.                                                                       |
| `variant`     | `outline`, `faded`, `ghost`, `headless` | `outline`                  | The box.                                                                                       |
| `showTrigger` | `boolean`                               | `true`                     | Renders the dropdown button. Set `false` when a `ComboboxTrigger` elsewhere anchors the popup. |
| `showClear`   | `boolean`                               | `false`                    | Renders a clear button before the dropdown button.                                             |
| `labels`      | `{ clear, open }`                       | `Clear value`, `Open list` | Names of the clear and dropdown buttons.                                                       |
| `inputStyle`  | StyleX styles                           | none                       | Styles the inner input element.                                                                |

### ComboboxChips

| Prop      | Values                                  | Default   | Note                     |
| --------- | --------------------------------------- | --------- | ------------------------ |
| `size`    | `sm`, `md`, `lg`                        | `md`      | Minimum height and type. |
| `variant` | `outline`, `faded`, `ghost`, `headless` | `outline` | The box.                 |

### ComboboxChip

| Prop     | Values             | Default                        | Note                                                                             |
| -------- | ------------------ | ------------------------------ | -------------------------------------------------------------------------------- |
| `labels` | `{ remove(text) }` | `Remove <text>`, else `Remove` | Name of the remove button; `text` is the chip's children when they are a string. |

### ComboboxContent

| Prop                 | Values                                                         | Default           | Note                                        |
| -------------------- | -------------------------------------------------------------- | ----------------- | ------------------------------------------- |
| `side`               | `top`, `right`, `bottom`, `left`, `inline-end`, `inline-start` | `bottom`          | Which side of the anchor the popup sits on. |
| `sideOffset`         | `number` or an offset function                                 | `6`               | Distance from the anchor, in px.            |
| `align`              | `start`, `center`, `end`                                       | `start`           | Alignment along the anchor's edge.          |
| `alignOffset`        | `number` or an offset function                                 | `0`               | Offset along the alignment axis, in px.     |
| `anchor`             | element, ref, virtual element, or a function returning one     | none              | What the popup positions against.           |
| `collisionAvoidance` | Base UI collision settings                                     | Base UI's default | How the popup moves to stay in view.        |
