# Preview Card

A preview shown when the user hovers or focuses a link. Use Popover when the content is interactive.

Built on Base UI [Preview Card](https://base-ui.com/react/components/preview-card). Props not listed here pass through.

## Anatomy

```jsx
import { PreviewCard, PreviewCardContent, PreviewCardTrigger } from 'uilibs/base/preview-card'

;<PreviewCard>
  <PreviewCardTrigger />
  <PreviewCardContent />
</PreviewCard>
```

`PreviewCardContent` renders the portal and the positioner.

## Props

`PreviewCardContent` also takes `style`: StyleX styles that replace `className` and `style`. It styles the popup. `PreviewCard` and `PreviewCardTrigger` are the Base UI parts unchanged.

### PreviewCardContent

The positioner props go to the positioner.

| Prop          | Values                                                         | Default  | Note                                         |
| ------------- | -------------------------------------------------------------- | -------- | -------------------------------------------- |
| `side`        | `top`, `bottom`, `left`, `right`, `inline-start`, `inline-end` | `bottom` | Which side of the trigger the card opens on. |
| `sideOffset`  | `number` or a function                                         | `4`      | Gap from the trigger.                        |
| `align`       | `start`, `center`, `end`                                       | `center` | Alignment along the side.                    |
| `alignOffset` | `number` or a function                                         | `4`      | Shift along the alignment axis.              |
