# Meter

A bar that shows a numeric value within a range.

Built on Base UI [Meter](https://base-ui.com/react/components/meter). Props not listed here pass through.

## Anatomy

```jsx
import { Meter, MeterLabel, MeterValue } from 'uilibs/base/meter'

;<Meter>
  <MeterLabel />
  <MeterValue />
</Meter>
```

`Meter` renders the track and the indicator itself, after its children, so `MeterTrack` and `MeterIndicator` are not placed by hand. Without a `MeterLabel`, give the meter an `aria-label`.

## Props

Every part also takes `style`: StyleX styles that replace `className` and `style`.

### Meter

| Prop    | Values                                                  | Default   | Note                                                                                     |
| ------- | ------------------------------------------------------- | --------- | ---------------------------------------------------------------------------------------- |
| `color` | `neutral`, `primary`, `positive`, `warning`, `critical` | `primary` | The role of the fill. Keep a label with a non-neutral color: color alone is not meaning. |
| `size`  | `sm`, `md`                                              | `md`      | Bar thickness: `sm` 2px, `md` 4px.                                                       |
