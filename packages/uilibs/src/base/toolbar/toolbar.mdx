# Toolbar

A container for toolbar items. Compose buttons, toggles, and inputs through the `render` prop.

Wraps Base UI [Toolbar](https://base-ui.com/react/components/toolbar). Its other props pass through.

`ToolbarButton`, `ToolbarLink`, and `ToolbarInput` are the Base UI parts unchanged.

## Toolbar

| Prop    | Values        | Default | Note                                        |
| ------- | ------------- | ------- | ------------------------------------------- |
| `style` | StyleX styles | none    | Replaces the `className` and `style` props. |
