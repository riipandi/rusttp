# Toolbar

A container that groups buttons, toggles, links, and inputs.

Built on Base UI [Toolbar](https://base-ui.com/react/components/toolbar). Props not listed here pass through.

## Anatomy

```jsx
import {
  Toolbar,
  ToolbarButton,
  ToolbarGroup,
  ToolbarInput,
  ToolbarLink,
  ToolbarSeparator
} from 'uilibs/base/toolbar'
import { Button } from 'uilibs/base/button'
import { Toggle } from 'uilibs/base/toggle'

;<Toolbar>
  <ToolbarGroup>
    <ToolbarButton render={<Toggle />} />
  </ToolbarGroup>
  <ToolbarSeparator />
  <ToolbarButton render={<Button />} />
  <ToolbarLink />
  <ToolbarInput />
</Toolbar>
```

`ToolbarButton`, `ToolbarLink`, and `ToolbarInput` carry no styles. Render a `Button`, `Toggle`, or `Input` through `render` to get theirs. To add a toggle group, place `ToggleGroup` in the toolbar and render each item through `ToolbarButton render={<ToggleGroupItem />}`.

## Props

No part adds props. `Toolbar`, `ToolbarGroup`, and `ToolbarSeparator` also take `style`: StyleX styles that replace `className` and `style`. `ToolbarButton`, `ToolbarLink`, and `ToolbarInput` are the Base UI parts unchanged.
