# Navigation Menu

Links and menus for site navigation.

Built on Base UI [Navigation Menu](https://base-ui.com/react/components/navigation-menu). Props not listed here pass through.

## Anatomy

```jsx
import {
  NavigationMenu,
  NavigationMenuContent,
  NavigationMenuItem,
  NavigationMenuLink,
  NavigationMenuList,
  NavigationMenuTrigger
} from 'uilibs/base/navigation-menu'

;<NavigationMenu>
  <NavigationMenuList>
    <NavigationMenuItem>
      <NavigationMenuTrigger />
      <NavigationMenuContent>
        <NavigationMenuLink />
      </NavigationMenuContent>
    </NavigationMenuItem>
    <NavigationMenuItem>
      <NavigationMenuLink />
    </NavigationMenuItem>
  </NavigationMenuList>
</NavigationMenu>
```

`NavigationMenu` renders the portal, the positioner, the popup, and the viewport itself, so do not add `NavigationMenuPositioner`. `NavigationMenuTrigger` renders its own chevron.

## Props

Every part also takes `style`: StyleX styles that replace `className` and `style`.

### NavigationMenu

| Prop     | Values                   | Default                | Note                                                                                                           |
| -------- | ------------------------ | ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| `align`  | `start`, `center`, `end` | `start`                | Alignment of the popup relative to the menu.                                                                   |
| `labels` | `{ menu, popup }`        | `Main`, `Main details` | Accessible names of the menu's `nav` landmark and of the popup's, which is a second landmark while it is open. |

### NavigationMenuPositioner

The positioner `NavigationMenu` renders. Set `align` on the root.

| Prop          | Values                                                         | Default  | Note                                          |
| ------------- | -------------------------------------------------------------- | -------- | --------------------------------------------- |
| `side`        | `top`, `bottom`, `left`, `right`, `inline-end`, `inline-start` | `bottom` | Which side of the trigger the popup opens on. |
| `sideOffset`  | `number` or a function                                         | `8`      | Distance from the trigger in pixels.          |
| `align`       | `start`, `center`, `end`                                       | `start`  | Alignment along the chosen side.              |
| `alignOffset` | `number` or a function                                         | `0`      | Offset along the alignment axis in pixels.    |
