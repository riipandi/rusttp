# Slider

Picks a value, or a range of values, by dragging a thumb along a track.

## Import

```jsx
import { Slider } from 'uilibs/base/slider'
```

Built on Base UI [Slider](https://base-ui.com/react/components/slider). Props not listed here pass through.

## Anatomy

- **Slider:** the root. It renders the control, track, filled range and one thumb per entry of `value` or `defaultValue` itself, so it takes no children.

```jsx
<Slider />
```

## Accessibility

Each thumb is a `slider` with `aria-valuenow`, `aria-valuemin` and `aria-valuemax`. A thumb has no text: name a single thumb with `aria-label` on `Slider` and each thumb of a range with `thumbLabels`. The `Keyboard` story walks the table below, and `Range` asserts the names.

| Key                      | Action                                                                                             |
| ------------------------ | -------------------------------------------------------------------------------------------------- |
| `Tab` and `Shift + Tab`  | Moves focus to a thumb. A range has one tab stop per thumb.                                        |
| `ArrowRight`, `ArrowUp`  | Raises the value by `step`.                                                                        |
| `ArrowLeft`, `ArrowDown` | Lowers the value by `step`.                                                                        |
| `PageUp`, `PageDown`     | Raises or lowers the value by `largeStep`, 10 by default.                                          |
| `Shift + Arrow`          | Steps by `largeStep`.                                                                              |
| `Home`, `End`            | Jumps to the lowest or highest value the thumb may take. In a range a thumb stops at its neighbor. |

- A disabled slider takes no keys; it is drawn with the disabled tokens, not dimmed.
- Keyboard behavior is Base UI's; see the Base UI [Slider](https://base-ui.com/react/components/slider) page for the rest.

## API reference

`Slider` also takes `style`: StyleX styles that replace `className` and `style`. It lands on the root. See [Styling](?path=/docs/styling--docs).

### Slider

| Prop          | Description                                                                                                                        |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `thumbLabels` | `string[]` <br /> The accessible name of each thumb, in order. A slider with one thumb uses its `aria-label` when this is not set. |

| Data attribute     | Description                                               |
| ------------------ | --------------------------------------------------------- |
| `data-orientation` | `horizontal` or `vertical`.                               |
| `data-dragging`    | Present while a thumb is being dragged.                   |
| `data-disabled`    | Present when the slider is disabled.                      |
| `data-invalid`     | Present when a surrounding `Field` marks it invalid.      |
| `data-index`       | Set on each thumb: its position among the thumbs, from 0. |

## Caveats

- A thumb has no text. Give a single thumb an `aria-label` on `Slider`, and a range `thumbLabels`.
- The number of thumbs is read from `value` or `defaultValue` at render; without an array there is one.
- `min` defaults to `0`, `max` to `100`, and `thumbAlignment` to `edge`, which keeps the thumb inside the track.
- There is no value readout; the Controlled story shows one beside the slider.
