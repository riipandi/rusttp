# Tabs

Panels of content, one visible at a time, switched by a list of tabs.

Built on Base UI [Tabs](https://base-ui.com/react/components/tabs). Props not listed here pass through.

## Anatomy

```jsx
import { Tabs, TabsContent, TabsList, TabsTrigger } from 'uilibs/base/tabs'

;<Tabs>
  <TabsList>
    <TabsTrigger value='…' />
  </TabsList>
  <TabsContent value='…' />
</Tabs>
```

A trigger and its panel share one `value`. `TabsTrigger` takes its `variant`, `size`, and `itemWidth` from the `TabsList` it sits in.

## Props

Every part also takes `style`: StyleX styles that replace `className` and `style`.

### TabsList

| Prop        | Values                                            | Default | Note                                                                                                                                                                                              |
| ----------- | ------------------------------------------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `variant`   | `pills`, `pills-raised`, `bordered`, `borderless` | `pills` | `pills` is a tinted list with a raised active pill, `pills-raised` lifts that list onto the raised surface, `bordered` is an underline on a border rail, and `borderless` is the underline alone. |
| `size`      | `xs`, `sm`, `md`, `lg`                            | `md`    | List height on the control scale; `md` is 36px.                                                                                                                                                   |
| `itemWidth` | `equal`                                           | none    | The list spans its parent and every trigger takes an equal share. Unset sizes each trigger to its label.                                                                                          |
