# Tabs

Panels of content, one visible at a time, switched by a list of tabs.

## Import

```jsx
import { Tabs, TabsContent, TabsList, TabsTrigger } from 'uilibs/base/tabs'
```

Built on Base UI [Tabs](https://base-ui.com/react/components/tabs). Props not listed here pass through.

## Anatomy

- **Tabs:** the root. It holds the selected tab and the orientation.
- **TabsList:** the row of triggers. It sets the look of every trigger in it and draws the indicator (Base UI `Tabs.Indicator`): the active pill, or the underline bar.
- **TabsTrigger:** one tab. Base UI calls this part `Tab`. It shares a `value` with its panel.
- **TabsContent:** the panel for one tab. Base UI calls this part `Panel`.

```jsx
<Tabs>
  <TabsList>
    <TabsTrigger value='gryffindor' />
  </TabsList>
  <TabsContent value='gryffindor' />
</Tabs>
```

### Motion

One indicator slides to the selected tab: the pill of `pills` and `pills-raised`, the bar of `bordered` and `borderless` (on a vertical list it moves down the list, along the inline-start edge). The tab itself has no active background. The new panel fades in and rises 4px from the side the tab came from. Under `prefers-reduced-motion` the indicator moves at once and the panel only fades; in forced colors the indicator keeps a system-color edge.

## Accessibility

`TabsList` is a `tablist` (name it with `aria-label`), each `TabsTrigger` is a `tab` named by its text, and each `TabsContent` is a `tabpanel` named by its tab. The `Keyboard` story walks the table below.

| Key                       | Action                                                                                              |
| ------------------------- | --------------------------------------------------------------------------------------------------- |
| `Tab` and `Shift + Tab`   | Enters the list on the selected tab, and leaves it for the selected panel. `Shift + Tab` goes back. |
| `ArrowRight`, `ArrowLeft` | Moves focus to the next or previous tab. The list loops.                                            |
| `Home`, `End`             | Moves focus to the first or last tab.                                                               |
| `Enter` or `Space`        | Selects the focused tab. Moving focus does not select it.                                           |

- `TabsContent` is a tab stop and draws the focus ring.
- A disabled tab cannot be selected; the `States` story proves a press does nothing.
- Keyboard behavior is Base UI's; see the Base UI [Tabs](https://base-ui.com/react/components/tabs) page for `activateOnFocus` and the rest.

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs).

### Tabs

| Prop          | Description                                                                      |
| ------------- | -------------------------------------------------------------------------------- |
| `orientation` | `horizontal`, `vertical` <br /> The direction of the list. Default `horizontal`. |

| Data attribute              | Description                                                                                  |
| --------------------------- | -------------------------------------------------------------------------------------------- |
| `data-orientation`          | `horizontal` or `vertical`.                                                                  |
| `data-activation-direction` | `left`, `right`, `up`, `down`, or `none`: where the new tab is relative to the previous one. |

### TabsList

| Prop        | Description                                                                                                                                                                                                                                                          |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `variant`   | `pills`, `pills-raised`, `bordered`, `borderless` <br /> `pills` is a tinted list with a raised active pill, `pills-raised` lifts it onto the raised surface, `bordered` is an underline on a border rail, and `borderless` is the underline alone. Default `pills`. |
| `size`      | `xsmall`, `small`, `medium`, `large` <br /> List height on the control scale. `medium` is 36px. Default `medium`.                                                                                                                                                    |
| `itemWidth` | `equal` <br /> The list spans its parent and every trigger takes an equal share. Unset sizes each trigger to its label.                                                                                                                                              |

| Data attribute     | Description                 |
| ------------------ | --------------------------- |
| `data-orientation` | `horizontal` or `vertical`. |

| CSS variable                                | Description                                                      |
| ------------------------------------------- | ---------------------------------------------------------------- |
| `--active-tab-left`, `--active-tab-top`     | Base UI's offset of the selected tab; the indicator moves to it. |
| `--active-tab-width`, `--active-tab-height` | The size of the selected tab.                                    |

### TabsTrigger

| Data attribute     | Description                        |
| ------------------ | ---------------------------------- |
| `data-active`      | Present while the tab is selected. |
| `data-disabled`    | Present when the tab is disabled.  |
| `data-orientation` | `horizontal` or `vertical`.        |

### TabsContent

| Data attribute              | Description                                                                     |
| --------------------------- | ------------------------------------------------------------------------------- |
| `data-activation-direction` | `left`, `right`, `up`, `down`, or `none`: the side the panel enters from.       |
| `data-hidden`               | Present while the panel is hidden.                                              |
| `data-orientation`          | `horizontal` or `vertical`.                                                     |
| `data-starting-style`       | Present as the panel begins to appear; the fade and the 4px rise start from it. |
| `data-ending-style`         | Present as the panel disappears.                                                |

## Caveats

- `TabsTrigger` reads `variant`, `size`, and `itemWidth` from the `TabsList` it sits in, so it must be inside one.
- `TabsContent` is a tab stop and draws the focus ring.
- The indicator appears after Base UI measures the selected tab, so the first paint of a list can draw it a frame after the labels.
- A `size='xsmall'` pill tab is 20px tall; its hit area adds 2px above and below to reach 24px. An underline tab at `xsmall` is already 28px.
