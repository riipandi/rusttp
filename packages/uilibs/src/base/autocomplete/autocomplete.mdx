# Autocomplete

An input that suggests options as you type. Choose it over Combobox when any typed value is allowed and the list only suggests.

Built on Base UI [Autocomplete](https://base-ui.com/react/components/autocomplete). Props not listed here pass through.

## Anatomy

```jsx
import {
  Autocomplete,
  AutocompleteCollection,
  AutocompleteContent,
  AutocompleteEmpty,
  AutocompleteGroup,
  AutocompleteInput,
  AutocompleteItem,
  AutocompleteLabel,
  AutocompleteList,
  AutocompleteSeparator
} from 'uilibs/base/autocomplete'

;<Autocomplete items={…}>
  <AutocompleteInput />
  <AutocompleteContent>
    <AutocompleteEmpty />
    <AutocompleteList>
      <AutocompleteItem />
      <AutocompleteSeparator />
      <AutocompleteGroup>
        <AutocompleteLabel />
        <AutocompleteCollection>
          <AutocompleteItem />
        </AutocompleteCollection>
      </AutocompleteGroup>
    </AutocompleteList>
  </AutocompleteContent>
</Autocomplete>
```

`AutocompleteContent` renders the portal and the positioner. `Autocomplete`, `AutocompleteCollection`, and `AutocompleteValue` are Base UI's parts, re-exported unchanged.

## Props

Every part except `Autocomplete`, `AutocompleteCollection`, and `AutocompleteValue` also takes `style`: StyleX styles that replace `className` and `style`. On `AutocompleteContent` it styles the popup.

### AutocompleteInput

| Prop      | Values                                  | Default   | Note                     |
| --------- | --------------------------------------- | --------- | ------------------------ |
| `size`    | `sm`, `md`, `lg`                        | `md`      | Control height and type. |
| `variant` | `outline`, `faded`, `ghost`, `headless` | `outline` | The box.                 |

### AutocompleteContent

| Prop          | Values                                                         | Default  | Note                                        |
| ------------- | -------------------------------------------------------------- | -------- | ------------------------------------------- |
| `side`        | `top`, `right`, `bottom`, `left`, `inline-end`, `inline-start` | `bottom` | Which side of the anchor the popup sits on. |
| `sideOffset`  | `number` or an offset function                                 | `6`      | Distance from the anchor, in px.            |
| `align`       | `start`, `center`, `end`                                       | `start`  | Alignment along the anchor's edge.          |
| `alignOffset` | `number` or an offset function                                 | `0`      | Offset along the alignment axis, in px.     |
| `anchor`      | element, ref, virtual element, or a function returning one     | none     | What the popup positions against.           |

### AutocompleteList

| Prop       | Values                            | Default | Note                                             |
| ---------- | --------------------------------- | ------- | ------------------------------------------------ |
| `children` | static items or a render function | none    | The render function receives the filtered items. |
