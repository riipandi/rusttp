# Checkbox

A box that is checked or not, alone or in a group that shares checked state.

## Import

```jsx
import { Checkbox, CheckboxGroup } from 'uilibs/base/checkbox'
```

Built on Base UI [Checkbox](https://base-ui.com/react/components/checkbox) and [Checkbox Group](https://base-ui.com/react/components/checkbox-group). Props not listed here pass through.

## Anatomy

- **Checkbox:** the box. It renders its check or indeterminate mark itself and works with or without a group.
- **CheckboxGroup:** optional. It shares checked state across the checkboxes inside it.

```jsx
<CheckboxGroup>
  <Checkbox name='…' />
</CheckboxGroup>
```

## Accessibility

A `Checkbox` is a `checkbox` that reports `aria-checked` as `true`, `false` or `mixed`. It has no text, so its name comes from a wrapping `Label`, a `FieldLabel`, or `aria-label`; a group is named by `aria-label` on `CheckboxGroup`. The `Keyboard` story walks the table below, and `States` and `Group with a parent` check the states and names.

| Key                     | Action                                                       |
| ----------------------- | ------------------------------------------------------------ |
| `Tab` and `Shift + Tab` | Moves focus to the checkbox. A disabled checkbox is skipped. |
| `Space`                 | Toggles the checkbox. `Enter` does not.                      |

- The indeterminate mark is reported as `aria-checked='mixed'`: the `parent` checkbox shows it while only some of its children are checked.
- An invalid checkbox inside a `Field` is marked `data-invalid`; show the reason with `FieldError`.
- Keyboard behavior is Base UI's; see the Base UI [Checkbox](https://base-ui.com/react/components/checkbox) and [Checkbox Group](https://base-ui.com/react/components/checkbox-group) pages for the rest.

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs).

### Checkbox

| Prop   | Description                                                                    |
| ------ | ------------------------------------------------------------------------------ |
| `size` | `small`, `medium`, `large` <br /> Box size: 12, 16 or 20 px. Default `medium`. |

| Data attribute       | Description                                          |
| -------------------- | ---------------------------------------------------- |
| `data-checked`       | Present when the box is checked.                     |
| `data-unchecked`     | Present when the box is not checked.                 |
| `data-indeterminate` | Present when the box is indeterminate.               |
| `data-disabled`      | Present when the checkbox is disabled.               |
| `data-readonly`      | Present when the checkbox is read-only.              |
| `data-required`      | Present when the checkbox is required.               |
| `data-invalid`       | Present when a surrounding `Field` marks it invalid. |

### CheckboxGroup

| Data attribute  | Description                         |
| --------------- | ----------------------------------- |
| `data-disabled` | Present when the group is disabled. |

## Caveats

- `Checkbox` renders a `span`, not an `input`, so `:disabled` never matches; style the disabled look with `[data-disabled]`.
- A checkbox has no text of its own. Wrap it in a `Label` or a horizontal `Field`, or give it an `aria-label`; a group also needs an `aria-label`.
- A `parent` checkbox needs `allValues` on the group.
