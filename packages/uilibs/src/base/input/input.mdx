# Input

A text input that fills its container and takes part in a surrounding `Field`.

## Import

```jsx
import { Input } from 'uilibs/base/input'
```

Built on Base UI [Input](https://base-ui.com/react/components/input). Props not listed here pass through.

## Anatomy

- **Input:** the `input` element. Inside a `Field` it takes the field's label, description and invalid state.

```jsx
<Input />
```

## Accessibility

An `Input` is a native `input`, so it is a `textbox` that takes typing and the browser's own editing keys. Inside a `Field` its name and description come from the field; alone it needs a `label` or an `aria-label`. The `Keyboard` story walks the table below, and `States` checks the disabled and invalid markup.

| Key                     | Action                                                 |
| ----------------------- | ------------------------------------------------------ |
| `Tab` and `Shift + Tab` | Moves focus to the input. A disabled input is skipped. |
| Characters              | Typed into the input. A disabled input takes none.     |

- `aria-invalid='true'` is set when a surrounding `Field` is `invalid`.
- `faded`, `ghost` and `headless` have no edge at rest, so give them a visible label; every variant draws the focus ring.
- Keyboard behavior is the browser's; see the Base UI [Input](https://base-ui.com/react/components/input) page for how it joins a `Field`.

## API reference

`Input` also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs).

### Input

| Prop      | Description                                                                                |
| --------- | ------------------------------------------------------------------------------------------ |
| `size`    | `small`, `medium`, `large` <br /> Height and type: 32, 36 or 40 px. Default `medium`.      |
| `variant` | `outline`, `faded`, `ghost`, `headless` <br /> The box around the text. Default `outline`. |

| Data attribute  | Description                                                 |
| --------------- | ----------------------------------------------------------- |
| `data-disabled` | Present when the input is disabled.                         |
| `data-invalid`  | Present when a surrounding `Field` marks it invalid.        |
| `data-filled`   | Present when the input has a value, inside a `Field`.       |
| `data-focused`  | Present when the input has focus, inside a `Field`.         |
| `data-touched`  | Present after the input has been touched, inside a `Field`. |
| `data-dirty`    | Present when the value has changed, inside a `Field`.       |

## Caveats

- `faded`, `ghost` and `headless` have no edge at rest, so give them a visible label.
- Without a `Field`, name the input with a `label` or an `aria-label`.
