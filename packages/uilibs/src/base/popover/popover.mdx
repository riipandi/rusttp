# Popover

Interactive content in a floating panel opened by a trigger. Use Tooltip to name a control, and Preview Card to preview a link on hover.

Built on Base UI [Popover](https://base-ui.com/react/components/popover). Props not listed here pass through.

## Anatomy

```jsx
import {
  Popover,
  PopoverClose,
  PopoverContent,
  PopoverDescription,
  PopoverHeader,
  PopoverTitle,
  PopoverTrigger
} from 'uilibs/base/popover'

;<Popover>
  <PopoverTrigger />
  <PopoverContent>
    <PopoverHeader>
      <PopoverTitle />
      <PopoverDescription />
    </PopoverHeader>
    <PopoverClose />
  </PopoverContent>
</Popover>
```

`PopoverContent` renders the portal and the positioner. `PopoverHeader` is a layout wrapper and optional. A popover without a `PopoverTitle` needs an `aria-label` on `PopoverContent`.

## Props

`PopoverHeader`, `PopoverTitle`, `PopoverDescription`, and `PopoverContent` also take `style`: StyleX styles that replace `className` and `style`. On `PopoverContent` it styles the popup.

### PopoverContent

The positioner props go to the positioner.

| Prop                 | Values                                                                                             | Default   | Note                                                 |
| -------------------- | -------------------------------------------------------------------------------------------------- | --------- | ---------------------------------------------------- |
| `elevation`          | `overlay`, `raised`                                                                                | `overlay` | Depth of the shadow; `raised` is the lighter one.    |
| `padding`            | `0`, `0.5`, `1`, `1.5`, `2`, `3`, `4`, `5`, `6`, `7`, `8`, `9`, `10`, `12`, `14`, `16`, `18`, `20` | `4`       | Space inside the popup in `unit` steps; `4` is 16px. |
| `borderRadius`       | `medium`, `large`                                                                                  | `medium`  | Corner radius.                                       |
| `side`               | `top`, `bottom`, `left`, `right`, `inline-start`, `inline-end`                                     | `bottom`  | Which side of the trigger the popup opens on.        |
| `sideOffset`         | `number` or a function                                                                             | `4`       | Gap from the trigger.                                |
| `align`              | `start`, `center`, `end`                                                                           | `center`  | Alignment along the side.                            |
| `alignOffset`        | `number` or a function                                                                             | `0`       | Shift along the alignment axis.                      |
| `collisionAvoidance` | Base UI positioner value                                                                           | none      | How the popup moves to stay in view.                 |
| `collisionPadding`   | Base UI positioner value                                                                           | none      | Space kept from the viewport edge.                   |
