# Accordion

A stack of headings that each open and close a panel of content.

Built on Base UI [Accordion](https://base-ui.com/react/components/accordion). Props not listed here pass through.

## Anatomy

```jsx
import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from 'uilibs/base/accordion'

;<Accordion>
  <AccordionItem>
    <AccordionTrigger />
    <AccordionContent />
  </AccordionItem>
</Accordion>
```

`AccordionTrigger` renders the heading and the chevron itself, so there is no separate header part.

## Props

Every part also takes `style`: StyleX styles that replace `className` and `style`. On `AccordionContent` it styles the inner wrapper of the panel.

### AccordionTrigger

| Prop           | Values         | Default | Note                                                                              |
| -------------- | -------------- | ------- | --------------------------------------------------------------------------------- |
| `iconPosition` | `start`, `end` | `end`   | Which side of the label the chevron is on. The DOM and focus order stay the same. |
