# Context Menu

A menu that opens at the pointer on right click or long press.

Wraps Base UI [Context Menu](https://base-ui.com/react/components/context-menu). Its other props pass through.

`ContextMenu`, `ContextMenuGroup`, `ContextMenuPortal`, `ContextMenuSub`, and `ContextMenuRadioGroup` are the Base UI parts unchanged.

`ContextMenuItem`, `ContextMenuCheckboxItem`, `ContextMenuRadioItem`, `ContextMenuSubTrigger`, `ContextMenuShortcut`, `ContextMenuSeparator`, and `ContextMenuLabel` are the Dropdown Menu parts, styled the same and taking the same props.

`ContextMenuTrigger` takes only `style` (StyleX styles that replace `className` and `style`).

## ContextMenuContent

Renders the portal and the positioner around the popup.

| Prop          | Values                                                         | Default | Note                                        |
| ------------- | -------------------------------------------------------------- | ------- | ------------------------------------------- |
| `side`        | `top`, `right`, `bottom`, `left`, `inline-end`, `inline-start` | `right` | Which side of the anchor the popup sits on. |
| `sideOffset`  | `number` or an offset function                                 | `0`     | Distance from the anchor, in px.            |
| `align`       | `start`, `center`, `end`                                       | `start` | Alignment along the anchor's edge.          |
| `alignOffset` | `number` or an offset function                                 | `4`     | Offset along the alignment axis, in px.     |
| `style`       | StyleX styles                                                  | none    | Replaces the `className` and `style` props. |

## ContextMenuSubContent

The popup of a submenu. It takes the `ContextMenuContent` props with other defaults.

| Prop          | Values                                                         | Default | Note                                        |
| ------------- | -------------------------------------------------------------- | ------- | ------------------------------------------- |
| `side`        | `top`, `right`, `bottom`, `left`, `inline-end`, `inline-start` | `right` | Which side of the anchor the popup sits on. |
| `sideOffset`  | `number` or an offset function                                 | `0`     | Distance from the anchor, in px.            |
| `align`       | `start`, `center`, `end`                                       | `start` | Alignment along the anchor's edge.          |
| `alignOffset` | `number` or an offset function                                 | `-4`    | Offset along the alignment axis, in px.     |
| `style`       | StyleX styles                                                  | none    | Replaces the `className` and `style` props. |
