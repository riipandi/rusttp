# Context Menu

A menu that opens at the pointer on right click or long press. Use Dropdown Menu for a menu opened from a button.

Built on Base UI [Context Menu](https://base-ui.com/react/components/context-menu). Props not listed here pass through.

## Anatomy

```jsx
import {
  ContextMenu,
  ContextMenuCheckboxItem,
  ContextMenuContent,
  ContextMenuGroup,
  ContextMenuItem,
  ContextMenuLabel,
  ContextMenuRadioGroup,
  ContextMenuRadioItem,
  ContextMenuSeparator,
  ContextMenuShortcut,
  ContextMenuSub,
  ContextMenuSubContent,
  ContextMenuSubTrigger,
  ContextMenuTrigger
} from 'uilibs/base/context-menu'

;<ContextMenu>
  <ContextMenuTrigger />
  <ContextMenuContent>
    <ContextMenuItem>
      <ContextMenuShortcut />
    </ContextMenuItem>
    <ContextMenuSeparator />
    <ContextMenuGroup>
      <ContextMenuLabel />
      <ContextMenuCheckboxItem />
    </ContextMenuGroup>
    <ContextMenuRadioGroup>
      <ContextMenuRadioItem />
    </ContextMenuRadioGroup>
    <ContextMenuSub>
      <ContextMenuSubTrigger />
      <ContextMenuSubContent>
        <ContextMenuItem />
      </ContextMenuSubContent>
    </ContextMenuSub>
  </ContextMenuContent>
</ContextMenu>
```

`ContextMenuContent` renders the portal and the positioner. `ContextMenuLabel` must sit inside a `ContextMenuGroup` or `ContextMenuRadioGroup`, and a radio item inside a `ContextMenuRadioGroup`.

## Props

Every part except `ContextMenu`, `ContextMenuGroup`, `ContextMenuPortal`, `ContextMenuSub`, and `ContextMenuRadioGroup` also takes `style`: StyleX styles that replace `className` and `style`. On `ContextMenuContent` and `ContextMenuSubContent` it styles the popup.

`ContextMenuItem`, `ContextMenuCheckboxItem`, `ContextMenuRadioItem`, `ContextMenuSubTrigger`, `ContextMenuShortcut`, `ContextMenuSeparator`, and `ContextMenuLabel` are the Dropdown Menu parts, with the same props (`color`, `icon`, and `inset` are documented there).

### ContextMenuContent

| Prop          | Values                                                         | Default | Note                                        |
| ------------- | -------------------------------------------------------------- | ------- | ------------------------------------------- |
| `side`        | `top`, `right`, `bottom`, `left`, `inline-end`, `inline-start` | `right` | Which side of the anchor the popup sits on. |
| `sideOffset`  | `number` or an offset function                                 | `0`     | Distance from the anchor, in px.            |
| `align`       | `start`, `center`, `end`                                       | `start` | Alignment along the anchor's edge.          |
| `alignOffset` | `number` or an offset function                                 | `4`     | Offset along the alignment axis, in px.     |

### ContextMenuSubContent

The popup of a submenu. It takes the `ContextMenuContent` props with other defaults.

| Prop          | Values                                                         | Default | Note                                        |
| ------------- | -------------------------------------------------------------- | ------- | ------------------------------------------- |
| `side`        | `top`, `right`, `bottom`, `left`, `inline-end`, `inline-start` | `right` | Which side of the anchor the popup sits on. |
| `sideOffset`  | `number` or an offset function                                 | `0`     | Distance from the anchor, in px.            |
| `align`       | `start`, `center`, `end`                                       | `start` | Alignment along the anchor's edge.          |
| `alignOffset` | `number` or an offset function                                 | `-4`    | Offset along the alignment axis, in px.     |
