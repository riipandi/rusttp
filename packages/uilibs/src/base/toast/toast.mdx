# Toast

Stacked notifications, raised by an imperative `toast` call from anywhere.

Built on Base UI [Toast](https://base-ui.com/react/components/toast). Props not listed here pass through.

## Anatomy

```jsx
import { ToastProvider, Toaster, toast } from 'uilibs/base/toast'

;<ToastProvider>
  {children}
  <Toaster />
</ToastProvider>

toast('Title', { description: '…' })
```

Mount `ToastProvider` and `Toaster` once, for example in the root layout. `Toaster` renders the portal, the viewport, and each toast with its title, description, action, and close button.

## Props

### Toaster

| Prop             | Values                                             | Default                 | Note                                                      |
| ---------------- | -------------------------------------------------- | ----------------------- | --------------------------------------------------------- |
| `swipeDirection` | `up`, `down`, `left`, `right`, or an array of them | `['down', 'right']`     | Directions a toast can be swiped to dismiss.              |
| `labels`         | `{ close, notification }`                          | `Close`, `Notification` | Names of the close button and of a toast without a title. |
| `style`          | StyleX styles                                      | none                    | Styles for the viewport, merged last.                     |

### toast

The options of `toast`, `toast.success`, and `toast.error` are the Base UI toast options without `title` and `data`, plus:

| Prop    | Values                                                  | Default   | Note                                                                            |
| ------- | ------------------------------------------------------- | --------- | ------------------------------------------------------------------------------- |
| `color` | `neutral`, `primary`, `positive`, `warning`, `critical` | `neutral` | The accent color. `success` and `error` toasts imply `positive` and `critical`. |
