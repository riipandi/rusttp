# Separator

A line that divides two pieces of content.

## Import

```jsx
import { Separator } from 'uilibs/base/separator'
```

Built on Base UI [Separator](https://base-ui.com/react/components/separator). Props not listed here pass through.

## Anatomy

- **Separator:** the line. It has no children.

```jsx
<Separator />
```

## API reference

`Separator` also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs).

### Separator

| Prop    | Description                                                                                                     |
| ------- | --------------------------------------------------------------------------------------------------------------- |
| `color` | `neutral-faded`, `neutral` <br /> The line color; `neutral-faded` is the soft divider. Default `neutral-faded`. |
| `inset` | `boolean` <br /> Stops short of the container's edges. Default `false`.                                         |

| Data attribute     | Description                 |
| ------------------ | --------------------------- |
| `data-orientation` | `horizontal` or `vertical`. |

## Caveats

- A `Separator` has the `separator` role and an `aria-orientation`, so a screen reader announces the division. It takes no focus and answers no keys, so it needs no name.
