# Separator

A visual divider between pieces of content.

Built on Base UI [Separator](https://base-ui.com/react/components/separator). Props not listed here pass through.

## Anatomy

```jsx
import { Separator } from 'uilibs/base/separator'

;<Separator />
```

## Props

| Prop    | Values                     | Default         | Note                                           |
| ------- | -------------------------- | --------------- | ---------------------------------------------- |
| `color` | `neutral-faded`, `neutral` | `neutral-faded` | The line; `neutral-faded` is the soft divider. |
| `inset` | `boolean`                  | `false`         | Stops short of the container's edges.          |
| `style` | StyleX styles              | none            | Replaces `className` and `style`.              |
