# Radio

A radio group for choosing one option, with its items.

Built on Base UI [Radio](https://base-ui.com/react/components/radio) and [Radio Group](https://base-ui.com/react/components/radio-group). Props not listed here pass through.

## Anatomy

```jsx
import { RadioGroup, RadioGroupItem } from 'uilibs/base/radio'

;<RadioGroup>
  <RadioGroupItem value='…' />
</RadioGroup>
```

`RadioGroupItem` renders its own indicator. It has no text, so put each item in a label or a horizontal `Field`, and name the group with `aria-label`.

## Props

Both parts also take `style`: StyleX styles that replace `className` and `style`.

### RadioGroupItem

| Prop   | Values           | Default | Note                              |
| ------ | ---------------- | ------- | --------------------------------- |
| `size` | `sm`, `md`, `lg` | `md`    | Circle size: 12px, 16px, or 20px. |
