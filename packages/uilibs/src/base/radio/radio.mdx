# Radio

A group of radio buttons for choosing one option.

## Import

```jsx
import { RadioGroup, RadioGroupItem } from 'uilibs/base/radio'
```

Built on Base UI [Radio](https://base-ui.com/react/components/radio) and [Radio Group](https://base-ui.com/react/components/radio-group). Props not listed here pass through.

## Anatomy

- **RadioGroup:** the root. It holds the selected `value`.
- **RadioGroupItem:** one option. It renders its own indicator and has a `value`.

```jsx
<RadioGroup>
  <RadioGroupItem value='…' />
</RadioGroup>
```

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs).

### RadioGroup

| Data attribute  | Description                         |
| --------------- | ----------------------------------- |
| `data-disabled` | Present when the group is disabled. |

### RadioGroupItem

| Prop   | Description                                                         |
| ------ | ------------------------------------------------------------------- |
| `size` | `sm`, `md`, `lg` <br /> Circle size: 12, 16 or 20 px. Default `md`. |

| Data attribute   | Description                                          |
| ---------------- | ---------------------------------------------------- |
| `data-checked`   | Present when the option is selected.                 |
| `data-unchecked` | Present when the option is not selected.             |
| `data-disabled`  | Present when the option is disabled.                 |
| `data-readonly`  | Present when the option is read-only.                |
| `data-required`  | Present when the option is required.                 |
| `data-invalid`   | Present when a surrounding `Field` marks it invalid. |

## Caveats

- `RadioGroupItem` has no text. Put each item in a `label` or a horizontal `Field`, and name the group with `aria-label`.
- An item renders a `span`, not an `input`, so `:disabled` never matches; style the disabled look with `[data-disabled]`.
