# Dropdown Menu

A menu of actions that opens from a trigger. Context Menu and Menubar items are the same components.

Built on Base UI [Menu](https://base-ui.com/react/components/menu). Props not listed here pass through.

## Anatomy

```jsx
import {
  DropdownMenu,
  DropdownMenuCheckboxItem,
  DropdownMenuContent,
  DropdownMenuGroup,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuRadioGroup,
  DropdownMenuRadioItem,
  DropdownMenuSeparator,
  DropdownMenuShortcut,
  DropdownMenuSub,
  DropdownMenuSubContent,
  DropdownMenuSubTrigger,
  DropdownMenuTrigger
} from 'uilibs/base/dropdown-menu'

;<DropdownMenu>
  <DropdownMenuTrigger />
  <DropdownMenuContent>
    <DropdownMenuGroup>
      <DropdownMenuLabel />
      <DropdownMenuItem>
        <DropdownMenuShortcut />
      </DropdownMenuItem>
      <DropdownMenuCheckboxItem />
    </DropdownMenuGroup>
    <DropdownMenuSeparator />
    <DropdownMenuRadioGroup>
      <DropdownMenuRadioItem />
    </DropdownMenuRadioGroup>
    <DropdownMenuSub>
      <DropdownMenuSubTrigger />
      <DropdownMenuSubContent>
        <DropdownMenuItem />
      </DropdownMenuSubContent>
    </DropdownMenuSub>
  </DropdownMenuContent>
</DropdownMenu>
```

`DropdownMenuContent` renders the portal and the positioner (`DropdownMenuPortal` is exported only for custom compositions). `DropdownMenuLabel` must sit inside a `DropdownMenuGroup` or `DropdownMenuRadioGroup`, and a radio item inside a `DropdownMenuRadioGroup`.

## Props

Every part except `DropdownMenu`, `DropdownMenuTrigger`, `DropdownMenuGroup`, `DropdownMenuPortal`, `DropdownMenuSub`, and `DropdownMenuRadioGroup` also takes `style`: StyleX styles that replace `className` and `style`. On `DropdownMenuContent` and `DropdownMenuSubContent` it styles the popup.

### DropdownMenuContent

| Prop          | Values                                                         | Default  | Note                                          |
| ------------- | -------------------------------------------------------------- | -------- | --------------------------------------------- |
| `side`        | `top`, `bottom`, `left`, `right`, `inline-end`, `inline-start` | `bottom` | Which side of the trigger the popup opens on. |
| `sideOffset`  | `number` or a function                                         | `4`      | Distance from the trigger in pixels.          |
| `align`       | `start`, `center`, `end`                                       | `start`  | Alignment along the chosen side.              |
| `alignOffset` | `number` or a function                                         | `0`      | Offset along the alignment axis in pixels.    |

### DropdownMenuSubContent

The popup of a submenu. It takes the `DropdownMenuContent` props with different defaults.

| Prop          | Values                                                         | Default | Note                                          |
| ------------- | -------------------------------------------------------------- | ------- | --------------------------------------------- |
| `side`        | `top`, `bottom`, `left`, `right`, `inline-end`, `inline-start` | `right` | Which side of the trigger the popup opens on. |
| `sideOffset`  | `number` or a function                                         | `0`     | Distance from the trigger in pixels.          |
| `align`       | `start`, `center`, `end`                                       | `start` | Alignment along the chosen side.              |
| `alignOffset` | `number` or a function                                         | `-4`    | Offset along the alignment axis in pixels.    |

### DropdownMenuItem

| Prop    | Values                           | Default | Note                                                                              |
| ------- | -------------------------------- | ------- | --------------------------------------------------------------------------------- |
| `color` | `neutral`, `critical`, `primary` | none    | `critical` marks a destructive or irreversible item; `primary` a recommended one. |
| `icon`  | glyph component                  | none    | A glyph before the label, hidden from assistive technology.                       |
| `inset` | `boolean`                        | none    | Indents the item to align with checkbox and radio item labels.                    |

### DropdownMenuSubTrigger

| Prop    | Values    | Default | Note                                                              |
| ------- | --------- | ------- | ----------------------------------------------------------------- |
| `inset` | `boolean` | none    | Indents the trigger to align with checkbox and radio item labels. |

### DropdownMenuLabel

| Prop    | Values    | Default | Note                                                            |
| ------- | --------- | ------- | --------------------------------------------------------------- |
| `inset` | `boolean` | none    | Indents the label to align with checkbox and radio item labels. |
