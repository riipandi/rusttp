# Menubar

A desktop-style bar of menus. Its menu parts are Dropdown Menu's.

## Import

```jsx
import {
  Menubar,
  MenubarCheckboxItem,
  MenubarContent,
  MenubarGroup,
  MenubarItem,
  MenubarLabel,
  MenubarMenu,
  MenubarRadioGroup,
  MenubarRadioItem,
  MenubarSeparator,
  MenubarShortcut,
  MenubarSub,
  MenubarSubContent,
  MenubarSubTrigger,
  MenubarTrigger
} from 'uilibs/base/menubar'
```

Built on Base UI [Menubar](https://base-ui.com/react/components/menubar). Props not listed here pass through.

## Anatomy

- **Menubar:** the bar that holds the menus.
- **MenubarMenu:** one menu: a trigger and its content.
- **MenubarTrigger:** the bar item that opens its menu.
- **MenubarContent:** the popup. It renders the portal and the positioner itself.
- **MenubarGroup**, **MenubarLabel:** a group of items and its heading. The label must sit inside a group or radio group.
- **MenubarItem:** an action. It can hold a `MenubarShortcut`.
- **MenubarShortcut:** the key hint at the end of an item.
- **MenubarCheckboxItem:** an item that toggles on and off, with a check indicator.
- **MenubarRadioGroup**, **MenubarRadioItem:** a set of choices, of which one is chosen.
- **MenubarSeparator:** a divider between items.
- **MenubarSub**, **MenubarSubTrigger**, **MenubarSubContent:** a submenu. The trigger renders the chevron itself.

```jsx
<Menubar>
  <MenubarMenu>
    <MenubarTrigger />
    <MenubarContent>
      <MenubarItem>
        <MenubarShortcut />
      </MenubarItem>
      <MenubarSeparator />
      <MenubarCheckboxItem />
      <MenubarRadioGroup>
        <MenubarRadioItem />
      </MenubarRadioGroup>
      <MenubarSub>
        <MenubarSubTrigger />
        <MenubarSubContent>
          <MenubarItem />
        </MenubarSubContent>
      </MenubarSub>
    </MenubarContent>
  </MenubarMenu>
</Menubar>
```

## Accessibility

The bar is a `menubar` whose triggers are `menuitem`s, and each popup is a `menu`. Every trigger and item needs text or an `aria-label`. The `Keyboard` story walks the keys below, and the `Open` story keeps a menu open so the accessibility check reads it.

| Key                              | Action                                                    |
| -------------------------------- | --------------------------------------------------------- |
| `Tab`                            | Enters the bar on its first trigger.                      |
| `ArrowRight`, `ArrowLeft`        | Move focus between the triggers.                          |
| `Enter`, `Space`, or `ArrowDown` | On a trigger: opens its menu.                             |
| `ArrowDown`, `ArrowUp`           | In an open menu: highlight the next or the previous item. |
| `Home`                           | In an open menu: highlights the first item.               |
| `Escape`                         | Closes the menu and returns focus to its trigger.         |

- Focus moves into the menu when it opens, and the highlighted item has a visible highlight (`data-highlighted`).
- Submenus, typeahead, and the item keys are the Dropdown Menu's: see its page and its `Keyboard` story.
- Keyboard behavior is Base UI's; see the Base UI [Menubar](https://base-ui.com/react/components/menubar) page for the rest.

## API reference

Every part except `MenubarMenu`, `MenubarGroup`, `MenubarSub`, and `MenubarRadioGroup` also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs). On `MenubarContent` and `MenubarSubContent` it styles the popup.

Every part other than `Menubar`, `MenubarTrigger`, and `MenubarContent` is the matching Dropdown Menu part under another name (`MenubarItem` is `DropdownMenuItem`). Their props and data attributes (`color`, `icon`, `inset`, `data-highlighted`, and the rest) are listed on the Dropdown Menu page.

### Menubar

| Prop   | Description                                                                                                      |
| ------ | ---------------------------------------------------------------------------------------------------------------- |
| `size` | `small`, `medium`, `large` <br /> Bar height and type, as the control scale: `medium` is 36px. Default `medium`. |

| Data attribute          | Description                                   |
| ----------------------- | --------------------------------------------- |
| `data-orientation`      | `horizontal` or `vertical`.                   |
| `data-modal`            | Present when the menubar is modal.            |
| `data-has-submenu-open` | Present while any submenu in the bar is open. |

### MenubarTrigger

| Data attribute    | Description                                                            |
| ----------------- | ---------------------------------------------------------------------- |
| `data-popup-open` | Present while its menu is open. The trigger takes a neutral fill then. |
| `data-pressed`    | Present while the trigger is pressed.                                  |
| `data-disabled`   | Present when the trigger is disabled.                                  |

### MenubarContent

The popup. It takes the `DropdownMenuContent` props and data attributes, with other defaults, and it sizes to its content rather than to the trigger.

| Prop          | Description                                                                                                                           |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `side`        | `top`, `bottom`, `left`, `right`, `inline-end`, `inline-start` <br /> Which side of the trigger the popup opens on. Default `bottom`. |
| `sideOffset`  | `number` or a function <br /> Distance from the trigger, in pixels. Default `8`.                                                      |
| `align`       | `start`, `center`, `end` <br /> Alignment along the chosen side. Default `start`.                                                     |
| `alignOffset` | `number` or a function <br /> Offset along the alignment axis, in pixels. Default `-4`.                                               |

## Caveats

- `MenubarTrigger` renders a `menuitem` inside the `menubar` role, not a `button`. Query it by that role.
- The `Playground` and `Open` stories are skipped in WebKit. There axe reports `aria-required-children` on the menubar because Base UI's focus guards lack `aria-hidden`. It is an upstream issue with no component change and the gate runs in Chromium only (audit finding F-12).
