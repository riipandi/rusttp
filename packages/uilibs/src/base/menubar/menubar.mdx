# Menubar

A desktop-style bar of menus. Its menu parts are Dropdown Menu's.

Built on Base UI [Menubar](https://base-ui.com/react/components/menubar). Props not listed here pass through.

## Anatomy

```jsx
import {
  Menubar,
  MenubarCheckboxItem,
  MenubarContent,
  MenubarItem,
  MenubarMenu,
  MenubarRadioGroup,
  MenubarRadioItem,
  MenubarSeparator,
  MenubarShortcut,
  MenubarSub,
  MenubarSubContent,
  MenubarSubTrigger,
  MenubarTrigger
} from 'uilibs/base/menubar'

;<Menubar>
  <MenubarMenu>
    <MenubarTrigger />
    <MenubarContent>
      <MenubarItem>
        <MenubarShortcut />
      </MenubarItem>
      <MenubarSeparator />
      <MenubarCheckboxItem />
      <MenubarRadioGroup>
        <MenubarRadioItem />
      </MenubarRadioGroup>
      <MenubarSub>
        <MenubarSubTrigger />
        <MenubarSubContent>
          <MenubarItem />
        </MenubarSubContent>
      </MenubarSub>
    </MenubarContent>
  </MenubarMenu>
</Menubar>
```

Each `MenubarMenu` holds one trigger and its content. `MenubarContent` renders the portal and the positioner. `MenubarGroup`, `MenubarLabel`, and `MenubarPortal` are also exported.

## Props

Every part except `MenubarMenu`, `MenubarGroup`, `MenubarPortal`, `MenubarSub`, and `MenubarRadioGroup` also takes `style`: StyleX styles that replace `className` and `style`. On `MenubarContent` and `MenubarSubContent` it styles the popup.

Every part other than `Menubar`, `MenubarTrigger`, and `MenubarContent` is the matching Dropdown Menu part (`MenubarItem` is `DropdownMenuItem`), with the same props.

### Menubar

| Prop   | Values           | Default | Note                                                     |
| ------ | ---------------- | ------- | -------------------------------------------------------- |
| `size` | `sm`, `md`, `lg` | `md`    | Bar height and type, as the control scale: `md` is 36px. |

### MenubarContent

The popup. It takes the `DropdownMenuContent` placement props with different defaults.

| Prop          | Values                                                         | Default  | Note                                          |
| ------------- | -------------------------------------------------------------- | -------- | --------------------------------------------- |
| `side`        | `top`, `bottom`, `left`, `right`, `inline-end`, `inline-start` | `bottom` | Which side of the trigger the popup opens on. |
| `sideOffset`  | `number` or a function                                         | `8`      | Distance from the trigger in pixels.          |
| `align`       | `start`, `center`, `end`                                       | `start`  | Alignment along the chosen side.              |
| `alignOffset` | `number` or a function                                         | `-4`     | Offset along the alignment axis in pixels.    |
