# Menubar

A desktop-style bar of menus. Its menus are Dropdown Menu parts.

Wraps Base UI [Menubar](https://base-ui.com/react/components/menubar). Its other props pass through.

`MenubarMenu`, `MenubarGroup`, `MenubarPortal`, `MenubarSub`, `MenubarRadioGroup`, `MenubarItem`, `MenubarCheckboxItem`, `MenubarRadioItem`, `MenubarLabel`, `MenubarSeparator`, `MenubarShortcut`, `MenubarSubTrigger`, and `MenubarSubContent` are the Dropdown Menu parts unchanged, with the same props.

## Menubar

| Prop    | Values           | Default | Note                                                     |
| ------- | ---------------- | ------- | -------------------------------------------------------- |
| `size`  | `sm`, `md`, `lg` | `md`    | Bar height and type, as the control scale: `md` is 36px. |
| `style` | StyleX styles    | none    | Replaces the `className` and `style` props.              |

## MenubarTrigger

| Prop    | Values        | Default | Note                                        |
| ------- | ------------- | ------- | ------------------------------------------- |
| `style` | StyleX styles | none    | Replaces the `className` and `style` props. |

## MenubarContent

The popup. It takes the `DropdownMenuContent` placement props with different defaults.

| Prop          | Values                                                         | Default  | Note                                          |
| ------------- | -------------------------------------------------------------- | -------- | --------------------------------------------- |
| `side`        | `top`, `bottom`, `left`, `right`, `inline-end`, `inline-start` | `bottom` | Which side of the trigger the popup opens on. |
| `sideOffset`  | `number` or a function                                         | `8`      | Distance from the trigger in pixels.          |
| `align`       | `start`, `center`, `end`                                       | `start`  | Alignment along the chosen side.              |
| `alignOffset` | `number` or a function                                         | `-4`     | Offset along the alignment axis in pixels.    |
