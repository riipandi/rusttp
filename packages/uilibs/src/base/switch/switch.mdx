# Switch

An on/off control.

Built on Base UI [Switch](https://base-ui.com/react/components/switch). Props not listed here pass through.

## Anatomy

```jsx
import { Switch } from 'uilibs/base/switch'

;<Switch />
```

`Switch` renders its own thumb. It has no text, so wrap it in a label, pair it with a `FieldLabel`, or set `aria-label`.

## Props

`Switch` also takes `style`: StyleX styles that replace `className` and `style`.

### Switch

| Prop   | Values           | Default | Note                  |
| ------ | ---------------- | ------- | --------------------- |
| `size` | `sm`, `md`, `lg` | `md`    | Track and thumb size. |
