# Switch

An on/off control.

Wraps Base UI [Switch](https://base-ui.com/react/components/switch). Its other props pass through.

## Switch

| Prop    | Values           | Default | Note                                        |
| ------- | ---------------- | ------- | ------------------------------------------- |
| `size`  | `sm`, `md`, `lg` | `md`    | Track and thumb size.                       |
| `style` | StyleX styles    | none    | Replaces the `className` and `style` props. |
