# Tooltip

A hint that appears on hover or focus. It names a control and holds no interactive content; use Popover when it needs any.

## Import

```jsx
import { Tooltip, TooltipContent, TooltipProvider, TooltipTrigger } from 'uilibs/base/tooltip'
```

Built on Base UI [Tooltip](https://base-ui.com/react/components/tooltip). Props not listed here pass through.

## Anatomy

- **TooltipProvider:** sets the open delay for the tooltips below it. Mount it once.
- **Tooltip:** the root. It holds the open state. It is Base UI's `Root` unchanged.
- **TooltipTrigger:** the element that opens the tooltip. It is Base UI's `Trigger` unchanged; `render` swaps in a Button.
- **TooltipContent:** the popup. It renders the portal, the positioner, and the arrow itself.

```jsx
<TooltipProvider>
  <Tooltip>
    <TooltipTrigger />
    <TooltipContent />
  </Tooltip>
</TooltipProvider>
```

## Accessibility

A tooltip is a hint for sighted users: it is not announced as the description of its trigger, so the trigger needs its own accessible name (visible text or `aria-label`) and the tooltip may only repeat it. The `Keyboard` story walks the keys below, and the `Open` story keeps a tooltip open so the accessibility check reads it.

| Key      | Action                                                                    |
| -------- | ------------------------------------------------------------------------- |
| `Tab`    | Focusing `TooltipTrigger` opens the tooltip; moving focus away closes it. |
| `Escape` | Closes the tooltip. Focus stays on the trigger.                           |

- Keyboard behavior is Base UI's; see the Base UI [Tooltip](https://base-ui.com/react/components/tooltip) page for the rest.

## API reference

`TooltipContent` also takes `style`: StyleX styles that replace `className` and `style`. They land on the popup. See [Styling](?path=/docs/styling--docs).

### TooltipProvider

| Prop    | Description                                                                                  |
| ------- | -------------------------------------------------------------------------------------------- |
| `delay` | `number` (ms) <br /> Time before a tooltip opens. Base UI's own default is 600. Default `0`. |

### TooltipTrigger

| Data attribute          | Description                           |
| ----------------------- | ------------------------------------- |
| `data-popup-open`       | Present while its tooltip is open.    |
| `data-trigger-disabled` | Present when the trigger is disabled. |

### TooltipContent

| Prop          | Description                                                                                                                                                          |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `color`       | `neutral`, `inverted`, `dark` <br /> The surface. `inverted` is the foreground color on the page; `dark` is black with white text in both themes. Default `neutral`. |
| `side`        | `top`, `bottom`, `left`, `right`, `inline-end`, `inline-start` <br /> Which side of the trigger the popup sits on. Default `top`.                                    |
| `sideOffset`  | `number` (px) <br /> Gap between the trigger and the popup. Default `4`.                                                                                             |
| `align`       | `start`, `center`, `end` <br /> Alignment along the trigger's edge. Default `center`.                                                                                |
| `alignOffset` | `number` (px) <br /> Shift along the aligned edge. Default `0`.                                                                                                      |

| Data attribute        | Description                                |
| --------------------- | ------------------------------------------ |
| `data-open`           | Present while the tooltip is open.         |
| `data-closed`         | Present once it is closed.                 |
| `data-side`           | The side the popup is on, after any flip.  |
| `data-align`          | `start`, `center`, or `end`.               |
| `data-starting-style` | Present as the popup begins to open.       |
| `data-ending-style`   | Present as the popup closes.               |
| `data-instant`        | Present when animations should be skipped. |

The positioner sets these variables and the popup inherits them.

| CSS variable                              | Description                                     |
| ----------------------------------------- | ----------------------------------------------- |
| `--anchor-width`, `--anchor-height`       | The size of the trigger.                        |
| `--available-width`, `--available-height` | Room between the trigger and the viewport edge. |
| `--transform-origin`                      | The point the popup grows from, for animation.  |

## Caveats

- A disabled native button fires no pointer events, so wrap it in a span and make the span the `TooltipTrigger`.
- Outside a `TooltipProvider`, a trigger uses Base UI's own 600 ms delay, not this library's `0`.
