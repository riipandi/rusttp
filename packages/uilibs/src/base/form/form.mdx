# Form

A native form with consolidated error handling. It validates the Fields inside it and takes external errors, such as from a server action, keyed by Field `name`.

Built on Base UI [Form](https://base-ui.com/react/components/form). Props not listed here pass through.

## Anatomy

```jsx
import { Field, FieldError, FieldLabel } from 'uilibs/base/field'
import { Form } from 'uilibs/base/form'

;<Form>
  <Field name='…'>
    <FieldLabel />
    {/* a control, such as Input */}
    <FieldError />
  </Field>
</Form>
```

Give each `Field` a `name`: the form's `errors` prop is keyed by it.

## Props

`Form` adds only `style`: StyleX styles that replace `className` and `style`.
