# Form

A native form that validates the fields inside it and shows their errors in one place.

## Import

```jsx
import { Field, FieldError, FieldLabel } from 'uilibs/base/field'
import { Form } from 'uilibs/base/form'
```

Built on Base UI [Form](https://base-ui.com/react/components/form). Props not listed here pass through.

## Anatomy

- **Form:** the root `form` element. Fields inside it report their errors to it.
- **Field:** each control sits in a `Field` with a `name`. The form's `errors` prop is keyed by that name, so a server action can set an error on one field.

```jsx
<Form>
  <Field name='…'>
    <FieldLabel />
    {/* a control, such as Input */}
    <FieldError />
  </Field>
</Form>
```

## API reference

`Form` adds no props of its own and sets no data attributes. It also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs).

## Caveats

- A `Field` without a `name` adds no value to the submitted values and cannot receive an external error.
- A control with `type='email'` or `required` is also checked by the browser on submit; pass `noValidate` to the form when a schema should be the only validator.
