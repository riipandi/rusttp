# Collapsible

One panel that expands and collapses.

Built on Base UI [Collapsible](https://base-ui.com/react/components/collapsible). Props not listed here pass through.

## Anatomy

```jsx
import { Collapsible, CollapsibleContent, CollapsibleTrigger } from 'uilibs/base/collapsible'

;<Collapsible>
  <CollapsibleTrigger />
  <CollapsibleContent />
</Collapsible>
```

`CollapsibleTrigger` has no styles of its own: bring your own, for example `render={<Button />}`. `CollapsibleContent` animates open and closed.

## Props

No part adds props. `CollapsibleContent` also takes `style`: StyleX styles that replace `className` and `style`. `Collapsible` and `CollapsibleTrigger` are the Base UI parts unchanged.
