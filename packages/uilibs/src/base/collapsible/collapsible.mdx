# Collapsible

One panel that expands and collapses.

Wraps Base UI [Collapsible](https://base-ui.com/react/components/collapsible). Its other props pass through.

`Collapsible` and `CollapsibleTrigger` are the Base UI parts unchanged. `CollapsibleContent` takes only `style` (StyleX styles that replace `className` and `style`).
