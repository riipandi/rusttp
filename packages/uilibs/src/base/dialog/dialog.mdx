# Dialog

A modal popup over the page, for content the user may dismiss; use Alert Dialog when the user must answer.

## Import

```jsx
import {
  Dialog,
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogOverlay,
  DialogPortal,
  DialogTitle,
  DialogTrigger
} from 'uilibs/base/dialog'
```

Built on Base UI [Dialog](https://base-ui.com/react/components/dialog). Props not listed here pass through. `Dialog`, `DialogTrigger`, `DialogPortal`, and `DialogClose` are the Base UI parts unchanged.

## Anatomy

- **Dialog:** the root. It holds the open state.
- **DialogTrigger:** the button that opens the dialog.
- **DialogContent:** the popup. It renders the portal, the overlay, and a close button itself.
- **DialogHeader:** a container for the title and description.
- **DialogTitle:** the dialog's heading and accessible name.
- **DialogDescription:** a short description under the title.
- **DialogFooter:** a container for the actions.
- **DialogClose:** a button that closes the dialog.
- **DialogPortal** and **DialogOverlay:** the portal and the backdrop. They are exported only for custom compositions.

```jsx
<Dialog>
  <DialogTrigger />
  <DialogContent>
    <DialogHeader>
      <DialogTitle />
      <DialogDescription />
    </DialogHeader>
    <DialogFooter>
      <DialogClose />
    </DialogFooter>
  </DialogContent>
</Dialog>
```

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs). On `DialogContent` it styles the popup.

### DialogTrigger

| Data attribute    | Description                           |
| ----------------- | ------------------------------------- |
| `data-popup-open` | Present while the dialog is open.     |
| `data-disabled`   | Present when the trigger is disabled. |

### DialogOverlay

| Prop             | Description                                                           |
| ---------------- | --------------------------------------------------------------------- |
| `blurredOverlay` | `boolean` <br /> Blurs the page behind the backdrop. Default `false`. |

| Data attribute        | Description                           |
| --------------------- | ------------------------------------- |
| `data-open`           | Present while the dialog is open.     |
| `data-closed`         | Present while the dialog is closed.   |
| `data-starting-style` | Present as the dialog begins to open. |
| `data-ending-style`   | Present as the dialog closes.         |

### DialogContent

| Prop              | Description                                                                                   |
| ----------------- | --------------------------------------------------------------------------------------------- |
| `size`            | `sm`, `md` <br /> The width: `md` is 32rem, `sm` is 24rem. Default `md`.                      |
| `blurredOverlay`  | `boolean` <br /> Blurs the page behind the backdrop. Default `false`.                         |
| `showCloseButton` | `boolean` <br /> Shows the built-in close button. Default `true`.                             |
| `labels`          | `{ close: string }` <br /> The accessible name of the built-in close button. Default `Close`. |

| Data attribute            | Description                                          |
| ------------------------- | ---------------------------------------------------- |
| `data-open`               | Present while the dialog is open.                    |
| `data-closed`             | Present while the dialog is closed.                  |
| `data-starting-style`     | Present as the dialog begins to open.                |
| `data-ending-style`       | Present as the dialog closes.                        |
| `data-nested`             | Present when the dialog is nested in another dialog. |
| `data-nested-dialog-open` | Present when another dialog is open inside it.       |

| CSS variable       | Description                            |
| ------------------ | -------------------------------------- |
| `--nested-dialogs` | How many dialogs are nested inside it. |

### DialogClose

| Data attribute  | Description                          |
| --------------- | ------------------------------------ |
| `data-disabled` | Present when the button is disabled. |

## Caveats

- `DialogContent` already renders `DialogPortal` and `DialogOverlay`; do not wrap it in them.
- With `showCloseButton={false}`, give the dialog a `DialogClose`, or the pointer has no way to dismiss it.
- `blurredOverlay` on `DialogContent` is forwarded to its overlay. Set it on `DialogOverlay` only in a custom composition.
- The popup has no maximum height or scrolling of its own. For long content, set a max height in `style` and scroll an inner element, as in the Scrollable example.
