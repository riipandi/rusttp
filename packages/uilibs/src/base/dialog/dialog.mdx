# Dialog

A modal popup over the page, for content the user may dismiss; use Alert Dialog when the user must answer.

## Import

```jsx
import {
  Dialog,
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogOverlay,
  DialogTitle,
  DialogTrigger
} from 'uilibs/base/dialog'
```

Built on Base UI [Dialog](https://base-ui.com/react/components/dialog). Props not listed here pass through. `Dialog`, `DialogTrigger`, and `DialogClose` are the Base UI parts unchanged.

## Anatomy

- **Dialog:** the root. It holds the open state.
- **DialogTrigger:** the button that opens the dialog.
- **DialogContent:** the popup. It renders the portal, the overlay, and a close button itself.
- **DialogHeader:** a container for the title and description.
- **DialogTitle:** the dialog's heading and accessible name.
- **DialogDescription:** a short description under the title.
- **DialogFooter:** a container for the actions.
- **DialogClose:** a button that closes the dialog.
- **DialogOverlay:** the backdrop. It is exported only for custom compositions.

```jsx
<Dialog>
  <DialogTrigger />
  <DialogContent>
    <DialogHeader>
      <DialogTitle />
      <DialogDescription />
    </DialogHeader>
    <DialogFooter>
      <DialogClose />
    </DialogFooter>
  </DialogContent>
</Dialog>
```

## Accessibility

The popup is a `dialog` named by `DialogTitle` and described by `DialogDescription`. Always render a `DialogTitle`: without it the dialog has no name. While it is open, the page behind it is inert, Tab stays inside the popup, and Escape closes it. The `Keyboard` story walks this path, and the `Open` story keeps the popup open so the accessibility check reads it.

| Key                     | Action                                                                                  |
| ----------------------- | --------------------------------------------------------------------------------------- |
| `Enter` or `Space`      | On `DialogTrigger`: opens the dialog. On `DialogClose`: closes it.                      |
| `Tab` and `Shift + Tab` | Moves focus between the controls inside the popup. It wraps and never leaves the popup. |
| `Escape`                | Closes the dialog and returns focus to the trigger.                                     |

- Focus moves to the first focusable control in the popup, in document order (a footer button when the header holds none), not to the built-in close button, which renders last. Pass `initialFocus` to `DialogContent` to pick another control.
- The built-in close button is named by `labels.close`. A `DialogClose` you render yourself needs visible text or an `aria-label`.
- Keyboard behavior is Base UI's; see the Base UI [Dialog](https://base-ui.com/react/components/dialog) page for focus options such as `initialFocus` and `finalFocus`.

## API reference

Every part also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs). On `DialogContent` it styles the popup.

### DialogTrigger

| Data attribute    | Description                           |
| ----------------- | ------------------------------------- |
| `data-popup-open` | Present while the dialog is open.     |
| `data-disabled`   | Present when the trigger is disabled. |

### DialogOverlay

| Prop             | Description                                                           |
| ---------------- | --------------------------------------------------------------------- |
| `blurredOverlay` | `boolean` <br /> Blurs the page behind the backdrop. Default `false`. |

| Data attribute        | Description                           |
| --------------------- | ------------------------------------- |
| `data-open`           | Present while the dialog is open.     |
| `data-closed`         | Present while the dialog is closed.   |
| `data-starting-style` | Present as the dialog begins to open. |
| `data-ending-style`   | Present as the dialog closes.         |

### DialogContent

| Prop              | Description                                                                                   |
| ----------------- | --------------------------------------------------------------------------------------------- |
| `size`            | `small`, `medium` <br /> The width: `medium` is 32rem, `small` is 24rem. Default `medium`.    |
| `blurredOverlay`  | `boolean` <br /> Blurs the page behind the backdrop. Default `false`.                         |
| `showCloseButton` | `boolean` <br /> Shows the built-in close button. Default `true`.                             |
| `labels`          | `{ close: string }` <br /> The accessible name of the built-in close button. Default `Close`. |

| Data attribute            | Description                                          |
| ------------------------- | ---------------------------------------------------- |
| `data-open`               | Present while the dialog is open.                    |
| `data-closed`             | Present while the dialog is closed.                  |
| `data-starting-style`     | Present as the dialog begins to open.                |
| `data-ending-style`       | Present as the dialog closes.                        |
| `data-nested`             | Present when the dialog is nested in another dialog. |
| `data-nested-dialog-open` | Present when another dialog is open inside it.       |

| CSS variable       | Description                            |
| ------------------ | -------------------------------------- |
| `--nested-dialogs` | How many dialogs are nested inside it. |

### DialogClose

| Data attribute  | Description                          |
| --------------- | ------------------------------------ |
| `data-disabled` | Present when the button is disabled. |

## Caveats

- `DialogContent` already renders its portal and `DialogOverlay`; do not wrap it in them.
- With `showCloseButton={false}`, give the dialog a `DialogClose`, or the pointer has no way to dismiss it.
- `blurredOverlay` on `DialogContent` is forwarded to its overlay. Set it on `DialogOverlay` only in a custom composition.
- A popup taller than the window scrolls as a whole with its backdrop, so the title and the footer can always be reached. To keep the header and footer in place and scroll only the body, set a max height in `style` and scroll an inner element, as in the Scrollable example.
