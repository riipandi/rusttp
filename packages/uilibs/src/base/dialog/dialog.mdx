# Dialog

A modal popup over the page, for content the user may dismiss. Use Alert Dialog when the user must answer.

Built on Base UI [Dialog](https://base-ui.com/react/components/dialog). Props not listed here pass through.

## Anatomy

```jsx
import {
  Dialog,
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger
} from 'uilibs/base/dialog'

;<Dialog>
  <DialogTrigger />
  <DialogContent>
    <DialogHeader>
      <DialogTitle />
      <DialogDescription />
    </DialogHeader>
    <DialogFooter>
      <DialogClose />
    </DialogFooter>
  </DialogContent>
</Dialog>
```

`DialogContent` renders the portal, the overlay, and a close button. `DialogPortal` and `DialogOverlay` are exported only for custom compositions.

## Props

Every part also takes `style`: StyleX styles that replace `className` and `style`.

### DialogContent

| Prop              | Values      | Default | Note                                          |
| ----------------- | ----------- | ------- | --------------------------------------------- |
| `size`            | `sm`, `md`  | `md`    | Width: `md` is 32rem, `sm` is 24rem.          |
| `blurredOverlay`  | `boolean`   | `false` | Blurs the page behind the backdrop.           |
| `showCloseButton` | `boolean`   | `true`  | Shows the built-in close button.              |
| `labels`          | `{ close }` | `Close` | Accessible name of the built-in close button. |

### DialogOverlay

| Prop             | Values    | Default | Note                                |
| ---------------- | --------- | ------- | ----------------------------------- |
| `blurredOverlay` | `boolean` | `false` | Blurs the page behind the backdrop. |

### CloseButton

The dismiss button inside `DialogContent`, shared with Sheet and Toast. It takes the props of a `button`.

| Prop     | Values      | Default | Note                           |
| -------- | ----------- | ------- | ------------------------------ |
| `labels` | `{ close }` | `Close` | Accessible name of the button. |
