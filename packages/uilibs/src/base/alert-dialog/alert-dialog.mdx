# Alert Dialog

A modal dialog that needs an answer before the user continues, for destructive or high-risk confirmations. Use Dialog for content the user may dismiss.

Built on Base UI [Alert Dialog](https://base-ui.com/react/components/alert-dialog). Props not listed here pass through.

## Anatomy

```jsx
import {
  AlertDialog,
  AlertDialogAction,
  AlertDialogCancel,
  AlertDialogContent,
  AlertDialogDescription,
  AlertDialogFooter,
  AlertDialogHeader,
  AlertDialogMedia,
  AlertDialogTitle,
  AlertDialogTrigger
} from 'uilibs/base/alert-dialog'

;<AlertDialog>
  <AlertDialogTrigger />
  <AlertDialogContent>
    <AlertDialogHeader>
      <AlertDialogMedia />
      <AlertDialogTitle />
      <AlertDialogDescription />
    </AlertDialogHeader>
    <AlertDialogFooter>
      <AlertDialogCancel />
      <AlertDialogAction />
    </AlertDialogFooter>
  </AlertDialogContent>
</AlertDialog>
```

`AlertDialogContent` renders the portal and the overlay, and has no close button. `AlertDialogMedia` is optional. `AlertDialogPortal` and `AlertDialogOverlay` are exported only for custom compositions.

## Props

Every part except `AlertDialog`, `AlertDialogTrigger`, and `AlertDialogPortal` also takes `style`: StyleX styles that replace `className` and `style`. On `AlertDialogContent` it styles the popup. On `AlertDialogAction` and `AlertDialogCancel` it styles the button.

### AlertDialogContent

| Prop   | Values     | Default | Note                 |
| ------ | ---------- | ------- | -------------------- |
| `size` | `sm`, `md` | `md`    | Width of the dialog. |

### AlertDialogAction

The confirming button. It closes the dialog after its `onClick` runs; call `event.preventBaseUIHandler()` there to keep it open while work runs.

| Prop      | Values                                                                      | Default          | Note                                                             |
| --------- | --------------------------------------------------------------------------- | ---------------- | ---------------------------------------------------------------- |
| `variant` | `solid`, `faded`, `outline`, `ghost`                                        | `solid`          | The fill, as on Button.                                          |
| `color`   | `primary`, `neutral`, `critical`, `positive`, `warning`, `media`, `inherit` | Button's default | The role, as on Button. Use `critical` for a destructive action. |
| `size`    | `xs`, `sm`, `md`, `lg`, `icon-xs`, `icon-sm`, `icon-md`, `icon-lg`          | `md`             | As on Button.                                                    |
| `loading` | `boolean`                                                                   | `false`          | As on Button.                                                    |

### AlertDialogCancel

The dismissing button. It closes the dialog like `AlertDialogAction`.

| Prop      | Values                                                                      | Default          | Note                    |
| --------- | --------------------------------------------------------------------------- | ---------------- | ----------------------- |
| `variant` | `solid`, `faded`, `outline`, `ghost`                                        | `outline`        | The fill, as on Button. |
| `color`   | `primary`, `neutral`, `critical`, `positive`, `warning`, `media`, `inherit` | Button's default | The role, as on Button. |
| `size`    | `xs`, `sm`, `md`, `lg`, `icon-xs`, `icon-sm`, `icon-md`, `icon-lg`          | `md`             | As on Button.           |
| `loading` | `boolean`                                                                   | `false`          | As on Button.           |
