# Alert Dialog

A modal dialog that needs an answer before the user continues, for destructive or high-risk confirmations. Use Dialog for content the user may dismiss.

## Import

```jsx
import {
  AlertDialog,
  AlertDialogAction,
  AlertDialogCancel,
  AlertDialogContent,
  AlertDialogDescription,
  AlertDialogFooter,
  AlertDialogHeader,
  AlertDialogMedia,
  AlertDialogOverlay,
  AlertDialogPortal,
  AlertDialogTitle,
  AlertDialogTrigger
} from 'uilibs/base/alert-dialog'
```

Built on Base UI [Alert Dialog](https://base-ui.com/react/components/alert-dialog). Props not listed here pass through.

## Anatomy

- **AlertDialog:** the root. It holds the open state.
- **AlertDialogTrigger:** the button that opens the dialog.
- **AlertDialogContent:** the popup. It renders the portal and the overlay itself, and has no close button.
- **AlertDialogHeader:** groups the media, title, and description.
- **AlertDialogMedia:** an icon tile above the title. Optional.
- **AlertDialogTitle:** the dialog's name.
- **AlertDialogDescription:** what the user is confirming.
- **AlertDialogFooter:** holds the buttons.
- **AlertDialogCancel:** a button that closes the dialog.
- **AlertDialogAction:** the confirming button. It also closes the dialog.
- **AlertDialogPortal**, **AlertDialogOverlay:** exported only for custom compositions. `AlertDialogContent` already includes both.

```jsx
<AlertDialog>
  <AlertDialogTrigger />
  <AlertDialogContent>
    <AlertDialogHeader>
      <AlertDialogMedia />
      <AlertDialogTitle />
      <AlertDialogDescription />
    </AlertDialogHeader>
    <AlertDialogFooter>
      <AlertDialogCancel />
      <AlertDialogAction />
    </AlertDialogFooter>
  </AlertDialogContent>
</AlertDialog>
```

## API reference

Every part except `AlertDialog`, `AlertDialogTrigger`, and `AlertDialogPortal` also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs). On `AlertDialogContent` it styles the popup; on `AlertDialogAction` and `AlertDialogCancel` it styles the button.

### AlertDialogTrigger

| Data attribute    | Description                           |
| ----------------- | ------------------------------------- |
| `data-popup-open` | Present while the dialog is open.     |
| `data-disabled`   | Present when the trigger is disabled. |

### AlertDialogOverlay

| Prop             | Description                                                           |
| ---------------- | --------------------------------------------------------------------- |
| `blurredOverlay` | `boolean` <br /> Blurs the page behind the backdrop. Default `false`. |

| Data attribute        | Description                           |
| --------------------- | ------------------------------------- |
| `data-open`           | Present while the dialog is open.     |
| `data-closed`         | Present while the dialog is closed.   |
| `data-starting-style` | Present as the dialog begins to open. |
| `data-ending-style`   | Present as the dialog closes.         |

### AlertDialogContent

| Prop             | Description                                                           |
| ---------------- | --------------------------------------------------------------------- |
| `size`           | `sm`, `md` <br /> The width of the dialog. Default `md`.              |
| `blurredOverlay` | `boolean` <br /> Blurs the page behind the backdrop. Default `false`. |

| Data attribute            | Description                                       |
| ------------------------- | ------------------------------------------------- |
| `data-open`               | Present while the dialog is open.                 |
| `data-closed`             | Present while the dialog is closed.               |
| `data-starting-style`     | Present as the dialog begins to open.             |
| `data-ending-style`       | Present as the dialog closes.                     |
| `data-nested`             | Present when the dialog is inside another dialog. |
| `data-nested-dialog-open` | Present when another dialog is open inside it.    |

| CSS variable       | Description                                  |
| ------------------ | -------------------------------------------- |
| `--nested-dialogs` | How many dialogs are nested inside this one. |

### AlertDialogAction

| Prop      | Description                                                                                                                                                              |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `variant` | `solid`, `faded`, `outline`, `ghost` <br /> The fill, as on Button. Default `solid`.                                                                                     |
| `color`   | `primary`, `neutral`, `critical`, `positive`, `warning`, `media`, `inherit` <br /> The role, as on Button. Use `critical` for a destructive action. Default is Button's. |
| `size`    | `xs`, `sm`, `md`, `lg` <br /> As on Button. Default `md`.                                                                                                                |
| `loading` | `boolean` <br /> Shows a spinner over the label, as on Button.                                                                                                           |

### AlertDialogCancel

| Prop      | Description                                                                                                                     |
| --------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `variant` | `solid`, `faded`, `outline`, `ghost` <br /> The fill, as on Button. Default `outline`.                                          |
| `color`   | `primary`, `neutral`, `critical`, `positive`, `warning`, `media`, `inherit` <br /> The role, as on Button. Default is Button's. |
| `size`    | `xs`, `sm`, `md`, `lg` <br /> As on Button. Default `md`.                                                                       |
| `loading` | `boolean` <br /> Shows a spinner over the label, as on Button.                                                                  |

## Caveats

- `AlertDialogAction` and `AlertDialogCancel` both close the dialog. To keep it open while work runs, call `event.preventBaseUIHandler()` in the action's `onClick` and close through the dialog's `open` state later.
- `AlertDialogContent` already wraps itself in a portal with an overlay. Do not add `AlertDialogPortal` around it.
- `md` is wider than `sm` only at 660px and up. Below that both sizes have the same width.
