# Alert Dialog

A dialog that needs a user response, for destructive or high-risk confirmations.

Wraps Base UI [Alert Dialog](https://base-ui.com/react/components/alert-dialog). Its other props pass through.

`AlertDialog`, `AlertDialogTrigger`, and `AlertDialogPortal` are the Base UI parts unchanged.

`AlertDialogOverlay`, `AlertDialogHeader`, `AlertDialogMedia`, `AlertDialogFooter`, `AlertDialogTitle`, and `AlertDialogDescription` take only `style` (StyleX styles that replace `className` and `style`).

## AlertDialogContent

Renders the portal and the overlay around the popup.

| Prop    | Values        | Default | Note                                                     |
| ------- | ------------- | ------- | -------------------------------------------------------- |
| `size`  | `sm`, `md`    | `md`    | Width of the dialog.                                     |
| `style` | StyleX styles | none    | Replaces the `className` and `style` props on the popup. |

## AlertDialogAction

The confirming button. It closes the dialog after its `onClick` runs; call `event.preventBaseUIHandler()` there to keep it open while work runs.

| Prop      | Values                                                                      | Default          | Note                                                             |
| --------- | --------------------------------------------------------------------------- | ---------------- | ---------------------------------------------------------------- |
| `variant` | `solid`, `faded`, `outline`, `ghost`                                        | `solid`          | The fill, as on Button.                                          |
| `color`   | `primary`, `neutral`, `critical`, `positive`, `warning`, `media`, `inherit` | Button's default | The role, as on Button. Use `critical` for a destructive action. |
| `size`    | `xs`, `sm`, `md`, `lg`, `icon-xs`, `icon-sm`, `icon-md`, `icon-lg`          | `md`             | As on Button.                                                    |
| `loading` | `boolean`                                                                   | `false`          | As on Button.                                                    |
| `style`   | StyleX styles                                                               | none             | Replaces the `className` and `style` props.                      |

## AlertDialogCancel

The dismissing button. It closes the dialog like `AlertDialogAction`.

| Prop      | Values                                                                      | Default          | Note                                        |
| --------- | --------------------------------------------------------------------------- | ---------------- | ------------------------------------------- |
| `variant` | `solid`, `faded`, `outline`, `ghost`                                        | `outline`        | The fill, as on Button.                     |
| `color`   | `primary`, `neutral`, `critical`, `positive`, `warning`, `media`, `inherit` | Button's default | The role, as on Button.                     |
| `size`    | `xs`, `sm`, `md`, `lg`, `icon-xs`, `icon-sm`, `icon-md`, `icon-lg`          | `md`             | As on Button.                               |
| `loading` | `boolean`                                                                   | `false`          | As on Button.                               |
| `style`   | StyleX styles                                                               | none             | Replaces the `className` and `style` props. |
