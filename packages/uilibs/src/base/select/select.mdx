# Select

A single-choice list in a popup. Choose it over Combobox for a short fixed list the user does not search.

## Import

```jsx
import {
  Select,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectLabel,
  SelectSeparator,
  SelectTrigger,
  SelectValue
} from 'uilibs/base/select'
```

Built on Base UI [Select](https://base-ui.com/react/components/select). `Select`, `SelectValue` and `SelectGroup` are Base UI's parts, re-exported unchanged. Props not listed here pass through.

## Anatomy

- **Select:** the root. It holds the chosen value; pass `items` for the value to show its label.
- **SelectTrigger:** the button that opens the list. It renders its chevron itself.
- **SelectValue:** the chosen value, or a placeholder, inside the trigger.
- **SelectContent:** the popup. It renders the portal, the positioner, the list and the scroll arrows itself.
- **SelectItem:** one option. It renders its text wrapper and check mark itself.
- **SelectGroup:** a set of items under one label.
- **SelectLabel:** the heading of a group.
- **SelectSeparator:** a line between groups.

```jsx
<Select>
  <SelectTrigger>
    <SelectValue />
  </SelectTrigger>
  <SelectContent>
    <SelectItem value='…' />
    <SelectGroup>
      <SelectSeparator />
      <SelectLabel />
      <SelectItem value='…' />
    </SelectGroup>
  </SelectContent>
</Select>
```

## API reference

Every part except `Select`, `SelectValue` and `SelectGroup` also takes `style`: StyleX styles that replace `className` and `style`. On `SelectContent` it lands on the popup. See [Styling](?path=/docs/styling--docs).

### SelectTrigger

| Prop      | Description                                                                                               |
| --------- | --------------------------------------------------------------------------------------------------------- |
| `size`    | `small`, `medium`, `large` <br /> Height and type: 32, 36 or 40 px. Default `medium`.                     |
| `variant` | `outline`, `faded`, `ghost`, `headless` <br /> The box around the trigger. Default `outline`.             |
| `icon`    | a glyph component <br /> A glyph before the value. It is decoration and hidden from assistive technology. |

| Data attribute     | Description                                          |
| ------------------ | ---------------------------------------------------- |
| `data-popup-open`  | Present while the popup is open.                     |
| `data-placeholder` | Present when no value is chosen.                     |
| `data-disabled`    | Present when the select is disabled.                 |
| `data-readonly`    | Present when the select is read-only.                |
| `data-required`    | Present when the select is required.                 |
| `data-invalid`     | Present when a surrounding `Field` marks it invalid. |
| `data-pressed`     | Present while the trigger is pressed.                |

### SelectContent

The positioning props go to the positioner.

| Prop                   | Description                                                                                                                           |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `side`                 | `top`, `bottom`, `left`, `right`, `inline-start`, `inline-end` <br /> Which side of the trigger the popup opens on. Default `bottom`. |
| `sideOffset`           | `number` or a function <br /> Gap from the trigger, in px. Default `4`.                                                               |
| `align`                | `start`, `center`, `end` <br /> Alignment along the side. Default `center`.                                                           |
| `alignOffset`          | `number` or a function <br /> Shift along the alignment axis, in px. Default `0`.                                                     |
| `alignItemWithTrigger` | `boolean` <br /> Overlaps the trigger so the selected text lines up with the value. Default `false`.                                  |

| Data attribute        | Description                                                                       |
| --------------------- | --------------------------------------------------------------------------------- |
| `data-open`           | Present while the popup is open.                                                  |
| `data-side`           | The side of the trigger the popup is on, or `none` when aligned with the trigger. |
| `data-align`          | `start`, `center` or `end`.                                                       |
| `data-starting-style` | Present as the popup begins to open.                                              |
| `data-ending-style`   | Present as the popup closes.                                                      |

| CSS variable         | Description                                                                          |
| -------------------- | ------------------------------------------------------------------------------------ |
| `--anchor-width`     | The trigger's width. The popup is set to this width.                                 |
| `--anchor-height`    | The trigger's height.                                                                |
| `--available-width`  | Space between the trigger and the viewport edge, horizontally.                       |
| `--available-height` | Space between the trigger and the viewport edge. The popup's height is capped by it. |
| `--transform-origin` | The point the popup grows from, for animations.                                      |

### SelectItem

| Data attribute     | Description                            |
| ------------------ | -------------------------------------- |
| `data-selected`    | Present while the item is selected.    |
| `data-highlighted` | Present while the item is highlighted. |
| `data-disabled`    | Present when the item is disabled.     |

### SelectSeparator

| Data attribute     | Description                 |
| ------------------ | --------------------------- |
| `data-orientation` | `horizontal` or `vertical`. |

## Caveats

- Name a standalone `SelectTrigger` with `aria-label` or `aria-labelledby`; it shows only the value or placeholder. Inside a `Field` the `FieldLabel` names it.
- With `alignItemWithTrigger` the popup only fades out and skips the scale-in pose, because the overlay repositions on open.
- The CSS variables are set on the positioner that `SelectContent` renders, so the popup and its children inherit them.
