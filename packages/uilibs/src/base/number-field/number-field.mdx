# Number Field

A numeric input with increment and decrement steppers and an optional scrub area.

## Import

```jsx
import {
  NumberField,
  NumberFieldDecrement,
  NumberFieldGroup,
  NumberFieldIncrement,
  NumberFieldInput,
  NumberFieldScrubArea,
  NumberFieldScrubAreaCursor
} from 'uilibs/base/number-field'
```

Built on Base UI [Number Field](https://base-ui.com/react/components/number-field). Props not listed here pass through.

## Anatomy

- **NumberField:** the root. It holds the value and passes `size` and `variant` down to the group and its steppers.
- **NumberFieldGroup:** the bordered box around the input and the steppers. With no children it renders the input and both steppers itself.
- **NumberFieldInput:** the text input.
- **NumberFieldDecrement:** the button that lowers the value.
- **NumberFieldIncrement:** the button that raises the value.
- **NumberFieldScrubArea:** optional. An area the user drags to change the value. Base UI's part, re-exported unchanged.
- **NumberFieldScrubAreaCursor:** optional. A custom cursor shown while scrubbing. Base UI's part, re-exported unchanged.

```jsx
<NumberField>
  <NumberFieldScrubArea>
    <NumberFieldScrubAreaCursor />
  </NumberFieldScrubArea>
  <NumberFieldGroup>
    <NumberFieldDecrement />
    <NumberFieldInput />
    <NumberFieldIncrement />
  </NumberFieldGroup>
</NumberField>
```

Most uses are `<NumberFieldGroup />` alone.

## API reference

Every part except `NumberFieldScrubArea` and `NumberFieldScrubAreaCursor` also takes `style`: StyleX styles that replace `className` and `style`. See [Styling](?path=/docs/styling--docs).

### NumberField

| Prop      | Description                                                                                 |
| --------- | ------------------------------------------------------------------------------------------- |
| `size`    | `sm`, `md`, `lg` <br /> Height and type. Default `md`.                                      |
| `variant` | `outline`, `faded`, `ghost`, `headless` <br /> The box around the field. Default `outline`. |

| Data attribute   | Description                                           |
| ---------------- | ----------------------------------------------------- |
| `data-scrubbing` | Present while the value is being scrubbed.            |
| `data-disabled`  | Present when the field is disabled.                   |
| `data-readonly`  | Present when the field is read-only.                  |
| `data-required`  | Present when the field is required.                   |
| `data-invalid`   | Present when a surrounding `Field` marks it invalid.  |
| `data-filled`    | Present when the field has a value, inside a `Field`. |
| `data-focused`   | Present while the field has focus, inside a `Field`.  |

### NumberFieldGroup

| Prop       | Description                                                                                                       |
| ---------- | ----------------------------------------------------------------------------------------------------------------- |
| `controls` | `stacked`, `sides` <br /> Where the built-in steppers sit. Ignored when you pass children. Default `stacked`.     |
| `labels`   | `{ increase, decrease }` <br /> The accessible names of the built-in steppers. Default `Increase` and `Decrease`. |

It carries the same data attributes as `NumberField`.

### NumberFieldInput

It carries the same data attributes as `NumberField`.

### NumberFieldDecrement

| Prop       | Description                                                                                                            |
| ---------- | ---------------------------------------------------------------------------------------------------------------------- |
| `icon`     | `chevron-down`, `minus` <br /> The built-in glyph. Default `chevron-down` when stacked, otherwise `minus`.             |
| `controls` | `stacked`, `sides` <br /> Styles the button for its place: in the group's stack, or beside the input. Default `sides`. |

It carries the same data attributes as `NumberField`.

### NumberFieldIncrement

| Prop       | Description                                                                                                            |
| ---------- | ---------------------------------------------------------------------------------------------------------------------- |
| `icon`     | `chevron-up`, `plus` <br /> The built-in glyph. Default `chevron-up` when stacked, otherwise `plus`.                   |
| `controls` | `stacked`, `sides` <br /> Styles the button for its place: in the group's stack, or beside the input. Default `sides`. |

It carries the same data attributes as `NumberField`.

## Caveats

- Name the field with a `Label` or a `FieldLabel`; the input has no text of its own.
- `controls` and `labels` on `NumberFieldGroup` apply only to the built-in steppers. Steppers you place as children need their own `aria-label`, and `controls='stacked'` for the stacked look.
