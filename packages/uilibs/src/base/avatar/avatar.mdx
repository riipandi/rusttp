# Avatar

An image with a fallback. `variant` and `color` tint the fallback.

Built on Base UI [Avatar](https://base-ui.com/react/components/avatar). Props not listed here pass through.

## Anatomy

```jsx
import {
  Avatar,
  AvatarBadge,
  AvatarFallback,
  AvatarGroup,
  AvatarGroupCount,
  AvatarImage
} from 'uilibs/base/avatar'

<Avatar>
  <AvatarImage />
  <AvatarFallback />
  <AvatarBadge />
</Avatar>

<AvatarGroup>
  <Avatar />
  <AvatarGroupCount />
</AvatarGroup>
```

`AvatarFallback` shows when the image is missing or fails to load. `AvatarBadge` is optional and sits at the bottom-right corner; `AvatarGroup` overlaps its children.

## Props

Every part also takes `style`: StyleX styles that replace `className` and `style`.

### Avatar

| Prop      | Values                                                  | Default   | Note                                 |
| --------- | ------------------------------------------------------- | --------- | ------------------------------------ |
| `size`    | `sm`, `md`, `lg`                                        | `md`      | Width and height.                    |
| `variant` | `faded`, `solid`                                        | `faded`   | The fallback's fill.                 |
| `color`   | `neutral`, `primary`, `positive`, `warning`, `critical` | `neutral` | The fallback's role color.           |
| `squared` | `boolean`                                               | `false`   | Rounded corners instead of a circle. |

### AvatarGroupCount

A trailing "+N" indicator, rendered as a `span`.

| Prop   | Values           | Default | Note                        |
| ------ | ---------------- | ------- | --------------------------- |
| `size` | `sm`, `md`, `lg` | `md`    | Matches the `Avatar` sizes. |
