# Toggle Group

A group of toggles that share one look.

Built on Base UI [Toggle Group](https://base-ui.com/react/components/toggle-group). Props not listed here pass through.

## Anatomy

```jsx
import { ToggleGroup, ToggleGroupItem } from 'uilibs/base/toggle-group'

;<ToggleGroup>
  <ToggleGroupItem value='…' />
</ToggleGroup>
```

Each item needs a `value`. Pressing an item releases the others unless the group sets `multiple`. An item with only an icon needs an `aria-label`.

## Props

Both parts also take `style`: StyleX styles that replace `className` and `style`.

### ToggleGroup

| Prop              | Values                                                  | Default           | Note                                                 |
| ----------------- | ------------------------------------------------------- | ----------------- | ---------------------------------------------------- |
| `variant`         | `ghost`, `outline`, `solid`                             | `ghost`           | The fill of the items at rest.                       |
| `selectedVariant` | `ghost`, `outline`, `solid`                             | follows `variant` | The fill of an item's pressed state, as on `Toggle`. |
| `selectedColor`   | `neutral`, `primary`, `critical`, `positive`, `warning` | `neutral`         | The color of an item's pressed state.                |
| `size`            | `xs`, `sm`, `md`, `lg`                                  | `md`              | Height of the items.                                 |
| `spacing`         | `gap`, `joined`                                         | `gap`             | `joined` fuses the items into one segmented control. |

### ToggleGroupItem

Takes the `Toggle` props. `variant`, `selectedVariant`, `selectedColor`, and `size` default to the group's values.
