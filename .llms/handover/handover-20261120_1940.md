## Non-obvious facts and traps (not derivable from the diff)

- **StyleX shorthand vs longhand**: a `paddingInline` shorthand in one style object loses to `paddingInlineStart/End` longhands in another, regardless of order. This caused the collapsed sidebar header to sit 6px off-center. Override with longhands.
- **Separator width**: `uilibs` `Separator` has `width: 100%`; with a side margin it overflows its container. Use `width: 'auto'` (done in `nav-sheet.stylex.ts` and `sidebar.stylex.ts`).
- **Tooltips**: Base UI tooltips default to a 600ms delay; `TooltipProvider` (delay 0) makes them instant. The collapsed sidebar wraps its nav in one.
- **Tooltip arrow** is an SVG (12x6) rotated per `data-side`; offsets for left/right are `-(8+1)px` because the rotated box swaps its axes. Verified by measuring in Chromium, not by eye.
- **TanStack devtools**: the shell reads `config` once at creation and saved settings (`localStorage.tanstack_devtools_settings`) outrank it, so the theme is written to storage in a lazy initializer and the child is remounted with `key={theme}`. The router panel has no theme prop.
- **Theme branching in StyleX** is not possible without OS media queries; solutions use tokens that flip per theme (e.g. `foregroundPrimary`, `borderPrimary`) instead of color mixes, which went dusty in light mode.
- **`oxfmt` reflows code**, so Python string-replace patches written against the pre-format text can silently miss. Re-read the file after formatting before patching.
- **Shell cwd resets between calls**, and prior `cd` can leave the session in the wrong directory; use absolute paths or `cd` to the repo root first.
- The notification count in `routes/admin/-sidebar.tsx` (`unread = 3`) is a fixed placeholder; the top-bar bells in `(app)/-header.tsx` and `admin/-topbar.tsx` have no indicator yet.
- Sidebar collapse state is local React state, not persisted. Collapsed, the logo is the expand button, so there is no link to `/admin` from it.
